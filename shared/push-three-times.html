叫 Antigravity 替你裝好 git 與 GitHub CLI，一支 Python 小程式改三次、commit 三次、最後 push 一次到 GitHub

Have Antigravity install git and GitHub CLI, change a small Python script three times, commit three times, then push once to GitHub

大部分的活是 AI 替你做的。你負責三件事：講清楚要它做什麼、每一步執行前看一眼再按同意、做完自己去 GitHub 看到三筆歷史，截一張圖交上來。三個版本各改什麼，你自己決定。

The AI does most of the work. You do three things: say clearly what you want, look at each step before you approve it, and check on GitHub yourself that three commits are there, then hand in a screenshot. What changes in each of the three versions is up to you.
