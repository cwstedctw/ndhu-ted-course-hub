跟著步驟做

GitHub 帳號與兩步驟驗證（2FA）

GitHub 是放程式與作品的平台。這一項先備好你的帳號，開啟兩步驟驗證。

先準備
  • 能收信的東華信箱。
  • 手機上的 Google Authenticator 或 Microsoft Authenticator；還沒安裝可先到手機的應用程式商店取得。
東華信箱 @gms.ndhu.edu.tw；既有帳號新增並驗證即可。
已經有了？ 已有 GitHub 帳號就直接登入，不必重辦。東華信箱已驗證、2FA 已開啟的部分直接跳過。

  1. 已有帳號：補上東華信箱

    登入原帳號，按右上角頭像 → Settings → Emails → Add email address。新增東華信箱，回信箱開驗證信完成驗證。

    確認一下 → 確認東華信箱已加入這個帳號，並完成信箱驗證。

  2. 沒有帳號：才從註冊開始

    開 GitHub 註冊頁，用東華信箱設定帳號名（Username）與密碼。依畫面完成驗證，回信箱收驗證信，再回 GitHub 完成註冊。

    確認一下 → 能登入自己的 GitHub 帳號；記下帳號名，交作業時會用到。

    建立 GitHub 帳號 ↗

  3. 開啟兩步驟驗證

    右上角頭像 → Settings → Password and authentication → Two-factor authentication → Enable two-factor authentication。用手機驗證器 App 掃 QR Code，把 App 顯示的六位數驗證碼填回 GitHub；已開啟者不用重設。

    確認一下 → 手機驗證器能產生 GitHub 驗證碼；接著保存下一步的復原碼。

  4. 保存復原碼

    依畫面下載並保存復原碼，再確認「I have saved my recovery codes」完成啟用。存到自己保管、帶得走的地方；不要只留在公用電腦，也不要交作業。

    確認一下 → 帳號設定顯示 2FA 已啟用；自己知道復原碼放在哪裡，離開這台電腦後仍拿得到。

  5. 打開個人頁

    開 github.com/你的帳號名，留下個人頁截圖。

    確認一下 → 個人頁上看得到你的 GitHub 帳號名。

✓ 這樣就完成

  • 能登入 GitHub。
  • 東華信箱已新增並驗證。
  • 2FA 已開啟，復原碼已自行保存。
  • 個人頁截圖存好。

要交的截圖

GitHub 個人頁

  • 帳號名要清楚可見。

截圖避開：不用截兩步驟驗證設定頁。不要包含密碼、驗證 QR Code 或復原碼。

GitHub 註冊 ↗2FA 官方設定說明 ↗
收不到驗證信

先看垃圾郵件，再依畫面重送。仍卡住就記下狀況，下週帶手機來處理。

註冊時帳號名已被使用

在想用的帳號名後加數字，再試一次；已經有帳號的人不用另取新名字。

GitHub Student Developer Pack

這是 GitHub 的學生資格申請。這次完成送件即可，審核中也算完成。

先準備
  • 先完成第①項的 GitHub 帳號與東華信箱驗證。
  • 準備一份在學證明，四選一：學生證正反面、這學期課表、成績單或在學證明書。這份只上傳 GitHub。
使用第①項帳號內已驗證的東華信箱。
已經有了？ 已核准、學生資格還沒到期，就直接截目前的核准狀態；已送出、仍在審核中，也不用重送。

  1. 進入學生資格申請

    登入同一個 GitHub 帳號，開 GitHub Education，找 Get verified；介面也可能寫 Join GitHub Education。

    確認一下 → 進入學生資格申請流程，或能查看自己目前的申請狀態。

    開啟 GitHub Education ↗

  2. 填學校與用途

    學術信箱選已驗證的東華信箱；學校填 National Dong Hwa University。用途欄依表單要求，用英文寫兩三句自己的修課用途。

    確認一下 → 確認選的是東華信箱，學校名稱正確，用途是自己的情況。

  3. 上傳在學證明並送出

    從準備好的四種證明中選一種，依表單上傳。若用學生證，正反面都準備好；檢查清晰度與在學日期，再送出。

    確認一下 → 頁面可確認申請已送出或正在審核；不用等核准才繳作業。

  4. 保留狀態截圖

    截已送出、審核中或已核准的狀態，裁掉在學證明內容。

    確認一下 → 只看狀態就能知道你已辦理，畫面沒有學生證或成績單。

✓ 這樣就完成

  • 申請已送出，或已有尚未到期的核准資格。
  • 狀態截圖存好。

要交的截圖

已送出、審核中或已核准的狀態

  • 能看出目前的申請狀態。

截圖避開：不要附學生證、成績單、課表或在學證明書。

學生驗證有效 2 年，到期後須重新驗證；各項優惠有各自期限。

學生資格申請 ↗官方申請說明 ↗官方效期條款 ↗

GitHub account and two-factor authentication

GitHub is a platform for code and other work. For this item, prepare your account and enable two-factor authentication.

WHAT YOU NEED
  • Access to your NDHU email inbox.
  • Google Authenticator or Microsoft Authenticator on your phone. If needed, install one from your phone's app store.
NDHU email: @gms.ndhu.edu.tw. Add and verify it on your existing account.
Already set up? Sign in to your existing GitHub account; do not create another one. Skip any email verification or 2FA setup you have already completed.

  1. Existing account: add your NDHU email

    Sign in, then choose your profile picture → Settings → Emails → Add email address. Add your NDHU email and open the verification email to finish.

    Check → Confirm that the NDHU address is attached to this account and verified.

  2. No account yet: sign up

    Open GitHub sign-up. Use your NDHU email, choose a username and password, then follow the verification steps. Check your inbox and return to GitHub to complete registration.

    Check → You can sign in to your own GitHub account. Keep the username; you will submit it with this assignment.

    Create a GitHub account ↗

  3. Enable two-factor authentication

    Choose your profile picture → Settings → Password and authentication → Two-factor authentication → Enable two-factor authentication. Scan the QR code with your authenticator app, then enter its six-digit code on GitHub. Skip this if 2FA is already enabled.

    Check → Your authenticator generates a GitHub code. Continue to save the recovery codes in the next step.

  4. Save the recovery codes

    Download and save the recovery codes, then confirm “I have saved my recovery codes” to finish enabling 2FA. Keep them somewhere you control and can take with you, not only on a shared computer. Do not submit them.

    Check → Account settings show 2FA is enabled. You know where your recovery codes are and can access them after leaving this computer.

  5. Open your profile

    Open github.com/yourusername and save a screenshot of your profile.

    Check → Your GitHub username is visible on the profile.

✓ You are done when

  • You can sign in to GitHub.
  • Your NDHU email has been added and verified.
  • 2FA is enabled and you have saved your recovery codes.
  • Your profile screenshot is saved.
