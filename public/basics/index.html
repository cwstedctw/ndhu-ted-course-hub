這個時代的三樣基本功

這頁是給東華學生的，不管你有沒有修我的課。這三樣東西跟哪一門課無關，學會了之後都用得到。

AI 現在會大量幫你產出東西——程式、報告、圖、簡報。

產出變多之後，人的價值就從「做得出來」移到「看得懂、留得住、救得回來」。

下面三樣，就是這件事的三個面向。

最後查核 2026-09-15｜工具與方案隨時會變，頁內連結一律以官方頁為準。

1

辦好帳號

免費的工具很多，但要先有帳號才進得去。

四樣必備（GitHub 帳號、GitHub Student Developer Pack、ChatGPT 桌面版、Antigravity 桌面版；2026-09-15 起所有課共用、演講課除外）一頁走完，步驟寫到零經驗也跟得上。裡面也老實列了哪些方案台灣學生現在領不到，省下你去試的時間。

開學前的帳號清單 →

裡面有一件事特別值得辦 GitHub Student Developer Pack 含 Codespaces——瀏覽器裡的完整開發環境。 沒有筆電、或電腦不能裝東西的人，靠這條一樣能學。
2

Git／GitHub

東西留得住、看得出改了什麼、改壞了救得回來。

教的不是背指令，是三件能力：

  • 存得住：有一個 repo、幾個看得懂的存檔紀錄
  • 看得懂差異：這次改了什麼、跟上次差在哪
  • 救得回來：改壞了能復原

完整教材是公開的，15 關，可以自己走完。不必先會任何 Git 指令、終端機或程式語言。

跟 AI 一起用 Git →

它本來是寫給研究生與老師的，但你一樣走得完 第一階段（P1–P9）一個人就能做；第二階段要兩個人，找個同學一起。
3

AI Agent 的四件判斷

會自己動手的 AI，你要看得懂它在做什麼。

Agent 跟聊天型 AI 的差別：它會自己動手——開檔案、改檔案、跑指令。

所以你要練的是四件判斷，跟你用哪一個產品沒有關係：

　判斷白話
A1看得懂它打算做什麼動手前先讀它的計畫，別直接按同意
A2看得懂它做了什麼動手後看差異，別看它說「完成了」
A3破壞性動作先問刪除、覆蓋、對外發送，一律先確認
A4拒絕得了越界至少做過一次「我退回它」，並說得出為什麼
最有效的練法 找一個會自己動手的工具，故意讓它出錯，然後你去抓。 「會跑」不等於「做對」——這件事別人講一百次，不如你自己看見一次。

一句提醒

工具會換，能力不會。

這頁提到的每一個工具，一年後可能改名、改方案、或消失。但「留得住、看得懂、救得回來、判斷得了」這四件，換哪個工具都成立。

所以這頁只寫怎麼判斷，不寫按哪一顆按鈕。

Before you start

Three Basics for This Era

This page is for NDHU students, whether or not you are taking my courses. None of it is course-specific.

AI now produces a great deal on your behalf — code, reports, images, slides.

Once the volume goes up, your value moves from "being able to make it" to "being able to read it, keep it, and get it back".

These three are the three sides of that.

Last verified 2026-09-15 · Tools and offers change constantly; every link here defers to its official page.

1

Set up your accounts

Plenty of tools are free, but you need accounts to get in.

The four required items (a GitHub account, the GitHub Student Developer Pack, the ChatGPT desktop app and the Antigravity desktop app; every course from 2026-09-15, except the lecture series) on one page, written so that no prior experience is needed. It also states honestly which offers students in Taiwan cannot get, so you do not waste time trying.

Accounts to set up before class →

2

Git / GitHub

Keep your work, read what changed, recover when you break it.

What is taught is not command memorisation, but three abilities:

  • Keep it: a repository and a few readable save points
  • Read the difference: what changed since last time
  • Get it back: recover when you break something

The full material is public — 15 stages you can work through on your own. No prior Git, terminal, or programming knowledge required.

Using Git with AI →

It was written for researchers, but you can finish it too Stage one (P1–P9) works solo; stage two needs a partner, so bring a classmate.
3

Four judgements about AI agents

An AI that acts on its own — you need to see what it is doing.

The difference between an agent and a chat AI: an agent acts — it opens files, edits them, runs commands.

So what you practise is four judgements, and none of them depends on which product you use:

　JudgementIn plain words
A1See what it intends to doRead its plan before it acts; do not just click approve
A2See what it actually didRead the diff afterwards; do not trust "done"
A3Confirm destructive actionsDeleting, overwriting, sending things out — always confirm
A4Refuse when it overstepsPush back at least once, and be able to say why
The most effective way to practise Take a tool that acts on its own, make it fail on purpose, and catch it. "It runs" is not "it is correct" — and being told that a hundred times is worth less than seeing it once yourself.

One reminder

Tools change; the skills do not.

Every tool named on this page could be renamed, repriced, or gone within a year. But keeping your work, reading the difference, recovering, and judging what an agent is doing — those hold no matter which tool you use.

So this page only tells you how to judge, never which button to click.
