課前準備：四樣必備

GitHub 帳號、GitHub Student Developer Pack、ChatGPT 桌面版、Antigravity 桌面版，四樣都要。演講課《AI未來應用與趨勢探索》除外。

查核日 2026-09-15｜各家條件隨時會變；跟這頁對不上時，請以官方頁為準。

〇先講兩件事

工具會換，能力不會

  1. 先用免費、開源的。
  2. 免費的做不到，再考慮有免費額度的商業工具。
  3. 付費方案永遠是選配——課程的任何一分都不需要你付錢。

辦不成不扣分，但要處理

審核由對方公司決定。因年齡、帳號種類或審核等條件辦不成，不影響成績；但「辦不成」和「沒去辦」不同。卡住就在第一週跟老師講，別放著。

二① GitHub 帳號

1

GitHub 帳號

必備5 分鐘 🏫 東華信箱不用審核

每一門課都會教 Git 與 GitHub，重點是三件能力：存得住、看得懂差異、救得回來。這跟會不會寫程式無關。

  1. 開 github.com/signup。
  2. Email 用東華信箱 @gms.ndhu.edu.tw。
  3. 設密碼，選一個適合放進網址、日後不必急著更換的 Username。
  4. 完成驗證題，到信箱收驗證信，把 8 位數字填回網頁。
  5. 後面的使用問卷可以按 Skip。
開兩步驟驗證 頭像 → Settings → Password and authentication → Two-factor authentication。用驗證器 App 掃 QR，並把 recovery codes 存在手機、自己的雲端或印出帶走。
公用電腦注意 不要註冊 passkey／Windows Hello，不要讓瀏覽器記住密碼；把復原碼下載到公用電腦也不算存好，機器重新開機後可能全部清空。
辦不成怎麼辦：收不到信或驗證一直過不了，第一週帶著手機來現場處理。

三② GitHub Student Developer Pack

2

GitHub Student Developer Pack

必備要審核，最先送 🏫 東華信箱15 分鐘

Pack 包含 GitHub Pro、每月 180 核心小時 Codespaces、20 GB Codespaces 儲存空間、每月 3,000 分鐘 Actions、2 GB Packages 儲存空間，以及可申請的 GitHub Copilot Student。

Codespaces 是瀏覽器裡的完整開發環境。沒有筆電、共用家中電腦，或機器被鎖住不能裝軟體，都能靠它完成課堂工作。2 核機器的 180 核心小時約等於 90 小時。

Copilot 但書 GitHub 曾在 2026-04-20 暫停新申辦，並於 2026-06-17 宣布分批重新開放，包括 Student。值得申請，但不要當成一定取得；課程沒有作業需要 Copilot。官方公告

先準備

  • 已辦好的 GitHub 帳號，以及已加入並驗證的東華信箱。
  • 學生證照片、這學期課表、成績單或在學證明書，四擇一。
  • 學生證最好正反面都拍，讓註冊章與文字清楚可見。

步驟

  1. 若 GitHub 還沒有東華信箱：Settings → Emails → Add email address，收信驗證。
  2. 開 GitHub Education Students，按 Get verified；頁面也可能顯示 Join GitHub Education，或從 Billing and licensing → Education benefits → Start an application 進入。
  3. 學術信箱選東華信箱；學校填 National Dong Hwa University；用途用英文照實寫兩三句。
  4. 上傳在學證明並送出。

審核時間不一定。送出、仍在等待就算完成；退件通常會說明缺什麼，補件重送即可。申請說明見 GitHub 官方文件。

辦不成怎麼辦 免費 GitHub 帳號仍可做課堂練習，也有每月 120 核心小時 Codespaces；Pack 只是提高到 180 並加入 Pro。沒有筆電先用教室電腦或備用機，不影響成績。

四③ ChatGPT 帳號＋桌面版

3

ChatGPT 帳號＋桌面版

必備10 分鐘，含下載 任何信箱不用審核

桌面版除了聊天，還有會開檔、改檔與跑指令的 Codex。要安裝的是 2026-07-09 起的新版 ChatGPT，把 Chat、Work、Codex 放在同一個 App 裡；它不等於 ChatGPT Classic，Classic 沒有 Codex。

  1. 到 chatgpt.com 註冊；免費帳號即可，東華或個人信箱都可以。13 歲以上可使用，未滿 18 歲需家長同意。
  2. 到 ChatGPT 下載頁下載桌面版。
  3. Windows：從 Microsoft Store 安裝「ChatGPT」，不要裝「ChatGPT Classic」。最不容易拿錯的是官方 Microsoft Store 連結。需要 Windows 10 64 位元、版本 17763 以上，支援 x64 與 ARM64。
  4. macOS：需要 macOS 14 Sonoma 以上。官方說明中心稱 Apple Silicon 與 Intel 都可用，但新版下載按鈕只標 Apple Silicon；Intel Mac 先試裝，不行就用網頁版。
  5. Linux：支援 Ubuntu 24.04／26.04、Debian 13、Fedora 43／44、Arch，並有 x64 與 ARM64。
  6. 登入後開新對話測試一次，再從左上角選單找到 Codex；先不要叫它做事，第一次操作留到課堂。
三件先知道 一、不要等到上課才下載；公用電腦可能每次開機還原。
二、免費版可以有限額使用 Codex，但官方沒有公布額度數字。把它當成現在能用、額度不保證；課程作業不會押在它的額度上。
三、練習把需求說成四塊：目標、背景、輸出、邊界。
辦不成怎麼辦 桌面版若因電腦太舊或系統版本不足而裝不上，網頁版仍能完成大部分課堂內容；需要 Codex 的幾週用教室電腦或跟老師說，不扣分。

五④ Antigravity 桌面版

4

Antigravity 桌面版

必備20 分鐘，含下載 👤 個人 Gmail不用審核

Google 的 AI agent 桌面工具，會開檔、改檔、跑指令、安裝東西，再列出做過的事。課堂用它與 Codex 練四件判斷：

#判斷你要做得到
A1看懂它打算做什麼動手前先看計畫
A2看懂它做了什麼動手後看差異，不只相信「完成了」
A3破壞性動作先問刪除、覆蓋、對外發送、動別人的東西前先確認
A4拒絕越界至少退回一次，並說得出原因
  1. 先辦個人 Gmail；東華 Workspace 帳號常無法登入。
  2. 到 antigravity.google/download。Windows 需要 Windows 10 64 位元以上；macOS 需要 macOS 12 Monterey 以上；Linux 也有。
  3. 安裝後用個人 Gmail登入。官方 FAQ 稱目前開放給 personal Google accounts，遇到問題也建議改用 @gmail.com。
  4. 先找到計畫與修改結果顯示的位置，不要先把額度玩掉。
登入資格 Antigravity 會看帳號種類、登記國家與年齡；台灣在支援範圍內，但官方不開放未滿 18 歲者。未滿 18 歲先跳過，用 ChatGPT 桌面版的 Codex 練同樣四件事，第一週跟老師說，不扣分。官方 FAQ
額度與版本 免費額度目前每週刷新，不是隔天恢復。版本更新很快，因此本頁不指定版本號；畫面不同時查看官方更新紀錄。
辦不成怎麼辦：帳號種類、年齡與地區由 Google 決定。走不通就用 Codex 練習，並在第一週告訴老師，不扣分。

六選配：Google 學生方案

＋

Google AI Plus 一年

選配👤 個人 Gmail ⚠️ 綁付款方式

台灣學生可領一年 Google AI Plus；截止日 2026-12-31。需滿 18 歲、大專在學，並由 SheerID 驗證。家庭群組成員、受監護帳號，以及透過第三方訂閱 Google One 的既有會員不能領。

一年後會自動扣款 領取時必須綁有效付款方式；一年到期若未取消，會按台灣學生頁所列的每月 NT$165 自動續訂。要領就立刻設 11 個月後的行事曆提醒，並記下綁了哪張卡。

必須用個人 Gmail 領，不能用東華信箱。學生身分另外用學校信箱或在學證明交給 SheerID 驗證。

  1. 登入個人 Gmail。
  2. 開 Google 學生中心或領取頁。
  3. 由 SheerID 驗證學生身分，學校搜尋 National Dong Hwa University。
  4. 通過後綁付款方式並完成領取。完整條款
尚未實測 還沒有用真實學生帳號確認 SheerID 是否認得東華。條款排除名單沒有台灣，但台灣學生頁 FAQ 與條款頁的適用地區說法互有矛盾；若成功或失敗，請告訴老師更新本頁。

Before Class: Four Things Everyone Sets Up

A GitHub account, the GitHub Student Developer Pack, the ChatGPT desktop app, and the Antigravity desktop app are all required—except for the lecture series AI Future Applications and Trends.

Verified on 2026-09-15｜Offers and requirements change. If this page and an official page disagree, follow the official page.

0Two things first

Tools change; the skills do not

  1. Use free and open-source tools first.
  2. If they cannot do the job, consider commercial tools with a free tier.
  3. Paid plans are always optional. No part of your grade requires spending money.

Failing to get one costs no marks, but it must be dealt with

The vendor decides eligibility and approval. If age, account type, or review prevents you from completing an item, your grade is unaffected. “Could not get it” is different from “did not try”: tell the instructor in week 1 if you are stuck.

2① GitHub account

1

GitHub account

Required5 min🏫 NDHU addressNo review

Every course teaches Git and GitHub through three abilities: keeping your work, reading what changed, and recovering when something breaks. None depends on already knowing how to code.

  1. Go to github.com/signup.
  2. Use your @gms.ndhu.edu.tw address.
  3. Set a password and choose a username suitable for your public URL.
  4. Complete the verification puzzle, then enter the 8-digit code from your email.
  5. The following survey may be skipped.
Turn on 2FA: profile picture → Settings → Password and authentication → Two-factor authentication. Save the recovery codes on your phone, personal cloud storage, or paper.
Shared computers: do not register a passkey or Windows Hello, let the browser remember your password, or leave recovery codes in the Downloads folder. Lab computers may erase everything when restarted.
If it does not work out: bring your phone in week 1 if mail or verification keeps failing.

3② GitHub Student Developer Pack

2

GitHub Student Developer Pack

RequiredNeeds review—submit first🏫 NDHU address15 min

The Pack includes GitHub Pro, 180 Codespaces core hours per month, 20 GB of Codespaces storage, 3,000 Actions minutes per month, 2 GB of Packages storage, and access to apply for GitHub Copilot Student.

Codespaces is a full development environment in a browser. It removes the barrier for students without a laptop, using a shared computer, or unable to install software. On a 2-core machine, 180 core hours is about 90 hours.

Copilot note: new sign-ups were paused on 2026-04-20 and announced as reopening in stages on 2026-06-17, explicitly including Student. Apply, but do not assume it is guaranteed; no assignment requires it. Official announcement

Prepare first

  • Your GitHub account with your verified NDHU address.
  • One proof of enrolment: student ID, current timetable, transcript, or enrolment letter.
  • For a student ID, photograph both sides clearly so the current registration date or stamp is visible.
  1. If necessary, add the NDHU address under Settings → Emails → Add email address and verify it.
  2. Open GitHub Education Students and choose Get verified. The wording may instead be Join GitHub Education, or use Billing and licensing → Education benefits → Start an application.
  3. Select the NDHU address; enter National Dong Hwa University; describe your intended use honestly in two or three English sentences.
  4. Upload proof and submit.

Review time varies. A submitted application counts as complete while pending. If rejected, correct the requested item and resubmit. See the official application guide.

If it does not work out: a free GitHub account still covers class exercises and includes 120 Codespaces core hours per month. The Pack raises this to 180 and adds Pro. Use a classroom or spare machine if needed; no marks are lost.

4③ ChatGPT account + desktop app

3

ChatGPT account + desktop app

Required10 min incl. downloadAny addressNo review

The desktop app includes Codex, which can open and edit files and run commands. Install the new ChatGPT released from 2026-07-09 onward, combining Chat, Work, and Codex. It is not ChatGPT Classic; Classic does not include Codex.

  1. Sign up at chatgpt.com. A free account and either email address are enough. Users must be at least 13; those under 18 need parental permission.
  2. Open the ChatGPT download page.
  3. Windows: install “ChatGPT,” not “ChatGPT Classic,” from the Microsoft Store. It requires 64-bit Windows 10 build 17763 or later and supports x64 and ARM64.
  4. macOS: requires macOS 14 Sonoma or later. The help centre says Apple Silicon and Intel are supported, while the new download button says Apple Silicon only. Try the Intel install; use the web version if it fails.
  5. Linux: Ubuntu 24.04/26.04, Debian 13, Fedora 43/44, and Arch are supported, on x64 and ARM64.
  6. Sign in, test one chat, and locate Codex in the top-left menu. Do not run it yet; the first run happens in class.
Three things:
One: install before class; reset-on-boot lab machines may erase it.
Two: Free includes limited Codex usage, but OpenAI publishes no numerical quota. No assignment depends on it.
Three: practise expressing a request as goal, context, output, and boundaries.
If it does not work out: if the app will not install because the machine or OS is too old, the web version covers most class work. Use a classroom machine in Codex weeks or tell the instructor. No marks lost.

5④ Antigravity desktop app

4

Antigravity desktop app

Required20 min incl. download👤 Personal GmailNo review

Google's desktop AI agent opens and edits files, runs commands, installs things, and reports what it did. Alongside Codex, class uses it to practise four judgements:

#JudgementYou should be able to
A1See what it intends to doRead its plan before it acts
A2See what it actually didRead the diff rather than trust “done”
A3Confirm destructive actionsConfirm deletion, overwriting, external sending, or touching others' work
A4Refuse overreachPush back at least once and explain why
  1. Create a personal Gmail first. NDHU Workspace accounts frequently cannot sign in.
  2. Download from antigravity.google/download. It requires 64-bit Windows 10 or later, macOS 12 Monterey or later, or a supported Linux system.
  3. Sign in with a personal Gmail. The official FAQ says it is available for personal Google accounts and recommends an @gmail.com address when problems occur.
  4. Find where plans and resulting changes appear. Do not spend the quota yet.
Eligibility: Antigravity checks account type, registered country, and age. Taiwan is supported, but it is officially unavailable to users under 18. If under 18, skip it, practise the same four judgements in Codex, and tell the instructor in week 1. Official FAQ
Quota and versions: the free allowance now refreshes weekly, not daily. Releases move quickly, so this page names no version; consult the official changelog when screens differ.
If it does not work out: account type, age, and region are Google's conditions. Use Codex instead and tell the instructor in week 1. No marks lost.
