和 AI 一起寫程式　WEEK 3

把它弄壞三次，
然後修成 v1

今天不做新東西。先把上週那一頁讀懂、故意弄壞三次，再只加一件事變成 v1。

弄壞不是失敗，是最快看懂的方法。猜錯了最值錢——那代表你以為它這樣運作，其實不是。

1　今天交什麼

東西怎麼處理
當堂卡②（E2）當堂寫、當堂交，不帶回家。正面是 trace 四行，背面是三次弄壞加四件事。
panel-v0.html自己帶走，不交。不要覆蓋掉，W5 要拿它跟 v1 比差異。
panel-v1.html自己帶走，不交。今天新存的那一份。

沒改好也交。這張卡看的是證據完整不完整，不是做得漂不漂亮。

2　先拿出 v0

  1. 從自己的雲端硬碟或信箱，把上週存的單檔找出來，放到桌面。
  2. 用瀏覽器打開它，確認名字和按鈕還會動。
  3. 把檔名改成 panel-v0.html（等一下才分得出哪個是舊的）。

檔不見了、上週沒來、或帳號進不去？下載老師的範例當成你的 v0：v0-sample.html（在瀏覽器上按右鍵「另存新檔」）。用範例做今天全部的事，跟自己做的同分。整包也可以直接抓 starter.zip。

3　讀懂它：trace 四行

trace（追蹤）就是當一次電腦：一行一行念下去，每念一行就寫下「變數現在是多少」。

怎麼在記事本打開 .html

  1. 在檔案上按右鍵 → 開啟檔案 → 選「記事本」。（直接點兩下會用瀏覽器開，那樣看不到程式。）
  2. 找到 <script> 和 </script> 中間那幾行，那就是程式。

挑哪四行

  • 名字那行——把你的名字放進畫面的那一行。
  • 按鈕那行——寫著「按下去要做什麼」的那一行。
  • 加一那行——數字變多的那一行。
  • 顯示那行——把結果寫回畫面的那一行。

四行找到之後，填在卡的正面。三欄長這樣：

這一行做什麼變數現在是多少畫面會變嗎
把數字加一count 從 0 變成 1還不會，下一行才會

這一列是示範，不要照抄。「變數現在是多少」看不出來就寫「我看不出來」——那也是誠實的答案，比亂填有用。

4　弄壞三次，各一種

每一次都照這六步走：先寫預期 → 改 → 存檔 → 回瀏覽器重新整理 → 寫實際 → 改回來。一次只弄壞一處，改回來了才弄下一個。

  1. 第一次：改一個數字。把加一的那個 1 改成 10（或把一開始的 0 改成 5）。先寫：你猜按一下會變多少？
  2. 第二次：刪一行。把「顯示那行」整行刪掉。先寫：你猜按下去會發生什麼？畫面會不會動？
  3. 第三次：改一個名字。把 count 這個字只改其中一處，改成 counter，其他地方不動。先寫：你猜它會停在哪裡？

最常卡的兩件：①改完忘了存檔就去重新整理——畫面當然沒變，那不是程式的問題。②改到的是 AI 對話裡的預覽，不是桌面上那個檔——請確認記事本標題列上的檔名，跟你在瀏覽器打開的是同一個。

第三次多半會出現紅字，或是按了完全沒反應。那正好——那就是下一段要貼給 AI 的原文。

5　出錯了，先做這四步

以下四步照抄自共用教材 P9〈電腦出錯了，先做這四步〉（background-knowledge/P9-電腦出錯先做的四步.md），各科共用同一份，本週不另寫版本。

  1. 複製錯誤訊息的原文，整段。不要截圖、不要濃縮成「它壞了」。從第一個字到最後一個字，包括看不懂的那些。
  2. 貼給 AI，前面加一句情況。例如：「我在做 ___ 的時候出現這段，請先解釋這是什麼意思，再說你會怎麼查。」——先解釋，不是先修。
  3. 看它的計畫，不要照單全收。它會列出幾個可能的原因和要做的事。挑最像你情況的那一個；會動到檔案的，先備份再試。
  4. 自己驗一次結果，記下四格。原文寫了什麼／它說是什麼／我做了什麼／結果如何。沒解掉也記——下一次問的時候，這四格就是你的問題描述。

沒有紅字的（按了沒反應、畫面不動）：第一步的「原文」改寫成三句——我做了什麼、我預期看到什麼、實際看到什麼。

貼之前先遮掉個資：姓名、學號、密碼，還有檔案路徑裡有你名字的那一段（例如 C:\Users\王小明 換成 C:\Users\me，路徑其他部分留著，AI 要靠它判斷）。

附帶一句 P9 也寫著的：它說「已修好」不算數。你自己重新整理一次、按一次那顆按鈕，看到對的結果才算。

6　修成 v1：只加一件事

上週的需求卡交回去了，不用去找。現在用一句話重寫你的目標，再挑一件想往前的——一顆歸零按鈕、換個顏色、多顯示一句話都好。一次只加一件，看一次結果。

用 Gemini 的 Canvas，或任何一個你打得開的網頁版 AI，都可以。把下面這段跟你的 v0 全文一起貼進去：

這是我的 v0 全文，它現在做的是「___」。
只加「___」這一件，其他不要動。
先講你打算改哪裡，我說好再動手。

驗收看兩件：新加的那一件有沒有出現？原本會動的，還動不動？兩個都要看。

它多做了你沒要的事，就說「這個我沒要，拿掉」——那一次退回，寫進卡背面的四件事裡。

7　存成單檔帶走

  1. 下載 starter.zip 之後先解壓縮（在壓縮檔裡直接雙擊，改了會存到暫存資料夾，關掉就不見）。
  2. 先把程式碼複製出來：在 Canvas 切到程式碼（Code）那一面 → 點進去按 Ctrl+A 全選 → Ctrl+C 複製 → 開記事本 Ctrl+V 貼上。
  3. 存成 panel-v1.html。用記事本「另存新檔」時，存檔類型要先改成「所有檔案」、編碼選 UTF-8，不然它會偷偷存成 panel-v1.html.txt。存完看一眼檔名有沒有多出 .txt。
  4. panel-v0.html 不要覆蓋。兩個檔名不一樣，W5 才有兩版可以比差異。
  5. 兩個檔都存進自己的雲端硬碟，或寄一封給自己。
  6. 驗收分兩件：自己的裝置拿得到檔案；用瀏覽器打得開、按得動。

下載夾不算。教室電腦會重置，留在下載夾的東西下次就不在了。手機打不開或只看到一堆程式文字，就登記卡關、改用其他瀏覽器驗功能——手機不必一定跑得動。

8　沒有帳號、Canvas 被擋怎麼辦

  • 換一個你打得開的網頁版 AI，任何一個都行，同分。
  • 完全沒有 AI 可以用：用老師給的 v1-sample.html 當成你的 v1，把今天的 trace 與三次弄壞做完，同分。卡上照實寫「這次沒用 AI」。
  • 不要為了繞過帳號或年齡限制去借別人的帳號。做不到就登記卡關，當堂用老師範例或看同學示範完成 E2，把「我親自測的」和「我看到的」分開寫。

今天的計分看的是 trace 與三次弄壞的證據，不是你用了哪一家 AI。

  • 10/05（W5）：帶著 panel-v0.html 和 panel-v1.html 兩個檔來，那天要把它放上網。
  • 兩個檔在雲端或信箱裡放好，中間這兩週不要刪。
