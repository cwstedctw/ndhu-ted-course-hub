指令小抄｜讓 AI agent 接上 Gemini Notebook

資訊科技與應用（115-1）　完整步驟在 學生頁；觀念在 互動概念頁。API 是公開預覽，內容依 Google 官方文件 2026-11-10 的版本。

一　用手（網頁）

  1. 無痕視窗開 https://notebook.google.com，個人 Gmail 登入。
  2. ＋ 新增筆記本 → ＋ 新增來源 → 網站 → 貼網址（多個用換行或空格分開）→ 插入。
  3. ＋ 新增來源 → 複製的文字 → 貼你自己的三句。
  4. 在「提問或創作內容」框提問 → 點回答後面的小數字 → 左邊看原文反白。
  5. 把一句話拆成兩半，各自對引用的原文。

二　四個詞

API服務開給程式用的窗口：https://notebook.googleapis.com/v1
專案Google Cloud 的戶頭，API 用量記在它名下
OAuth 同意瀏覽器裡按「允許」——只有你能按
權杖一小時有效的通行證；ya29. 開頭，不印、不存、不貼

API 做得到：建／看／列／改名筆記本；加網頁、YouTube、文字、Markdown 來源；查狀態。
還做不到：提問、刪除、上傳檔案、語音摘要、學校帳號。

三　交給 agent（提示詞在起始檔 agent-prompt.zh-TW.md）

三條規矩：先給計畫，我說可以才動手／權杖不准印／不動我原本的筆記本。agent 會依序跑：

winget install --id Google.CloudSDK -e                      （Windows 裝 gcloud；裝完開新視窗）
gcloud --version
gcloud auth login                                           （第 1 次瀏覽器登入：你來按）
gcloud projects create nb-你的代號
gcloud config set project nb-你的代號
gcloud services enable notebook.googleapis.com --project=nb-你的代號
（你自己做）console.cloud.google.com/auth/overview：開始→外部→同意；目標對象加自己為測試使用者；
            用戶端→電腦版應用程式→下載 JSON，改名 client.json 放進起始檔資料夾
gcloud auth application-default login --client-id-file=client.json --scopes="https://www.googleapis.com/auth/cloud-platform,https://www.googleapis.com/auth/notebook"
                                                            （第 2 次瀏覽器登入：進階→前往→允許）
gcloud auth application-default print-access-token          （拿權杖，放變數、不印）

每個請求帶兩個標頭：Authorization: Bearer 權杖、x-goog-user-project: nb-你的代號

做什麼動作與網址內容（JSON）
列出筆記本GET /v1/notebooks—
建筆記本POST /v1/notebooks{"displayName":"W10-agent-空氣品質"}
加網頁／YouTubePOST /v1/notebooks/你的ID/sources{"webContent":{"url":"https://…"}}
加文字同上{"displayName":"我的筆記","mimeType":"text/markdown","textContent":{"content":"…"}}
查來源狀態GET /v1/notebooks/你的ID/sources看每一筆的 state：PROCESSING → ACTIVE 或 FAILED

路線 B　自己貼（起始檔 nb.ps1）

在起始檔資料夾開 PowerShell：

powershell -ExecutionPolicy Bypass -File .\nb.ps1 check
powershell -ExecutionPolicy Bypass -File .\nb.ps1 new "W10-agent-空氣品質"
powershell -ExecutionPolicy Bypass -File .\nb.ps1 add notebooks/你的ID "https://…"
powershell -ExecutionPolicy Bypass -File .\nb.ps1 addtext notebooks/你的ID .\my-notes.md "我的筆記"
powershell -ExecutionPolicy Bypass -File .\nb.ps1 wait notebooks/你的ID
powershell -ExecutionPolicy Bypass -File .\nb.ps1 list

四　讀回＋收尾

  1. 回 notebook.google.com 重新整理：找到 agent 建的那一本、來源數對、中文沒亂碼、原本那本沒被動。
  2. 在那一本自己問一題、點引用。
  3. 撤銷這台電腦的登入：
gcloud auth application-default revoke
gcloud auth revoke --all

刪掉 client.json；關掉無痕視窗；不要的筆記本自己到網頁刪（API 刪不了）。

常見錯誤

看到原因處置
「系統已封鎖這個應用程式」登入沒帶自己的用戶端（官方那行實測被擋）建 client.json，登入加 --client-id-file=client.json
「未完成 Google 驗證程序」帳號不在測試使用者清單目標對象 → 測試使用者加自己，等儲存轉完
401 UNAUTHENTICATED沒帶權杖或權杖過期（一小時）請 agent 重新取權杖
403 … WORKSPACE_ACCOUNT_NOT_SUPPORTED用了學校帳號兩次登入都改個人 Gmail
404 … Account not found for user.帳號沒在網頁登入過 Gemini Notebook先到 notebook.google.com 登入一次
429 RESOURCE_EXHAUSTED送太快（每人每分鐘加來源 20 次）等一分鐘，不要重複加
