3. 目標一：看懂整理表（20 分鐘）

點 整理表 工作表。一站一列，10 個欄：縣市、行政區、站號、站名、總格、可借、可還、啟用、緯度、經度。

第 1 題：台北市有幾站？

  1. 點「縣市」右邊的下拉箭頭。
  2. 取消「全選」，只勾「台北市」，按「確定」。
  3. 點篩選後看得到的第一個「站名」儲存格，按 Ctrl＋Shift＋↓，看視窗右下角的「項目個數」（只算看得到的列）。

你應該看到項目個數 249。表格只剩台北市的列，列號變成藍色、跳號。

  1. 再點「縣市」的下拉箭頭，按「清除 "縣市" 的篩選」（選項裡會帶入欄名）。

你應該看到又看得到 478 站，台北、新北、台中都在。

第 2 題：可借＝0（一台車都沒有）的站有幾站？

用「可借」的下拉箭頭，只勾 0。

你應該看到54 站。往下捲，臺大公館校區特別多。看完記得清除篩選。

第 3 題：可借最多的是哪一站？

點「可借」的下拉箭頭 →「從最大到最小排序」（有的版本叫「遞減排序」）。

你應該看到第一列是台北市萬華區「YouBike2.0_老松國小」，可借 72 台。

標題列沒有下拉箭頭

點整理表任一格 → 資料 → 篩選。

篩選完，很多列不見了

那是篩選還開著，列號是藍色就是在篩選中。點那一欄的下拉箭頭清除篩選。

右下角沒有「項目個數」或「加總」

在右下角狀態列按右鍵，把「項目個數」「加總」勾起來。

站號那一欄有綠色小三角

站號存成文字（它是代號，不拿來加減），不用管。

4. 目標二：樞紐分析表＋一張圖（25 分鐘）

4-1 做樞紐分析表

  1. 點整理表任一格 → 插入 → 樞紐分析表。
  2. 範圍會自動選好整張表，位置選「新工作表」→ 確定。
  3. 右邊出現「樞紐分析表欄位」。把 縣市 拖到「列」。
  4. 把 站名、總格、可借 依序拖到「值」。

你應該看到新工作表上：A3「列標籤」，A4 到 A6 三個縣市（台中市、台北市、新北市），A7「總計」。B3 到 D3 是「計數 - 站名」「加總 - 總格」「加總 - 可借」。台北市那一列是 249、7,615、2,094。

只放縣市三列。想再拆行政區是選配，不用另做第二個樞紐。

值變成「加總 - 站名」，或「計數 - 總格」

點「值」區那個欄位 → 值欄位設定（功能區上叫「欄位設定」）→ 站名改成「計數」，總格、可借改成「加總」。

我的 A3 是「值」，三個縣市在 A5 到 A7

有的版本會多一列。下面每個列號都加 1：F4、G4 打標題，F5 打 =A5、G5 打 =D5/C5，選 F4:G7 畫圖。

三個縣市的順序跟上面不一樣

沒關係。下面的公式照「你的 A4、A5、A6 是哪個縣市」來看就好。

4-2 可借率三格

在樞紐右邊，用鍵盤打（不要用滑鼠去點樞紐的格子）：

你應該看到台中市 25.9%、台北市 27.5%、新北市 26.0%（順序跟你的 A 欄一樣）。

G4、G5、G6 三格一模一樣，公式很長，有 GETPIVOTDATA

可借率顯示 0.2593…

4-3 一張直條圖

  1. 選 F3:G6（游標要在這塊，不要在樞紐裡）。
  2. 插入 → 直條圖 → 群組直條圖。
  3. 點圖表標題，改成「三地可借率（可借合計÷總格合計）」。
  4. 先點圖表外面的空白儲存格，再在圖下方的儲存格打（文字打在儲存格裡，不是打進圖表）：「資料來源：台北、新北、台中市政府 YouBike 2.0 即時資料，2026-10-17 18:28 快照」。

你應該看到三根柱子、一種顏色，縱軸從 0% 開始，標題、單位（%）、來源與時間都有。

圖變成三種顏色的柱子，旁邊還有欄位按鈕

那是「樞紐分析圖」：插入時游標在樞紐裡。刪掉這張圖，先選 F3:G6 再插入。

圖上有一根「總計」，或少了一個縣市

列號差了一列：看你的三個縣市在 A 欄哪三列，F、G 欄的公式和選的範圍要對齊那三列。

三根柱子高度看起來差很多

5. 目標三：兩筆回查（15 分鐘）

圖畫好了，現在證明它沒算錯。照下面兩筆找回去，看數字一不一樣。不用另外寫卡。

第一筆：合計值

挑圖上一個縣市（例：台北市 27.5%）。

  1. 回樞紐看那一列：可借合計、總格合計。
  2. 回 整理表，先清掉前面留下的篩選，再篩選同一個縣市。點看得到的第一站的「可借」，按 Ctrl＋Shift＋↓，看右下角「加總」；「總格」也一樣。

你應該看到台北市：樞紐 2,094 ÷ 7,615；整理表篩選後，可借加總 2,094、總格加總 7,615。一樣。

第二筆：單站值

  1. 在整理表挑你自己的一站，記下它的站號和可借數。
  2. 到同一個檔裡那個縣市的「原始表」工作表（台北看 原始表_台北，依此類推）。
  3. 按 Ctrl＋F，貼上站號，找到那一列。
  4. 對照欄位對照表，看那一列的「可借」欄：台北叫 available_rent_bikes、新北叫 sbi_quantity、台中叫 sbi。

你應該看到例：台中市西區「科博館/金典酒店」，整理表可借 30；原始表_台中 第 128 列的 sbi 欄（K 欄）也是 30，左上角有綠色小三角，因為原檔把它存成文字。

做完了：上傳 Excel 檔

兩筆都找到了，就把 整理表_縮小版.xlsx 存檔，上傳到老師上課時開的 e學苑 作業。檔案裡要看得到樞紐、三格可借率、一張直條圖。
