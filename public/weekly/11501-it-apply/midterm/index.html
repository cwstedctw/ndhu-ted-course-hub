2. 第一步：定一個問題

好問題的樣子：資料答得出來、一句話講得完、答案不是一眼就知道。四種最好下手：

類型句型會畫的圖
比大小、排名哪個縣市（行政區、類別）的 ○○ 最多／最少？長條圖
看變化○○ 這幾年（這幾個月、一天之中）怎麼變？折線圖
找關係○○ 比較高的地方，△△ 是不是也比較高？散佈圖
看組成○○ 裡面，各類別各占多少？長條圖（比圓餅圖好讀）

太大的問題（「台灣的交通好不好」）縮成資料答得出的一小塊（「哪個縣市每萬人的公車站最多」）。先寫一句，找到資料後可以再改。

你應該看到一句話的問題，寫在報告第一段。

想不到題目

從你每天會碰到的事開始：通勤、租屋、吃的、天氣、運動、家鄉。去第 3 節的平臺用關鍵字搜一下，看哪一份資料讓你想問「為什麼」。

問題跟資料對不起來

正常。先看資料有哪些欄位，再把問題改成那些欄位答得出來的樣子。

去哪裡找

平臺（點名稱開網站）適合找
政府資料開放平臺什麼都有，先從這裡搜
臺北市資料大平臺台北市交通、人口、設施
新北市政府資料開放平臺新北市
臺中市政府資料開放平臺台中市
高雄市政府資料開放平臺高雄市
運輸資料流通服務 TDX公車、火車、捷運（多數要註冊）
中央氣象署開放資料天氣、雨量、地震（多數要註冊）
環境部環境資料開放平臺空氣、水、廢棄物
教育部統計處學生數、學校、畢業生
內政部社會經濟資料服務平臺人口、村里統計

挑資料的四個判準

  1. 下載得到：有 CSV、JSON 或 Excel 檔。只有網頁表格或要寫信申請的，換一份。
  2. 量剛好：幾十到幾萬列。只有十幾列畫不出東西；幾十萬列 Excel 會很慢。
  3. 有一個分類欄＋一個數字欄：例如「縣市」＋「人數」。有時間欄更好。
  4. 看得到更新時間和授權：資料頁會寫「更新頻率」「授權方式」。政府資料開放平臺的資料大多是「政府資料開放授權條款」，可以自由使用，要註明出處。

你應該看到來源三行，抄進報告第二段：①資料名稱與網址 ②你下載的日期時間 ③授權方式。

範例 A：台北 YouBike（從網頁下載 JSON）

範例不能當期中題目。只看「怎麼拿到資料」。

  1. 打開臺北市資料大平臺，搜尋「YouBike2.0」，點「YouBike2.0臺北市公共自行車即時資訊」。
  2. 看詮釋資料：更新頻率每 1 分、資料授權公開、主要欄位有站名（sna）、行政區（sarea）、總停車格（Quantity）、可借車數（available_rent_bikes）。
  3. 「檔案下載」那一列，格式 JSON，按「下載」。
  4. 存檔，檔名加上下載時間，例如 台北YouBike_20261021-1000.json。即時資料每分鐘都在變，時間要記下來。

你應該看到一個約 1 MB 的 JSON 檔，大約 1,800 站（2026-10-21 實抓 1,822 站）。

按了下載，瀏覽器卻顯示一大堆文字

那就是 JSON 的內容。按右鍵 → 另存新檔，存成 .json。

JSON 用 Excel 打不開

兩條路：Excel 的 資料 → 取得資料 → 從檔案 → 從 JSON（選單名稱以畫面為準），或交給 AI 轉成 CSV（第 4 節）。

範例 B：空氣品質指標 AQI（從環境部下載 CSV）

範例不能當期中題目。只看「怎麼拿到資料」。

  1. 打開環境部環境資料開放平臺，搜尋「空氣品質指標」，點「空氣品質指標(AQI)」（資料集代碼 AQX_P_432）。
  2. 看詮釋資料：每 1 小時更新；欄位有測站名稱、縣市、AQI、PM2.5、狀態、資料發布時間。
  3. 往下到「資料預覽」，按「下載篩選後資料」→ 選 CSV。

你應該看到一個 CSV 檔，每個測站一列（2026-10-21 10:00 那一份是 84 個測站）。

這份下載的測站名稱、縣市、狀態是英文（Hualien、Hualien County、Good），而且只有最新一個整點、最多 100 列。要整理成中文，就是第三步的工作。

在政府資料開放平臺按 CSV 下載，出現「每日呼叫API的次數不可大於5000次」

那個公用下載鍵全國共用，一天用完就不能下（2026-10-21 實際遇到）。改去資料原本的機關網站（像範例 B 的環境部平臺）下載，或隔天再試。

要註冊會員、要 API 金鑰

TDX、氣象署很多資料要先註冊。註冊免費，但要等寄信；趕時間就換一份不用註冊的。

4. 第三步：整理資料

整理的目的：讓每一列是一筆、每一欄是一種東西、數字真的是數字。三條路評分一樣，挑你順手的。

路 A：Excel 或 Google 試算表自己做

  1. 開檔：CSV 用 資料 → 從文字/CSV 匯入，編碼選 UTF-8（不然中文會變亂碼）。
  2. 選整張表 → 插入 → 表格，勾「我的表格有標題」。
  3. 一欄一欄看：數字欄是不是真的數字（靠左通常是文字；用 =SUM(那一欄) 試加，加起來是 0 或加不起來，就是文字，要轉成數字）、有沒有空白、有沒有怪值（-1、999、「—」）。
  4. 不要的欄可以隱藏，不要刪原始工作表。另開一張工作表叫「整理表」做事。

用 Google 試算表（學校帳號）：檔案 → 匯入 → 上傳 CSV；資料 → 建立篩選器；插入 → 資料透視表；做完 檔案 → 下載 → Microsoft Excel（.xlsx）。W7 學生頁第 7 節有一樣的步驟（選單名稱以畫面為準）。

路 B：AI 網頁版，上傳檔案請它整理

在 ChatGPT、Gemini、Claude 這類 AI 網頁版的對話裡上傳檔案，用白話請它做事。有的會在旁邊開一個可以一起改的區塊（叫 Canvas 或 Artifacts），有的直接在對話裡跑程式給你結果，名稱不一樣、用法差不多。先問、再改，不要一開始就叫它「幫我分析」：

我上傳的是 <資料名稱>，來源 <網址>，<下載日期時間> 下載。
先不要改任何資料。請告訴我：有幾列、幾欄、每一欄是什麼意思、
哪些欄有空白或怪值、數字欄有沒有被當成文字。

看完它的回答，再一件一件請它做：

請把 <欄位> 轉成數字；空白的不要刪，標成「缺」，告訴我有幾列。
做完給我下載 CSV（UTF-8），並列出你改了哪些東西。

它給不出下載檔，就請它把做法寫成 Python，改走路 C。

路 C：請 AI 寫 Python，在 Google Colab 跑

想看清楚每一步怎麼做的，請 AI 寫 Python 程式，貼到 Google Colab（用 Google 帳號開的線上筆記本，不用安裝）執行：

請寫一段 Python，在 Google Colab 執行：讀我上傳的 <檔名>，
印出列數、欄名、每欄空白幾個，再把 <欄位> 轉成數字，
存成 整理後.csv，用 encoding="utf-8-sig"、index=False（Excel 打開才不會亂碼、不會多一欄編號）。每一步加中文註解。

程式跑出錯，把整段錯誤訊息貼回給 AI，說「這是錯誤，請修正，並告訴我原因」。

不管走哪條路，都要做這三件事

  1. 列數對一次：整理前幾列、整理後幾列，差多少、為什麼（刪了重複？標成缺？）。
  2. 兩筆回查：隨便挑兩筆，用不會重複的欄位（站號、測站編號、名稱＋行政區）回原始檔找同一筆，數字一樣才算數。整理時排序或刪過列，列號就對不上，不要用列號找。
  3. 寫下你怎麼處理怪東西：空白、怪值、英文名稱、重複列，各怎麼處理。這段直接放進報告。

你應該看到一張整理表、整理前後的列數、兩筆回查（用哪個欄位找、原始檔和整理表的數字各是多少）。

中文變亂碼

檔案是 UTF-8，Excel 直接雙擊會用錯編碼。用「從文字/CSV 匯入」選 UTF-8，或存成 UTF-8-BOM。

日期變成一串數字（像 46316）

那是 Excel 的日期序號。選那一欄 → 儲存格格式 → 日期。

AI 說有 100 列，我數是 84 列

以你自己數的為準，跟 AI 說「我數到 84 列，請重算並說明差在哪」。AI 數錯很常見，這就是為什麼要回查。

範例 B 的英文縣市要轉中文

做一張對照表（兩欄：英文、中文），用 XLOOKUP（照一個值去對照表查另一個值的公式，例如 =XLOOKUP(B2, 對照表!A:A, 對照表!B:B)，B2 是英文縣市）或請 AI 照對照表換。對照表本身也要檢查一次。

5. 第四步：分析、出圖

一個問題配一張圖

你的問題是用這種圖
比大小、排名長條圖（類別多就用橫條，由大排到小）
看變化折線圖（橫軸是時間）
找關係散佈圖（一個點是一筆）

每張圖都要有四樣東西

  1. 標題：寫出結論或問題，例如「哪個縣市的 ○○ 最多（2026-10-21）」。
  2. 單位：座標軸寫上單位（人、站、μg/m³、%）。
  3. 來源與時間：一行小字「資料來源：○○，2026-10-21 10:00 下載」，放在圖裡面（Excel：圖表項目加「副標題」或插入文字方塊；AI／Colab：請它加在圖下方）。放在圖外的儲存格，複製圖時不會跟著走。
  4. 看得懂的類別名稱：不要留英文代碼或欄位名。

怎麼算、怎麼畫

  • Excel：插入 → 樞紐分析表，把分類欄拉到「列」、數字欄拉到「值」，再 插入 → 圖表（W7 做過）。比率要用合計 ÷ 合計，不要把每一筆的百分比拿來平均（W7 的可借率就是這個陷阱）。
  • AI 網頁版：先叫它給你算好的表格，你核對一兩格，對了再叫它畫圖：
先用表格列出每個 <分類> 的 <數字欄> 合計，由大排到小，不要畫圖。
我核對後，再請你畫長條圖：標題 <…>、Y 軸單位 <…>、圖下方寫資料來源與時間。
  • Colab：請 AI 用 matplotlib 畫，存成 PNG。

你應該看到一到三張圖（PNG 或 Excel 圖表），每張圖旁邊有它背後的數字表。

AI 畫的圖，要拿得到背後的數字表。拿不到、或數字對不回整理表，那張圖不能用。

Colab 畫出來中文變成方塊

Colab 預設沒有中文字型。把錯的圖和這句話給 AI：「圖上的中文變方塊，請修正字型」；或先把標籤改成英文。

圖很多，不知道放哪張

只放回答你那個問題的圖。其他的不要硬塞。

6. 第五步：寫 Word 報告

用 W5 的報告格式（W5 報告範本）：標題樣式、自動目錄、圖用「插入標號」、內文用「交互參照」寫「如圖 1 所示」。頁數不限，下面六段都要有：

段寫什麼
一、問題你的一句話問題，為什麼想知道
二、資料來源來源三行（名稱與網址、下載時間、授權），資料有幾列、幾欄、用到哪幾欄
三、怎麼整理空白、怪值、英文、重複怎麼處理；整理前後列數；兩筆回查
四、發現每張圖一段：圖說了什麼、最高最低是誰、差多少。數字要寫出來
五、限制這份資料答不了什麼（只是某一刻的快照、有缺值的測站、只有部分縣市……）
六、AI 使用紀錄用了哪一套 AI、做了哪幾件事、哪裡你自己驗過、哪裡發現 AI 錯了怎麼改。沒用 AI 就寫「本次未使用 AI」

圖怎麼放進 Word

  • Excel 的圖：點圖 → 複製 → 到 Word 貼上（貼成圖片比較不會跑版）。
  • AI 或 Colab 的圖：下載 PNG → Word 插入 → 圖片。
  • 圖裡沒有來源那行，就寫在圖說下面一行。
  • 放好後：右鍵 → 插入標號 → 「圖 1 ○○○」；內文提到它時用 參考資料 → 交互參照，不要手打「圖 1」。

你應該看到期中報告.docx：有目錄、圖有標號、內文用交互參照、六段都在。

圖貼進來很糊

Excel 圖改用「選擇性貼上 → 圖片（增強型中繼檔）」；PNG 請 AI 存成寬至少 1600 像素，貼進 Word 再縮小。

目錄頁碼不對

目錄上按右鍵 → 更新功能變數 → 更新整個目錄。

7. 第六步：做簡報、上台

簡報從報告長出來，不要另外重寫一套。建議六頁：

頁放什麼
1問題（一句話）＋你的名字
2資料：從哪裡、什麼時候、幾筆
3怎麼整理：最重要的一個處理＋回查
4主圖：最能回答問題的那一張
5發現：兩三句，數字要跟報告一樣
6限制＋AI 幫了什麼、你驗了什麼
  • 每頁一個想法，字越少越好，圖放大。
  • PowerPoint、Google 簡報、Canva、AI 生的簡報都可以；AI 生的要改到每一頁你都講得出來。
  • 數字跟報告對一次，兩邊不一樣就是有一邊錯了。

W9 上台

  • 照簡報順序講你的問題、資料、圖、發現。
  • 同學和老師會問「這個數字哪裡來的？」——你要能打開原始檔或整理表，指出是哪一列。
  • 帶著你的資料檔（原始檔＋整理表）來，上台時開得出來。

你應該看到期中簡報.pptx（或 PDF），W9 上台時講得出每個數字的來處。

8. 交件前檢查清單

期中 30% 看四部分：資料與整理（來源清楚、回查做了）、分析與圖、Word 報告、簡報與上台（答得出數字哪來的）。不看你用哪一套 AI，也不看台風。

檢查清單的勾選只留在這個分頁，重新整理就會清掉。
