1-1

LaTeX 是什麼

LaTeX（排版系統）的原稿是一個純文字檔（.tex）。按下編譯（compile），它才把原稿排成 PDF。圖號、引用號、章節編號都由它自己編。

WordLaTeX
怎麼寫所見即所得，畫面上看到的就是成品寫純文字加標記，例如 \section{…}，編譯後才看到成品
怎麼排版點滑鼠選樣式寫標記，排版交給它
圖號、引用號多半要自己顧自動編號，增刪一張圖，後面的號碼自己更新

Overleaf 是瀏覽器裡的 LaTeX，免安裝，右邊馬上看到 PDF。第一部分全程用它。

1-2

註冊、登入 Overleaf

  1. 做什麼用 Chrome 打開 overleaf.com（教室電腦請開無痕視窗：Chrome 右上角三個點 →「新增無痕式視窗」）。

  2. 做什麼第一次用：按右上角 Sign up（或登入頁最下面的 Register），選 Log in with Google 用學校的 Google 帳號最快；也可以填 email 和自己設的密碼，再到信箱點確認信。已經有帳號的按 Log in。

    應該看到專案清單頁（網址是 overleaf.com/project），左上有綠色的 New Project 按鈕。第一次進來清單是空的，這是正常的。

跳出 cookie 詢問，選 Essential cookies only 就好。不要把密碼或驗證碼貼給 AI。Overleaf 的介面是英文的，下面每一步都會寫出按鈕上的英文字。

1-3 · 約 3 分

先看 Overleaf 自己附的範例

  1. 做什麼按 New Project → Example Project。

    應該看到三塊畫面：左邊檔案區、中間原稿、右邊 PDF。範例裡有章節、圖、引用。

  2. 做什麼按 Recompile，再把中間原稿 \title{…} 大括號裡的字改掉，再按一次 Recompile。

    應該看到右邊 PDF 的標題跟著變了。這就是「改原稿 → 編譯 → PDF 更新」。

範例是英文的，看懂結構就好，不用讀完。

1-4

貼上中文起始檔、編譯

  1. 做什麼回到專案清單（按左上角的 Overleaf 圖示或瀏覽器上一頁），按 New Project → Blank Project，名稱填 w11-hand，按 Create。

    應該看到一樣是三塊畫面，中間的 main.tex 只有短短幾行英文。

  2. 做什麼按下面深色框右上角的「複製」，把整份起始檔複製起來。

    % hand-first.tex：第一部分「先用手做一輪」的起始檔。
% 百分比符號後面是註解，不會出現在 PDF 裡。
% Overleaf：Menu → Settings → Compiler 選 XeLaTeX，再按 Recompile。
\documentclass[12pt,a4paper]{article}
\usepackage{xeCJK}
% 下面這一行在挑中文字型：Overleaf 用 Noto Serif CJK TC，Windows 用微軟正黑體，Mac 用宋體。
\IfFontExistsTF{Noto Serif CJK TC}{\setCJKmainfont{Noto Serif CJK TC}}{\IfFontExistsTF{Microsoft JhengHei}{\setCJKmainfont{Microsoft JhengHei}}{\setCJKmainfont{Songti TC}}}
\usepackage[margin=2.5cm]{geometry}
\renewcommand{\refname}{參考文獻}

\title{我的第一份 LaTeX 文件}
\author{你的稱呼（可用化名）}
\date{2026 年 11 月}

\begin{document}
\maketitle

\section{這份文件在做什麼}
這是用 LaTeX 寫的一頁文件。原稿是純文字，按下 Recompile 之後才變成 PDF。
\textbf{粗體}要用標記寫出來，章節編號由它自己排。

\section{三件我今天要學的事}
\begin{itemize}
  \item 改原稿、重新編譯，看 PDF 怎麼變。
  \item 讀懂一個錯誤訊息，把它修好。
  \item 加一筆引用，讓參考文獻自己出現。
\end{itemize}

\section{一篇文獻}
% 做到「加一筆引用」那一步時：把下面這一行開頭的百分比符號拿掉。
% 這裡引用一篇 2021 年刊登在 BMC Geriatrics 的研究 \cite{Su2021}。

% 做到「加一筆引用」那一步時：把下面兩行開頭的百分比符號也拿掉。
% \bibliographystyle{plain}
% \bibliography{refs}
\end{document}

    這就是起始包裡的 hand-first.tex。想從檔案開也可以：對檔案按右鍵 → 開啟檔案 → 記事本（Mac 用「文字編輯」）。

  3. 做什麼在 Overleaf 中間的原稿區點一下，按 Ctrl＋A 全選（Mac 是 ⌘＋A），再按 Ctrl＋V 貼上，蓋掉原本的內容。

    應該看到原稿第一行變成 % hand-first.tex：…。

  4. 做什麼把編譯器換成 XeLaTeX（中文需要它）。Overleaf 有新舊兩種介面，位置不同：
    舊介面：左上角 Menu → 往下找 Settings 區塊的 Compiler → 選 XeLaTeX。
    新介面：左下角齒輪 Settings → Compiler 分頁 → Compiler 選 XeLaTeX。

  5. 做什麼按 PDF 上方綠色的 Recompile。

    應該看到一頁中文 PDF：標題「我的第一份 LaTeX 文件」，三個有編號的章節，第二節是三點條列。

原稿裡 % 開頭的那幾行是註解，不會出現在 PDF 裡。中文變成方框或整頁編不出來，九成是編譯器還停在 pdfLaTeX，回上一步檢查。

1-5

改三處，再編一次

  1. 做什麼把 \title{…} 換成你自己的題目。

  2. 做什麼把 \author{…} 換成你的稱呼（可以用化名，不要寫學號）。

  3. 做什麼在 \section{一篇文獻} 前面加一節：

    \section{我的看法}
這裡寫第一句。這裡寫第二句。

    兩句話換成你自己的。

  4. 做什麼Recompile。

    應該看到新題目、新稱呼；「我的看法」自己排成第 3 節，後面那節自動變成第 4 節。

六個最常見的標記，先認得就好：

標記做什麼
\section{標題}開一個有編號的章節
\textbf{文字}粗體
\begin{itemize} \item …條列，每個 \item 一點，最後 \end{itemize}
\begin{figure} … \includegraphics{檔名} … \end{figure}放一張圖，加 \caption{…} 就有「圖 1」
\cite{代號}引用一筆文獻，PDF 上變成 [1]
% 文字註解，PDF 上看不到
1-6

故意弄壞一行，再把它修好

  1. 做什麼把 \section{我的看法} 這一行的 \section 故意打錯，改成 \secton（少一個 i），按 Recompile。

    應該看到Recompile 旁邊出現紅色的數字。點它（或 Logs and output files 圖示），第一個錯誤寫著 Undefined control sequence（看不懂的指令），旁邊有行號，就是你改壞的那一行。右邊的 PDF 可能還停在上一次成功的樣子。

  2. 做什麼照行號找回去，把 \secton 改回 \section，再 Recompile。

    應該看到紅色數字消失，PDF 恢復正常。

學到的事：錯誤訊息是文字、有行號。有好幾個錯誤時先看第一個，後面常常是被它連帶出來的。行號是線索，不一定剛好就是錯的那一行（例如少一個 }，常常到後面幾行才報錯），找不到就往前看你最近改過的地方。
1-7

加一筆引用

  1. 做什麼左側檔案區最上面有一排小圖示，按第一個 New file（一張紙的圖示），檔名填 refs.bib，按 Create。然後複製下面這一筆，貼進這個新檔案。

    % 這一筆書目是用 DOI 向 doi.org 取回來的（2026-11-16），代號 Su2021 是自己取的。
@article{Su2021,
  author = {Su, Hsin-Feng and Koo, Malcolm and Lee, Wen-Li and Sung, Huei-Chuan and Lee, Ru-Ping and Liu, Wen-I},
  title = {A dementia care training using mobile e-learning with mentoring support for home care workers: a controlled study},
  journal = {BMC Geriatrics},
  year = {2021},
  volume = {21},
  number = {1},
  doi = {10.1186/s12877-021-02075-3}
}

    應該看到左側有兩個檔在同一層：main.tex、refs.bib。refs.bib 裡那一筆開頭是 @article{Su2021,，Su2021 就是這筆的代號。

  2. 做什麼回到 main.tex 最下面，找到三行開頭有 % 的：…研究 \cite{Su2021}。、\bibliographystyle{plain}、\bibliography{refs}。把這三行開頭的 % 拿掉（寫著「做到加一筆引用那一步時…」的兩行說明留著不動）。

  3. 做什麼Recompile。

    應該看到正文出現 [1]，文末多一節參考文獻，裡面一筆 BMC Geriatrics 2021 年的文章。看到 [?] 就再按一次 Recompile。證據 ① 截這一頁（要看得到你的題目和 [1]）。

1-8

有圖有表的一頁

  1. 做什麼在同一個專案（或新開一個 Blank Project），左側按 Upload，上傳起始包裡的三個檔：report-demo.tex、figure-demo.png、refs.bib（已經有 refs.bib 就不用再傳）。

    應該看到左側檔案區同一層有這三個檔。

  2. 做什麼二選一：Menu → Main document 選 report-demo.tex；或打開 report-demo.tex 全選複製，貼進 main.tex。Compiler 一樣是 XeLaTeX，按 Recompile。

    應該看到一頁 PDF：有「圖 1」的折線圖、「表 1」的表格、正文有 [1]、文末有參考文獻。

  3. 做什麼（裝好 gnuplot 之後再回來做）把你自己用 gnuplot 畫出的 figure-demo.png 上傳，蓋掉原本那張，Recompile。

    應該看到PDF 裡的圖換成你畫的那張，原稿一個字都沒改。

表格那幾行在做什麼（tabular）

在 report-demo.tex 裡找 \begin{tabular}，表格就寫在它和 \end{tabular} 中間：

  • &：分欄。一列裡每個 & 隔開一格。
  • \\：換到下一列。
  • \hline：畫一條橫線。

外面包一層 table 環境、加 \caption{…}，PDF 上就自動編成「表 1」。

2-2 · 老師用手示範，你先看

三張工具卡

老師先用手把三張卡各做一次，你看就好。等一下裝好工具（2-3），再照卡片自己做一次（2-4）。做完 gnuplot 卡，可以回 1-8 把自己的圖換進報告。

gnuplot

寫論文時它管哪一段：圖。

用手做一次：先在起始包的資料夾裡開一個終端機（terminal，用打字下指令的視窗）：

  • Windows 11：打開解壓縮後的資料夾（要看得到 figure-data.dat；「解壓縮全部」常會多包一層同名資料夾，再點進去一層），在空白處按右鍵 →「在終端機中開啟」。
  • Mac：打開「終端機」，輸入 cd 加一個空白，再把那個資料夾從 Finder 拖進終端機視窗，按 Enter。

再一條一條複製貼上、按 Enter：

  1. gnuplot --version

    應該看到一行 gnuplot 加版本號。Windows 說找不到 gnuplot：把終端機關掉重開；還是找不到，回 Antigravity 請它照指引把 gnuplot 加進 PATH。

  2. gnuplot -e "set terminal dumb size 60,15; plot 'figure-data.dat' using 1:2 with lines title 'Group A'"

    應該看到終端機裡直接出現一張用字元畫的折線圖，一路往下降。這是最快看到結果的方法，不會產生檔案。

  3. gnuplot figure-demo.gp

    應該看到資料夾多出 figure-demo.png，打開是兩條折線（Group A、Group B）。

  4. gnuplot figure-bar.gp

    應該看到多出 figure-bar.png，同一份資料變成長條圖。

  5. 做什麼用記事本打開 figure-data.dat，改最後一列的數字、存檔，再跑一次第 3 條。

    應該看到圖跟著變了。

出現 warning: iconv failed to convert degree sign 可以忽略，圖照樣會產生。

什麼時候值得用：資料會一直改、同一張圖要重畫好幾次的時候。

Zotero

寫論文時它管哪一段：參考文獻。看到一篇要引用的論文，按一下就收進文獻庫；要寫報告時再匯出書目檔。

先裝 Chrome 外掛（Zotero Connector）：它是 Chrome 工具列上的一顆「存進 Zotero」按鈕。

  1. 做什麼先把 Zotero 桌面版打開，放著不要關。

    應該看到Zotero 視窗，左邊有「我的文獻庫」。

  2. 做什麼用 Chrome 打開 zotero.org/download。右半邊是 Zotero Connector，按 Install Chrome Connector；跳到 Chrome 線上應用程式商店後按「加到 Chrome」，再按「新增擴充功能」。

    應該看到Chrome 右上角的拼圖圖示（擴充功能）裡多了 Zotero Connector。按它旁邊的圖釘，把它固定在工具列上。

用手做一次：從網頁把論文收進來。

  1. 做什麼用 Chrome 打開這篇論文的網頁：

    https://doi.org/10.1186/s12877-021-02075-3

    應該看到BMC Geriatrics 期刊的一篇論文頁面，2021 年，第一作者 Su。

  2. 做什麼按工具列上的 Zotero Connector 按鈕。

    應該看到右上角跳出一個小框，寫著正在存到「我的文獻庫」。回到 Zotero，多了一筆這篇論文，題名、作者、期刊、年份都填好了。

  3. 做什麼在 Zotero 裡對那一筆按右鍵 → 匯出項目…（英文介面是 Export Item…），格式選 BibTeX，存檔。

    應該看到得到一個 .bib 檔。用記事本打開，跟起始包的 refs.bib 是同一種檔：@article{代號, 開頭，接著作者、題名、期刊。

外掛按了沒反應：多半是 Zotero 桌面版沒開。另一個收文獻的方法：Zotero 工具列的魔術棒圖示「依識別碼新增」，貼上 10.1186/s12877-021-02075-3 按 Enter。

什麼時候值得用：報告的文獻超過三篇、要一直增減的時候。

本機版 LaTeX 選做

寫論文時它管哪一段：排版。跟 Overleaf 是同一件事，只是裝在自己電腦。

用手做一次：裝好後在終端機打：

xelatex --version

應該看到版本號。

再 cd 進起始包資料夾，四行依序打：

xelatex report-demo
bibtex report-demo
xelatex report-demo
xelatex report-demo

應該看到資料夾多出 report-demo.pdf，跟 Overleaf 編出來的一樣。第一次編譯中文會很慢，是在下載缺的套件，不是當機。更多說明在上週的 論文工具箱。

什麼時候值得用：沒網路也要寫，或不想把稿子放雲端的時候。有 Overleaf 就夠用。

2-3 · 自己的筆電

請 Antigravity 替你安裝

用教室電腦的同學先看 2-5。

起始包裡有一份 AGENT-GUIDE.md，是老師寫給 AI agent 讀的安裝指引。你不用自己記安裝步驟，只要讓 Antigravity 讀這份指引、照著做，你負責看計畫、回「可以」、按它按不到的視窗。

  1. 做什麼打開 Antigravity，用它開啟起始包解壓縮後的那個資料夾（裡面要看得到 AGENT-GUIDE.md）。

    應該看到Antigravity 左側的檔案清單裡有 AGENT-GUIDE.md、figure-data.dat 這些檔。

  2. 做什麼在對話框貼上這一句，送出：

    請讀這個資料夾裡的 AGENT-GUIDE.md，照它替我安裝 gnuplot 和 Zotero，再畫出兩張圖。先給我計畫，我回「可以」你再動手。

    應該看到它沒有馬上動手，而是先列計畫：它判斷你的電腦是 Windows 還是 Mac、會跑哪幾條指令、裝到哪裡、大概占多少空間。

  3. 做什麼把計畫讀一遍。看得懂、沒有奇怪的下載網址，就回它：

    可以

    應該看到它開始一樣一樣裝，每裝完一樣就跑版本指令給你看。

  4. 做什麼看著它裝。Windows 會跳「使用者帳戶控制」視窗問你要不要允許，agent 看不到這個視窗，你來按「是」（視窗沒跳到最前面時，看工作列有沒有閃爍的盾牌圖示）。Mac 若問電腦登入密碼，也是你自己打，不要把密碼告訴 agent。

  5. 做什麼等它做完。

    應該看到最後它給你一張表：裝了什麼、版本、裝在哪、怎麼移除；資料夾裡多了 figure-demo.png 和 figure-bar.png 兩張圖。

它沒給計畫就開始裝？按停止，回它：「先停。照 AGENT-GUIDE.md 的規則，先只給計畫，我說可以再動手。」這不是它壞掉，是你在練「退回一次」。

指引裡寫給 agent 的六條規則，各自在防什麼（想看原文就打開 AGENT-GUIDE.md，它是一般的文字檔）：

規則在防什麼
先給計畫，你說可以才動手防它一口氣做完你才發現不對。你看過、說「可以」，主控權在你。
只用 winget（Windows）或 Homebrew（Mac）裝防它從來路不明的網站下載安裝檔。
一次裝一樣、裝完就驗證防它說「都裝好了」其實有一樣沒成功。
要密碼或要按同意就停按同意、打密碼是你的事。agent 不需要知道你的密碼。
出錯就停、給錯誤原文防它自己換來源一直試，越試越亂。錯誤原文你可以拿去問老師。
只動這次要裝的東西防它順手升級或移除你電腦上其他軟體。

想裝本機版 LaTeX（選做）：前兩樣裝完之後，再跟它說「我要裝本機版 LaTeX，照 AGENT-GUIDE.md 最後一節做」。檔案很大，課堂上網路慢就回家再裝；Mac 今天先用 Overleaf。

Overleaf／LaTeX

看到什麼通常是怎麼處理
中文變成方框、空白或缺字Compiler 不是 XeLaTeXMenu → Settings → Compiler 改 XeLaTeX，再 Recompile
一大堆紅字，第一個跟中文或 xeCJK 有關Compiler 沒切 XeLaTeX同上，先切 XeLaTeX
正文出現 [?]書目還沒跑完，或 \cite{…} 的代號跟 refs.bib 對不上再 Recompile 一次；還是一樣就核對 \cite{Su2021} 和 refs.bib 裡的代號
文末沒有參考文獻1-7 那三行的 % 沒拿乾淨，或 refs.bib 檔名不對檢查三行開頭都沒有 %；左側檔名是 refs.bib，跟 \bibliography{refs} 對得上
File 'figure-demo.png' not found 之類檔案沒上傳，或檔名大小寫不同看左側檔案區有沒有那個檔；名字要跟原稿裡寫的一模一樣
Overleaf 說編譯逾時（timed out）伺服器忙，或原稿有地方卡住再按一次 Recompile；還是逾時就把最近改的那幾行先改回來

安裝

看到什麼通常是怎麼處理
agent 沒給計畫就開始動手它跳過了「先給計畫」按停止，回它「先停。照 AGENT-GUIDE.md，先只給計畫，我說可以再動手」
winget 或 brew 說找不到套件套件名稱不對請它跑 winget search gnuplot／brew search gnuplot 看正確名稱；還是找不到就照 論文工具箱 手動裝
