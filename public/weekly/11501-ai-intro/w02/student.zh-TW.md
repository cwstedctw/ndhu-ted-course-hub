## 今天的活動需求

這是一場**虛構的校園換書活動**，不是實際公告，也沒有預約場地或取得校方背書。讀者是包含外籍生在內的新生。做一張直式海報，邀請他們「帶一本，換一本」。

| 項目 | 固定資訊 |
| --- | --- |
| 標題 | BOOK SWAP |
| 日期 | 22 SEPT 2026 |
| 時間 | 16:30 |
| 地點 | LIBRARY LOBBY（圖書館大廳） |
| 參與方式 | BRING ONE BOOK, TAKE ONE BOOK |
| 性質 | FICTIONAL EVENT / CLASS EXERCISE |

可以改色調、插畫、標語與版面。活動事實不能自行改，不加校徽、真人、贊助商、校方背書或報名連結。

## 五個停靠點

1. 看示範 A／B，選一張並指出一個細節。
2. 做第一版 v0，留下提示與圖像。
3. 找一個問題、改一項要求，保存 v1，再比一次。
4. 換成你想邀請的讀者，做一個自己的修改，請同學檢查。
5. 完成 E1：採用／修改／拒絕、證據、理由、下一步。

## 動手：做第一版

先開 [Gemini](https://gemini.google.com/)，找側欄 Images／圖像或當下可用的生圖入口，貼上這段提示（prompt）。介面名稱以你帳號顯示為準。參考 [Google 生圖與編輯說明](https://support.google.com/gemini/answer/14286560)，查核日 2026-09-10。

```
請做一張直式的「虛構校園換書活動」海報，給包含外籍生在內的新生看。用暖白紙色、珊瑚色與書本插畫，活動資訊要在手機上讀得清楚。
以下資訊請原樣保留：BOOK SWAP；22 SEPT 2026；16:30；LIBRARY LOBBY；BRING ONE BOOK, TAKE ONE BOOK。
不要加入校徽、校方背書、真人、贊助商或報名連結。標明 FICTIONAL EVENT / CLASS EXERCISE。資訊不足請先問，不要自行補寫。
```

生圖後下載或截圖，另存為 v0，也保存你實際送出的提示。不要只留聊天最後一句「完成了」。如果你加了自己的條件，記下加了什麼。

**不必付費。** 官方列有無 AI 訂閱的圖像功能，但額度與開放條件會變；本課不保證每人固定幾張。個人帳號生圖與編輯的年齡條件不同，編輯需滿 18 歲；學校帳號可能另有管理員限制。遇到登入、年齡、額度或功能受阻，直接走下一節，不需刷卡或規避限制。[官方額度](https://support.google.com/gemini/answer/16275805) · [登入條件](https://support.google.com/gemini/answer/13278668)，2026-09-10 查核。

本週只輸入上述虛構內容。不貼學生資料、私人照片或未授權的素材。Gemini 的資料使用受設定與帳號類型影響；關閉活動紀錄不等於資料完全不會被處理。[官方隱私說明](https://support.google.com/gemini/answer/13594961)，2026-09-10 查核。

## 帳號或裝置受阻時

開啟 [離線工作室](studio-ab.html)，選 A 作原版，先按「存原版」，再修改海報欄位，按「存修正版」與「存修改紀錄」。下載後確認有 v0、v1 與紀錄檔。這些檔不會自動送交老師。

A、B、C 是這份教材繪製的 **SVG 教學模擬圖**，不是 Gemini 實跑紀錄、不是活動照片。A 的時間為 18:30；B 改為 16:30；C 加了未授權的「OFFICIAL NDHU EVENT」。你的判斷與修改仍須自己完成，來源請寫「教學模擬圖＋我的修改」。

沒有筆電時，與同學共用畫面或使用老師印出的 A／B／C。在紙上圈出細節、寫修改指令、畫修正版，完成相同的 E1。帳號受阻不扣分，不需要事後補跑 AI。

## 檢查，再修一件事

把自己的圖與固定資訊並排。看時間、地點是否一致；把畫面縮到手機寬度，確認關鍵文字能讀；找有沒有自行添加的背書或報名連結。圈出或截圖一個實際問題。

如果時間真的錯了，可以這樣要求修改：

```
保留原本版面與其他內容，只把活動時間改為 16:30。不要新增資訊。
```

如果你的時間本來就對，請改成你實際看到的問題。第一版沒有發現錯誤時，記錄一項通過的檢查，再提出一個適合讀者的改善；不要為了寫卡片捏造失敗。

保存 v1 後，再看修改是否真的發生、其他資訊是否被動到。還沒修好，就記下剩餘問題，決定再問一次或手動修改。用簡報的文字方塊覆蓋錯字也可以，請保留原版並說明這是人的修改。

## 做成你的版本

回到剛才使用的工具或離線工作室分頁，接著自己的 v1 修改。這一步不要重開工作室，新分頁會從素材 A 開始。Gemini 請回到原圖的對話；需要時在 Library／圖庫找到原圖，再選 Chat。保留 BOOK SWAP 標題，改完再保存修正版圖像並更新修改紀錄。

選一種更具體的讀者，例如剛入學的外籍生或喜歡漫畫的讀者。改標語、色調或視覺重點中的一項，保留日期、時間、地點與活動性質。避免用刻板印象替讀者下定義。

請同學用這句話回饋：「在＿＿，我看到＿＿，讀者可能＿＿。」他要能指到圖像上的位置；你可以接受建議，也可以說明不採用的理由。

## E1：你的判斷

[空白 E1 卡](e1-ab.html) 可直接打字後列印／另存 PDF，也可印出手寫。頁面不會自動保存或送出。

填入：你檢查的版本、採用／修改／拒絕、一個具體細節及其位置、它為何影響需求或讀者、下一步與檢查方式、素材／工具與人的修改。

採用、修改、拒絕都可以，重點是理由有依據。**E1 當堂完成、當堂繳交**；繳交方式依老師課堂與 e學苑公告。本週不另加配分、額外截止日或公開發布要求。
