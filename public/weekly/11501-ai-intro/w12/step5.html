Tool calls are covered only on this page and on the official Stage 5 page; the video and the notebook don't include them. 工具呼叫（tool call）只在這一頁與官方第 5 頁談，短片與筆記本沒有。

Answering questions well comes from post-training plus the chat template, not from the markers alone. 能回答問題靠的是後訓練（post-training）加上對話範本，不是只靠記號。

In a real chat, your message is first wrapped in the chat template with turn markers such as <|turn> (ID 105) and <turn|> (ID 106). 真的聊天裡，訊息會先被包進對話範本，用 <|turn>（105）和 <turn|>（106）這類記號分段。

Real output from the Gemma 4 chat template, run in Colab on 2026-11-23

Asking “What is Hualien famous for?” turns into this one long text before Step 1 starts (it ends with a line break after <|turn>model): 問一句話，送進模型之前先變成這一長串（最後在 <|turn>model 後面有一個換行）：

<bos><|turn>user
What is Hualien famous for?<turn|>
<|turn>model

The model's answer is written after <|turn>model, one piece at a time, until it writes the end mark. 模型的回答從 <|turn>model 後面開始，一塊一塊寫，直到寫出結束記號。

2Guess first

先猜

When the model “thinks”, is it a different brain or the same next-token loop?

模型在「思考」的時候，是換了一顆腦，還是同一個猜下一個字的迴圈？

Write your guess on paper, then open the answer. 先猜再點開

The same loop. Thinking notes are ordinary tokens the model writes between <|channel>thought and <channel|>; thinking mode is switched on by <|think|> in the system turn (from the guide). 同一個迴圈；思考內容只是寫在 <|channel>thought 和 <channel|> 之間的一般 token，思考模式由放在 system turn 的 <|think|> 開啟。

▶Short video

看短片

Transcript 逐幕文字（English narration + 中文字幕）

  1. If Gemma 4 only guesses the next word, why does it answer your question instead of writing another question?

    模型只會接下一個字，為什麼會回答你而不是反問你？

  2. Think of labeled envelopes: each envelope names who is speaking and where their turn stops. This fixed wrapper is a chat template.

    想成寫好發言者的信封，這套固定包裝格式叫對話範本。

  3. Each envelope uses reserved markers called special control tokens. Gemma 4 opens a turn with token 105 and seals it with 106.

    信封靠特殊控制記號：105 開啟一輪，106 封口。

  4. Seeing the open model envelope, the model then writes its reply, one token at a time, stopping once it outputs token 106.

    看到模型信封打開，就一字一字往下接，這個例子寫出 106 號記號就停。

  5. Put token 98 in the system envelope, and Gemma 4 writes a draft in the thought channel first. That reasoning space is called thinking mode.

    系統信封加上 98 號記號，模型會先寫草稿，這叫思考模式。

  6. Even thinking uses the exact same loop. Every draft word feeds back in, so later attention layers can check earlier steps before answering.

    思考用的也是同一套迴圈：先寫出草稿，後面再回頭檢查。

  7. So chat is post-training plus labeled envelopes, with five stations guessing one token at a time.

    所以聊天＝經過後訓練的模型，加上貼好標籤的信封，一次猜一個 token

More detail: where the prompt ends and when the loop stops 細節：提示停在哪、迴圈何時停

The guide says the prompt handed to the model ends at <|turn>model plus a line break. With standard token-by-token generation, writing 20 tokens takes about 20 runs. This example stops at <turn|> (106); generation can also stop at <eos> (1).

導覽說交給模型的提示停在 <|turn>model 加一個換行。標準的逐 token 生成寫 20 個 token 約跑 20 次。這個例子停在 <turn|>（106），一般也可能停在 <eos>（1）。

⑤ The loop: one token at a time (Stages 4–5)

Scripted — choices and chances are made up

Each press of Step is one full run of the model. It guesses, picks one piece, and that piece is fed back onto the end of the input for the next run. This is the autoregressive loop. (A real chat would also wrap the input in the chat template; we skip that to keep it short.)

每按一次 Step＝模型完整跑一次：猜、挑一塊、把那一塊接回輸入尾巴，下一次再跑。這就是自迴歸迴圈。
