  1. Wrong name tag, exit code 0 (0 = the program says “no complaint”): it printed not found, then did the whole job as the leader.名牌叫錯，exit code 仍是 0（0＝程式說「沒意見」）：印了 not found，然後用領隊名牌把事做完。
