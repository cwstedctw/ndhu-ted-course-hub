課前：申請環境部的金鑰（API key）

點陣要捲的空氣品質資料來自環境部，要帶自己的金鑰才拿得到。金鑰（API key）就像一張借書證：每次跟環境部要資料都要出示，對方才知道是誰在要、今天要了幾次。

先知道內容
要錢嗎不用，註冊免費
能用多久一年；到期後 log 會出現「該 API KEY 不存在或是已經到期。」，再申請一把
一天能用幾次每把金鑰、每個 API 每天 5,000 次。我們的程式 10 分鐘才問一次，一天最多用 144 次，很夠
金鑰長什麼樣一串英文字母和數字，中間有 4 個減號，像 xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx，共 36 個字元。貼的時候要整串，少一截就不能用
寄到哪註冊時填的電子郵件信箱。官方說明只寫「請妥善保存信件中的 API 金鑰」，沒寫信不見了怎麼在網站上重查，所以信一定要留好
  1. 打開環境部環境資料開放平臺的「API介接服務條款」頁：https://data.moenv.gov.tw/api-term（複製到瀏覽器網址列；從平臺首頁上方選單的「會員註冊」進去也是同一頁）。
  2. 讀完條款，勾選「我已閱讀上述說明，並將遵守上述規則使用平臺資料」，按「下一步」。
  3. 填會員資料。電子郵件填你收得到信的（學校信箱或自己常用的都可以），金鑰會寄到這裡。
  4. 收「註冊通知信」，API Key 就在信裡。找不到信，先看垃圾信匣、促銷或社交分類。
  5. 把信留著（加星號或標籤），上課第 5 節要用。

1　就位：接板子、開兩條通道、SSH 進板子

目標：電腦開好兩條通道，提示字元變成 arduino@ 開頭。

為什麼兩條？2222 讓你用 SSH 進板子打指令；7000 讓電腦的瀏覽器看得到板子上的網頁（第 2 節要用）。兩條都走 USB 線，不用知道板子的 IP。

  1. 接線、等心跳：USB-C 資料線把板子直接插在電腦上（中間不要經過 hub）。點陣從旋轉的圖案變成心跳動畫，通常 30～60 秒。還在轉就先等，不要拔。
  2. USB 看得到：打開終端機（Ctrl＋Alt＋T），打： 
    lsusb | grep -E '2341:0078|05c6:9008'
    正常要看到 2341:0078。看到 05c6:9008 是恢復模式：舉手叫老師，不要自己重刷。
  3. 找出 adb（App Lab 附的那個，不用另外裝）。前兩行是同一個指令（第一行最後的 \ 代表接到下一行），要一起貼： 
    ADB=$(find "$HOME/.arduino15/packages/arduino/tools/adb" \
    -type f -name adb -perm -u+x -print 2>/dev/null | sort -V | tail -n 1)
"$ADB" devices -l
    最後一行要列出剛好一塊板，狀態是 device。列出兩台以上，拔掉手機或別人的板子。$ADB 只在跑過這段的視窗裡有值，換視窗要重跑。
  4. 開兩條通道：在跑過上面那段的同一個視窗打。成功時不印任何字： 
    "$ADB" forward tcp:2222 tcp:22
"$ADB" forward tcp:7000 tcp:7000
  5. SSH 進板子： 
    ssh -p 2222 arduino@127.0.0.1
    第一次會問 Are you sure you want to continue connecting，打完整的 yes、按 Enter；再打板子的密碼（打的時候畫面不會動，打完按 Enter）。要打 127.0.0.1，不要打成英文的本機名稱，會連不上。

提示字元變成 arduino@… 開頭，就進到板子裡了。今天後面所有 arduino-app-cli 指令都在這個 SSH 視窗打。要回到電腦打指令（例如重開通道），另開一個終端機視窗，記得在新視窗重跑第 3 步。

卡住了：連不上、找不到 adb、SSH 門壞了
  • bash: : command not found：$ADB 是空的，這個視窗沒跑過第 3 步，重跑一次。
  • Connection refused：2222 通道沒開。回到電腦、在跑過第 3 步的同一個視窗再打一次 forward；網址要打 127.0.0.1。
  • WARNING: REMOTE HOST IDENTIFICATION HAS CHANGED!：這台電腦記的是別塊板的鑰匙（換過座位、換過板都會）。叫老師，不要自己刪檔。
  • SSH 一直連不上，而且 W3／W4 沒修過 SSH：照 W4 學生頁第 6 節的摺疊「補鑰匙」做（出廠板的 SSH 鑰匙檔是空的）。
  • 忘了板子密碼：問老師，不要貼給 AI。
在家用自己的 Windows／Mac 的人（課後補做用）

先裝好 App Lab（adb 跟著它來），板子接上、等心跳。lsusb 是 Ubuntu 的，跳過。

2　網頁按一下，燈就變

目標：在電腦的瀏覽器替板上 4 顆 RGB 燈換顏色。

先跑官方範例〈Color your LEDs〉：板子自己開一個網頁，你在電腦上按，板子上的燈就變。先看到效果，再想程式怎麼做到的。

  1. 找範例的 ID： 
    arduino-app-cli app list | grep -i color
    第一欄就是 ID，整串照抄你看到的： 
    examples:inspirational/color-your-leds
    出廠的板可能少了 inspirational/ 那一層，以你的畫面為準。下面的 <範例ID> 都換成這一串。
  2. 跑起來（第一次約 90 多秒，不要重按）： 
    arduino-app-cli app start <範例ID>
    <範例ID> 換成剛才 app list 第一欄那一整串（直接複製貼上，不要留 < >），例如 examples:inspirational/color-your-leds。最後一行是 ✓ App "…" started successfully 才算起來了。
  3. 等 10 秒，開瀏覽器：在電腦的瀏覽器網址列打 http://127.0.0.1:7000。打不開就重新整理一次。
  4. 玩一下：網頁上有四張卡——LED 1、2、4 各有 7 個固定色塊和一個開關；LED 3 不一樣，有一個色碼框，點下去是整片調色盤。

✋ 先猜：哪一顆燈能調亮度？猜完，替 LED 3 挑一個暗一點的顏色、再挑一個亮的，看板上那顆燈。

揭曉：誰管哪顆燈
燈誰管程式裡的關鍵字所以
1、2 號Linux（Python 直接管）Leds.set_led1_color(r != 0, …)每個顏色只有開／關
3 號MCU：Python 用 Bridge.call("set_led3_color", …) 請它做analogWrite可以調亮度
4 號MCU：同上digitalWrite只有開關，LOW 才亮

Bridge 是兩顆腦之間傳話的橋：MCU 先用 Bridge.provide("set_led3_color", …) 登記「有人叫這個名字，我就做這件事」；Linux 用 Bridge.call 叫它。LED 1 就是上週你用 echo 1 > 點亮的那顆——上週你自己寫檔點它，這週換 Python 幫你點。

grep -n -E "set_led|analogWrite|digitalWrite" ~/ArduinoApps/my-color/python/main.py ~/ArduinoApps/my-color/sketch/sketch.ino
  1. 收掉（一次只能跑一支 App；<範例ID> 跟上面 start 用的是同一串）： 
    arduino-app-cli app stop <範例ID>
卡住了：找不到範例、網頁打不開
  • grep 什麼都沒印：你的板子可能沒有這支範例。舉手，老師示範，先看鄰座的。
  • 瀏覽器打不開：先等 10 秒、重新整理。再查三件：①forward tcp:7000 要在電腦打（第 1 節）②App 還在跑嗎 ③網址是 127.0.0.1。還不行，看它的 log 有沒有 Local URL 那行：

    log 上的網址是「從板子自己看」的寫法，電腦上照樣打 127.0.0.1:7000；另一行帶著板子的 IP，不用抄、不要截進作業。

3　板子上網了嗎＋時區

目標：確認板子上得了網，跟開放資料（open data）要一筆；把板子的時鐘改成台灣時間。

開放資料是公開給大家取用的資料。等一下 Linux 要上網拿 AQI，所以先確認網路通；時區沒設，log 上的每一筆時間都會差 8 小時。

  1. 看 Wi-Fi： 
    nmcli -t -f DEVICE,STATE,CONNECTION dev status
    wlan0:connected:<Wi-Fi 名稱>
    第一行是 connected 就是連上了。不是的話，用老師現場給的 Wi-Fi 名稱連（會問密碼，一樣老師現場給，這一頁不印）： 
    nmcli --ask dev wifi connect "<Wi-Fi 名稱>"
    ⚠️ 這一行只驗過權限（板上的 arduino 帳號不用 sudo 就能連），還沒在教室真的換過網路。不行就叫老師。
  2. 直接跟開放資料要一筆（open-meteo 的 API，不用金鑰；網址裡有 &，所以整串用雙引號包住）： 
    curl -fsS "https://air-quality-api.open-meteo.com/v1/air-quality?latitude=23.97694&longitude=121.60444&current=us_aqi,pm2_5&timezone=Asia%2FTaipei"
    回來的是一長串 JSON（一種「名字:值」成對寫的資料格式），找最後面這一段： 
    "current":{"time":"2026-10-02T14:00","interval":3600,"us_aqi":58,"pm2_5":7.2}
    把你看到的 us_aqi 數字記下來，第 7 節要跟環境部的比。印出 curl: 開頭的錯誤＝沒拿到，先回上一步看 Wi-Fi。
  3. 時區：板子的時鐘差了 8 小時。先看： 
    date
timedatectl
    date 印的最後是 … AM UTC 2026；timedatectl 有一行 Time zone: Etc/UTC (UTC, +0000)（另一行 RTC time 是 1970 年：板子沒有電池時鐘，開機靠網路對時）。改成台灣： 
    sudo timedatectl set-timezone Asia/Taipei
date
    這裡的 sudo 要打板子的密碼（不是教室電腦的），打的時候畫面不會動。教室電腦一樣不准自己用 sudo。忘了板子密碼就跳過這一步，不影響後面。
卡住了：curl 錯誤、sudo 密碼錯
  • curl: 開頭的錯誤：先看 Wi-Fi；Wi-Fi 是好的還不行，可能是教室網路擋住了，舉手。
  • sudo 一直說密碼錯：要打的是板子的密碼（W3 修 SSH 用過那組），不是教室電腦的。

4　天氣範例：這次換 MCU 發問

目標：跑官方天氣範例，log 出現 Hualien，點陣播天氣動畫。

方向跟第 2 節相反：MCU 問「這個城市天氣怎樣」，Linux 上網問完再回答，MCU 依答案在點陣上播動畫。同一座 Bridge，方向反過來。

  1. 找 ID、抄一份來改： 
    arduino-app-cli app list | grep -i weather
arduino-app-cli app new my-weather --from-app <範例ID>
    <範例ID> 換成第一行看到的 weather 那一串（整串照抄）。成功的最後一行： 
    App created successfully: /home/arduino/ArduinoApps/my-weather (ok)
  2. 改成花蓮：城市寫在 sketch/sketch.ino 第 10 行 String city = "Turin";。一行改完，不必開編輯器： 
    cd ~/ArduinoApps/my-weather
sed -i 's/"Turin"/"Hualien"/' sketch/sketch.ino
grep -n Hualien sketch/sketch.ino
    最後一行要印出第 10 行，裡面變成 "Hualien"。什麼都沒印＝沒改到（引號、大小寫要一字不差）。
  3. 跑起來（第一次約 100 秒）： 
    arduino-app-cli app start ~/ArduinoApps/my-weather
    等的這 100 秒：讀設計文件 §1、§2，看資料怎麼在兩顆腦之間走。還沒申請環境部金鑰的，趁現在用手機申請。
  4. 看 log（看到 ✓ App "my-weather" started successfully 再打）： 
    arduino-app-cli app logs ~/ArduinoApps/my-weather --tail 5
    [main] Weather forecast for Hualien: Drizzle, not freezing, continuous
    天氣每天不一樣，後半段的字會不同。再看板子：點陣依天氣分類播動畫。截一張 log 的圖（證據 1）。
  5. 看到動畫，馬上停： 
    arduino-app-cli app stop ~/ArduinoApps/my-weather
    為什麼要馬上停？這支範例播完一輪就再問一次（約 12 秒一次），每問一次打 2 個 API。全班 26 塊一起問，約每分鐘 260 次，約 19 分鐘就用光 open-meteo 免費額度的每小時 5,000 次——那之後全班都拿不到資料。
有餘力：在程式裡找「誰問、誰答」 
grep -n Bridge sketch/sketch.ino python/main.py
  • sketch/sketch.ino（MCU）：Bridge.call("get_weather_forecast", city).result(weather_forecast)——MCU 問。
  • python/main.py（Linux）：Bridge.provide("get_weather_forecast", get_weather_forecast)——Linux 答。
卡住了：sed 沒改到、紅字、全班拿不到天氣
  • grep -n Hualien 什麼都沒印：引號、大小寫要一字不差 "Turin"，重打一次 sed。
  • app start 印出紅字（例如 verify failed … 或 Stopped decode loop: EOF）：先看最後一行，有 started successfully 就沒事。
  • Stat /Data/Local/Tmp：你在 adb shell 裡跑了 app start。改用 SSH 視窗；非用 adb 不可，先打 export TMPDIR=/tmp。
  • 全班都拿不到天氣：額度可能被用光。確認大家都 app stop 了，先看鄰座已截到的 log。

cat > python/main.py <<'EOF'
# W5 花蓮 AQI 跑馬燈：Linux 這半——跟環境部開放資料要花蓮測站的 AQI，整理成一行字，交給 MCU 捲動
import json
import pathlib
import ssl
import time
import urllib.parse
import urllib.request

from arduino.app_utils import *

SITE = "花蓮"  # 環境部測站名稱
LABEL = "HUALIEN"  # 點陣只認得英文字母和數字
CACHE_SECONDS = 600  # 10 分鐘內只問一次：測站每小時才更新，金鑰每天也有次數上限
RETRY_SECONDS = 60  # 沒拿到資料時，1 分鐘後再試
KEY_FILE = pathlib.Path(__file__).with_name("moenv_key.txt")  # 金鑰放檔案，不寫進程式

# 環境部網站的憑證少了一個新版 Python 預設要查的欄位；只放寬這一項，憑證和網址照樣驗證
SSL_CTX = ssl.create_default_context()
SSL_CTX.verify_flags &= ~ssl.VERIFY_X509_STRICT

last_text = "WAIT"
last_fetch = 0.0


def fetch_aqi() -> str:
    key = KEY_FILE.read_text().strip()
    query = urllib.parse.urlencode({"api_key": key, "format": "JSON", "filters": f"sitename,EQ,{SITE}"})
    url = "https://data.moenv.gov.tw/api/v2/aqx_p_432?" + query
    with urllib.request.urlopen(url, timeout=15, context=SSL_CTX) as r:
        body = r.read().decode("utf-8")
    try:
        records = json.loads(body)
    except ValueError:
        print("moenv says:", body[:60])  # 金鑰打錯、或今天的次數用完了
        return "KEY?"
    if not records:
        print("no such site:", SITE)
        return "NO SITE"
    rec = records[0]
    print("moenv:", rec["publishtime"], rec["sitename"], "AQI", rec["aqi"], rec["status"])
    return f"{LABEL} AQI {rec['aqi'] or '--'} PM2.5 {rec['pm2.5'] or '--'}"


def get_aqi_text() -> str:
    global last_text, last_fetch
    now = time.time()
    if now - last_fetch < CACHE_SECONDS:
        print("cache:", last_text)
        return last_text
    last_fetch = now
    try:
        last_text = fetch_aqi()
    except FileNotFoundError:
        last_text = "NO KEY"
        print("no key file:", KEY_FILE.name)
    except Exception as e:
        last_text = "NO DATA"
        print("fetch failed:", type(e).__name__)
    if not last_text.startswith(LABEL):  # 沒拿到資料：不等 10 分鐘，1 分鐘後再試
        last_fetch = now - CACHE_SECONDS + RETRY_SECONDS
    return last_text


Bridge.provide("get_aqi_text", get_aqi_text)

App.run()
EOF

③ 存金鑰：放檔案，不寫進程式

打開環境部的「註冊通知信」，複製裡面的 API Key。在板子上打這一行，出現 API Key: 之後貼上金鑰、按 Enter：

read -rsp "API Key: " K; echo "$K" > python/moenv_key.txt; unset K; echo

貼上的時候畫面不會顯示（跟打密碼一樣），金鑰也不會留在指令歷史裡。確認檔案有內容（只印 OK，不會印出金鑰）：

test -s python/moenv_key.txt && echo "key file OK"

為什麼放檔案？寫進程式的話，程式一分享、一上傳，金鑰就跟著外流。main.py 只讀這個檔，不會把金鑰印出來。這個檔不截圖、不上傳、不貼給 AI，也不要用 cat 把它印到畫面上。

為什麼放在 python/ 裡、跟 main.py 同一層？main.py 是在容器裡跑的，容器只看得到這支 App 的資料夾（下一節 5＋ 會講）。放在家目錄或別的地方，容器裡的程式就找不到，點陣會顯示 NO KEY。

以後別支 App 也要用這把金鑰

cp ~/ArduinoApps/my-aqi/python/moenv_key.txt ~/ArduinoApps/<App 名>/python/

5＋　App 的 Python 跑在容器裡：numpy、pandas 怎麼裝

目標：說得出 main.py 在哪裡跑，會用 requirements.txt 幫自己的 App 加套件（以 numpy、pandas 為例）。

今天的 AQI 程式只用 Python 內建的模組（json、urllib…），所以什麼都不用裝。之後要整理表格、算平均、看趨勢，就會用到 numpy、pandas。這時候一定要先知道：套件要裝進 App 的容器，不是裝在板子上。

這一節是有餘力的延伸：點陣捲出 AQI 才是今天的成功線，沒做這節也算完成。⚠️ 這一節的指令是照 Arduino 官方原始碼寫的，還沒在出廠板上照抄跑過；畫面跟這裡寫的不一樣，以畫面為準，把完整錯誤訊息貼給 AI agent。

① 先搞清楚：同一塊板子，有兩個「Python 的家」

你 SSH 進去的是板子本身的 Linux。app start 的時候，App Lab 會另外開一個容器（container）來跑 main.py。容器像是板子裡隔出來的一個小房間：跟板子共用同一顆 Linux 核心（所以不是虛擬機），但有自己的檔案、自己的 Python、自己的套件。

板子本身（你的 SSH 視窗）App 的容器（main.py 住這裡）
怎麼進去ssh 進板子，提示字元 arduino@ 開頭不用進去：app start 自動建好、自動跑 main.py；app stop 就收掉
Python 是誰的板子的 Debian 系統附的Arduino 官方映像（image）python-apps-base 裡的 Python 3.13，已經裝好 arduino.app_utils 和一批常用套件
看得到哪些檔整台板子只有這支 App 的資料夾：板子上的 ~/ArduinoApps/my-aqi，在容器裡叫 /app
套件裝在哪板子的系統裡（今天不要動它）這支 App 自己的虛擬環境（virtual environment，venv）：~/ArduinoApps/my-aqi/.cache/.venv
誰在用你打的指令、agymain.py

所以：在 SSH 視窗打 pip install pandas，是裝到（或被擋在）板子本身，容器裡的 main.py 看不到，照樣出現 ModuleNotFoundError。金鑰檔要放在 python/ 裡，也是因為容器只看得到 App 的資料夾。

親眼看一下容器（App 要在跑）：

docker ps --format "{{.Names}}  {{.Image}}"

會列出正在跑的容器：名字是「App 資料夾名-main-1」（例：my-aqi-main-1），映像那欄看得到 python-apps-base。印出 permission denied 就跳過這步，不影響後面。

② 加套件：在 App 裡放一個 requirements.txt

requirements.txt 是 Python 的標準「購物清單」：一行寫一個套件名稱。把它放在 python/ 裡、跟 main.py 同一層，app start 的時候容器就會照清單，把套件裝進這支 App 的 venv（用的是 uv，一個比 pip 快的安裝工具）。

cd ~/ArduinoApps/my-aqi
printf "numpy\npandas\n" > python/requirements.txt
cat python/requirements.txt

cat 會印出兩行：numpy、pandas。接著重開 App，讓容器照清單安裝：

arduino-app-cli app stop ~/ArduinoApps/my-aqi
arduino-app-cli app start ~/ArduinoApps/my-aqi

這次 app start 會比平常久：容器要從網路上的 PyPI（Python 的套件倉庫）下載 pandas，全班同時下載會更慢。不要重按，等最後一行 started successfully。⚠️ 第一次要等多久，老師還沒在板子上計時。

numpy 其實已經內建在官方映像裡（麥克風、姿勢辨識那些積木要用），pandas 沒有。兩個都寫進清單比較保險：換一塊板子、換一版映像，照樣裝得起來。

③ 確認裝好了

用「容器裡、這支 App 的 venv 的 Python」試著 import 兩個套件，印出版本：

docker exec my-aqi-main-1 /app/.cache/.venv/bin/python -c "import numpy, pandas; print(numpy.__version__, pandas.__version__)"

印出兩個版本號就是裝好了。路徑一定要寫 /app/.cache/.venv/bin/python：只打 python 用的是映像本身的 Python，看不到你剛裝進 venv 的 pandas。

想在容器裡的 Python 玩一下（例如 import pandas as pd、建一個小表格），用互動模式進去，打 exit() 離開：

docker exec -it my-aqi-main-1 /app/.cache/.venv/bin/python

④ 安裝的規則（出問題時回來看）

  • 只有清單改了才會重裝。容器把上次裝過的清單記在 .cache/installed_requirements.txt；這次的 requirements.txt 跟它一模一樣，就印一行 Requirements already installed. 跳過，所以第二次起動又變快了。
  • 每支 App 各裝各的。my-aqi 裝了 pandas，my-weather 還是沒有；要用，就在那支 App 的 python/ 也放一份清單。
  • 檔名、位置要對：一定叫 requirements.txt、放在 python/ 裡。放在 App 最外層不會裝。
  • 想指定版本，照 pip 的寫法，一行一個，例如 pandas==<版本>。
  • 裝失敗，App 會起不來：套件名稱打錯、或教室網路連不到 PyPI，容器準備階段會印 App preparation failed。把 app start 和 app logs 的完整錯誤訊息貼給 AI agent；名稱拼對、網路好了，再 stop、start 一次。
  • 不要在 SSH 視窗用 sudo pip install 或 --break-system-packages 硬裝：那是裝進板子系統，App 照樣看不到，還可能弄壞板子自己的工具。AI 叫你這樣做，先給老師看。
卡住了：ModuleNotFoundError、permission denied、No such container
  • ModuleNotFoundError: No module named 'pandas'：①requirements.txt 不在 python/ 裡 ②改完清單沒有 stop、start ③你在 SSH 視窗直接跑了 python3 main.py（那是板子本身的 Python，不是容器）。
  • docker 說 permission denied：這個帳號沒有 docker 權限。跳過 docker 那幾行；之後在 main.py 用到 pandas 時，app logs 沒出現 ModuleNotFoundError 就是裝好了。
  • No such container：App 沒在跑，或容器名字不一樣。先用 ① 的 docker ps 看名字，把 my-aqi-main-1 換成你看到的。

想深入：容器跟虛擬機差在哪、隔離靠什麼 → 概念頁「兩顆腦地圖」的容器方塊；App 從建立到停止做了哪些事 → 設計文件 §4。

揭曉

一個是測站量到的，一個是模型算出來的，而且兩邊的 AQI 算法也不同（台灣環境部的 AQI 與美國的 US AQI），數字本來就對不上。資料要拿來做決定之前，先問清楚：誰量的、怎麼算的、多久更新一次。

金鑰也是一課：資料集頁上的公開金鑰全國一起用，每把每天 5,000 次，常常「今天用完」；自己的金鑰效期一年，寫進程式一分享就外流，所以放在檔案裡。
