1　就位（接線、等心跳）

電腦USB 看得到（要有 2341:0078）

lsusb | grep -E '2341:0078|05c6:9008'

電腦找 adb（兩行一起貼）、列出板子（要有 device）

ADB=$(find "$HOME/.arduino15/packages/arduino/tools/adb" \
    -type f -name adb -perm -u+x -print 2>/dev/null | sort -V | tail -n 1)
"$ADB" devices -l

電腦兩條通道（不印字）＋SSH（打 yes、板子密碼）

"$ADB" forward tcp:2222 tcp:22
"$ADB" forward tcp:7000 tcp:7000
ssh -p 2222 arduino@127.0.0.1

✅ 提示字元 arduino@ 開頭。以下都在 SSH 視窗打。

5　AQI 跑馬燈

板子空白 App＋換三個檔

arduino-app-cli app new my-aqi
cd ~/ArduinoApps/my-aqi
curl -fsSL https://cwstedctw.github.io/ndhu-ted-course-hub/weekly/11501-aiot/w05/starter/aqi/python/main.py -o python/main.py
curl -fsSL https://cwstedctw.github.io/ndhu-ted-course-hub/weekly/11501-aiot/w05/starter/aqi/sketch/sketch.ino -o sketch/sketch.ino
curl -fsSL https://cwstedctw.github.io/ndhu-ted-course-hub/weekly/11501-aiot/w05/starter/aqi/sketch/sketch.yaml -o sketch/sketch.yaml

板子存金鑰（出現 API Key: 貼上按 Enter，畫面不顯示）

read -rsp "API Key: " K; echo "$K" > python/moenv_key.txt; unset K; echo

板子啟動（約 110 秒）、清畫面、看 log

arduino-app-cli app start ~/ArduinoApps/my-aqi
clear
arduino-app-cli app logs ~/ArduinoApps/my-aqi --tail 60

📸 證據 2：同一張有 moenv: 和 cache:。📸 證據 3：點陣捲出 HUALIEN AQI …。

點陣上的字是什麼意思

  • WAIT：還沒拿到回覆，等一輪
  • NO KEY：沒有金鑰檔／放錯資料夾 → 再存一次
  • KEY?：金鑰錯、到期或今天用完 → 換金鑰
  • NO SITE：測站名錯（「臺」不是「台」）
  • NO DATA：連不到環境部 → 看 Wi-Fi

補好金鑰不用重開，1 分鐘內自己再試。
