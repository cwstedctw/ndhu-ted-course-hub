第二部分
UNO Q 連 ESP32 的基地台
ESP32 自己當基地台；連上後 UNO Q 離開原本網路，SSH 一律走 USB。
1起始檔先抓好：連上後板子沒有外網
2在 UNO Qnmcli device wifi list先看清單
3在 UNO Qnmcli device wifi connect maker-XXXX password makerXXXX
4回原網路nmcli connection up <原本的名字>
檢查點SSH 斷了？你用了 WiFi 的 IP，改 192.168.7.2

來回時間（RTT，一問一答來回的時間）每次都不一樣，所以看中位數。

讀一次感測值來回：中位數 … ms、最快 … ms、最慢 … ms、95% 在 … ms 內

第三部分
換一條線：藍牙
同一個大腦、同一份規則，只換連法；換線要真的重開 ESP32（按 EN）。
1在 ESP32按住 A 再按 EN，看到 OLED 顯示 BLE 才放開⚠️ 沒驗退路./tools/upload.sh d11_ble_remote
2在 UNO Qpython3 brain.py --link ble --name maker-XXXX
3按 A 鍵、加--seconds 60跑滿
練不用安裝：藍牙套件已在起始檔vendor/沒有 ESP32 時python3 brain.py --link ble-sim --esp 127.0.0.1:8090
檢查點OLED 第二行出現 maker-XXXX 才開始連
