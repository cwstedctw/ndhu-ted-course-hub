🆘 三個最常見的卡關

① SSH 斷線：用了 WiFi 的位址。改 ssh arduino@192.168.7.2；說鑰匙變了 → 教室機 ssh-keygen -R 192.168.7.2。

② ESP32 沒回應／連不上 ESP32：…：剛重開就等它自己接回；說要先連 WiFi → 照它下一行連、nmcli -t dev status 確認；名字跟 OLED 不同 → nmcli connection delete 那個名字；名字對但燈亂變 → 兩台搶，請上一位 Ctrl＋C 並 delete。

③ 藍牙 掃不到 maker-XXXX：OLED 要 BLE → 名字 → 上一位程式還在跑就請他 Ctrl＋C（光重開會被搶回）；他視窗關了就重開 ESP32（按住 A 再按 EN）。No module named 'bleak' → vendor/ 沒解出來，重新解壓。
