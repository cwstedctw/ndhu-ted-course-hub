2　找到 adb、進板子

SSH 的門要先從板子裡面修好（第 3 節），所以第一次進板子還是走 USB，用 W2 那個 adb。

  1. 接線、等心跳。用 USB-C 資料線把板子直接接到電腦（先不要經過 hub），等點陣從旋轉圖案變成心跳動畫，通常要 30～60 秒。
  2. 照你用的電腦，挑下面其中一段打。

教室 E307（Ubuntu）

跟 W2 同一段。前兩行是同一個指令（第一行最後的 \ 代表「接到下一行」），要一起貼：

ADB=$(find "$HOME/.arduino15/packages/arduino/tools/adb" \
    -type f -name adb -perm -u+x -print 2>/dev/null | sort -V | tail -n 1)
"$ADB" devices -l
"$ADB" shell

devices -l 要列出剛好一塊板、狀態是 device，再打最後一行進去。

Windows（PowerShell）

& "$env:LOCALAPPDATA\Arduino15\packages\arduino\tools\adb\32.0.0\adb.exe" shell

說找不到？32.0.0 這個資料夾名在你的電腦上可能不一樣。先看一下是哪個，再把上面那行的 32.0.0 換掉：

dir "$env:LOCALAPPDATA\Arduino15\packages\arduino\tools\adb"

Mac（終端機）

~/Library/Arduino15/packages/arduino/tools/adb/*/adb shell

⚠️ 這條 Mac 路徑還沒在 Mac 上實際查過。Mac 同學照這行試，不行叫老師。

進去之後，提示字元（shell prompt，游標前面那串字）會變成板子的。第 3 節的指令都在這裡打。

E307 的 $ADB 只在跑過上面那段的視窗裡有值，換視窗要重跑。Windows 和 Mac 打的是完整路徑，沒有這個問題。

3　修好 SSH

SSH（Secure Shell）是一條加密的遠端連線：你在自己的電腦打字，指令送到板子上執行。今天之後，進板子主要走這條路。

問題是這批板子的 SSH 門是壞的。SSH 服務（service）開門前，要先拿出板子自己的主機金鑰（host key），證明「我就是這塊板」。這批板子出廠時，六個金鑰檔全是 0 位元組，也就是空的；服務一啟動找不到金鑰，就自己退出了。補上金鑰就好。

在第 2 節進去的板子裡，一行一行打：

systemctl is-active ssh              # failed 或 inactive → 門壞了
journalctl -u ssh -n 3 --no-pager    # 看到 no hostkeys available
ls -l /etc/ssh/ssh_host_*            # 六個檔都是 0 → 鑰匙是空的
sudo ssh-keygen -A                   # 補鑰匙（會問板子密碼）
sudo systemctl enable ssh
sudo systemctl restart ssh
systemctl is-active ssh              # active 才算修好
ip -4 -o addr show wlan0             # 抄下 inet 後面那串（斜線前）＝板子 IP
exit
這一行在做什麼
systemctl is-active ssh問 SSH 服務現在有沒有在跑
journalctl -u ssh -n 3 --no-pager看 SSH 服務最後 3 行紀錄，找它倒下的原因
ls -l /etc/ssh/ssh_host_*列出六個金鑰檔，看檔案大小那一欄
sudo ssh-keygen -A把不存在或空的金鑰重新產生
sudo systemctl enable ssh設成開機自動啟動
sudo systemctl restart ssh現在就重新啟動一次
systemctl is-active ssh再問一次，這次要回 active
ip -4 -o addr show wlan0查板子在 Wi-Fi 上的位址（IP）
exit離開板子，回到你自己的電腦
  • sudo 問密碼時，打板子密碼。打的時候畫面不會出現任何字，連星號都沒有，這是正常的；打完按 Enter。
  • 抄 IP：ip 那行印出來的一長串裡找 inet，後面那串數字抄到斜線 / 前為止，像 192.168.… 這樣四段數字。每塊板都不一樣。
  • 別用 hostname -I 查 IP，它會混進板子內部用的位址（docker0），抄錯就連不上。用 板名.local 連也別指望，學校網路把這種名字擋掉了。

網路上或 AI 可能叫你跑 arduino-app-cli system network-mode enable。這塊板用它修不好：它只補「不存在」的金鑰，碰到「存在但是空的」金鑰會直接跳過。照上面這幾行做就好。

4　SSH 連進去

回到你自己的電腦（提示字元不再是 arduino@ 開頭），打：

ssh arduino@<板子IP>

<板子IP> 整個換成第 3 節抄的 IP，尖括號也拿掉。Windows 一樣在 PowerShell 打 ssh，Windows 10／11 內建。

  1. 第一次連會問 Are you sure you want to continue connecting，打完整的 yes，按 Enter。
  2. 輸入板子密碼，一樣不會顯示，打完按 Enter。
  3. 提示字元變成 arduino@<板名>:~$ 就是進去了。把這一行抄下來，這是要交的第 1 樣。

等很久然後逾時：改走 USB

電腦跟板子不在同一個網路，SSH 就過不去。這時用 adb 在 USB 線上開一條通道：把第 2 節你打的那行最後的 shell，換成 forward tcp:2222 tcp:22，在自己的電腦上打。

教室 E307（Ubuntu）：

"$ADB" forward tcp:2222 tcp:22

Windows（PowerShell）：

& "$env:LOCALAPPDATA\Arduino15\packages\arduino\tools\adb\32.0.0\adb.exe" forward tcp:2222 tcp:22

Mac（⚠️ 路徑跟第 2 節一樣，還沒實查）：

~/Library/Arduino15/packages/arduino/tools/adb/*/adb forward tcp:2222 tcp:22

然後連：

ssh -p 2222 arduino@127.0.0.1
  • 要打 127.0.0.1，不要打 localhost，有些電腦打 localhost 會連不上。
  • E307 的 "$ADB" 要在跑過第 2 節那段的視窗裡才有值，換了視窗先重跑那段。SSH 本身不需要 $ADB。
  • 這條通道只負責讓你連進板子。板子要下載 agy，還是靠它自己的 Wi-Fi。

5　在板子上裝 Antigravity CLI

W2 你在電腦上裝的是有視窗的 Antigravity；今天在板子上裝它的命令列版 Antigravity CLI，指令叫 agy。裝在板子上，它就能直接讀板子裡的檔、幫你改程式。

以下都在 SSH 視窗裡打（提示字元是 arduino@ 開頭）：

curl -fsSL https://antigravity.google/cli/install.sh -o /tmp/agy-install.sh
head -1 /tmp/agy-install.sh          # 一定要看到 #!/bin/bash
bash /tmp/agy-install.sh
source ~/.bashrc
agy --version
  1. curl … -o /tmp/agy-install.sh：把安裝程式下載成一個檔，先不執行。
  2. head -1：看它的第一行。是 #!/bin/bash 才往下；不是就重跑一次 curl 那行。
  3. bash /tmp/agy-install.sh：真的安裝。agy 會放在 ~/.local/bin/agy。
  4. source ~/.bashrc：安裝程式把 agy 的位置寫進了 ~/.bashrc，這行讓目前這個視窗重讀一次，才找得到它。
  5. agy --version：印出版本號就是裝好了（9/23 實裝是 1.2.9，你的可能比較新）。這行的輸出是要交的第 2 樣。

為什麼不用一行裝完

很多安裝說明會寫成 curl … | bash，下載下來直接交給 bash 跑。9/23 實測時，第一次就收到一串亂碼，bash 報語法錯誤。先存成檔、看一眼第一行、確定是腳本再執行，比較穩，你也知道自己要跑的是什麼。

看到這些，別緊張

  • 好幾行 ERROR: logging before google.Init 開頭的字：正常，只是紀錄的格式，不是出錯。最後有 ✅ Antigravity CLI binary placed successfully 就是成功。
  • 最後還會跳一段 Warning: … is not present in your active PATH，叫你自己加一行 echo 'export PATH=…' >> ~/.bashrc：不用照做，安裝程式已經幫你寫進 ~/.bashrc 了，照上面打 source ~/.bashrc 就好。
  • 下載大約 56 MB，全班同時抓會慢。等的時候再開一個終端機視窗，重新 ssh 進板子，先做第 7 節。
  • 要重裝：先 rm ~/.local/bin/agy，不然安裝程式會直接結束。

6　登入 agy

你是從 SSH 連進板子的，板子沒辦法替你開瀏覽器。所以登入要繞一下：板子給你一個網址，你在電腦的瀏覽器登入，再把網頁給你的授權碼（authorization code）貼回板子。

agy
  1. 在 SSH 視窗打 agy。畫面出現 Select login method:，游標停在 1. Google OAuth，直接按 Enter。
  2. 畫面印出 Open the URL below in your browser: 和一長串網址（會折成好幾行）。按住 Ctrl 點那串網址（或下面的 → Click here to authenticate），電腦的瀏覽器就會打開。點不動的話，把整串網址選起來複製，貼到瀏覽器的網址列。教室電腦請用無痕視窗，下課前登出、關掉。
  3. 用個人 Gmail 登入，東華帳號不行。
  4. 網頁會給你一串授權碼，複製它。
  5. 貼回 SSH 視窗（畫面寫 authorization code... 那一格），按 Enter。

要離開 agy：連按兩次 Ctrl＋C。

⚠️ 登入成功之後的畫面，以老師課堂示範為準。

終端機裡怎麼複製貼上

Ubuntu 的終端機用 Ctrl＋Shift＋C 複製、Ctrl＋Shift＋V 貼上。少了 Shift 的 Ctrl＋C 在終端機裡是「中斷」，會把正在跑的程式停掉，登入就得重來。Mac 用 ⌘C／⌘V；Windows 的 PowerShell 按右鍵就能貼上。

8　燈也是一個檔案

在 Linux 裡，很多硬體也被做成檔案。板子上的小燈就在 /sys/class/leds/ 底下：寫 1 進去就亮，寫 0 就滅。

ls /sys/class/leds/
echo 1 > /sys/class/leds/green:user/brightness   # 綠燈亮
echo 0 > /sys/class/leds/green:user/brightness   # 滅

ls 會列出好幾顆燈，今天只碰名字裡有 user 的三顆：red:user、green:user、blue:user。

名字跟這裡不一樣？系統比較新的板子，燈叫 unoq:user-green1 這種名字。那就把上面兩行的 green:user 換成你 ls 看到的那個——以你的板子為準。

這幾顆燈不用 sudo 就寫得進去：它們開放給 gpiod 群組寫，而你（arduino）就在這個群組裡，第 7 節 id 那行看得到。

換一個你沒有權限的檔

echo test >> /etc/hostname

會看到 Permission denied（沒有權限）。/etc/hostname 存的是板子的名字，只有管理員（root）能改。這才是 sudo 的用途：借管理員的權限，去動整台機器的設定。

今天不要真的改 /etc/hostname。看到 Permission denied 就好，別加 sudo 再試一次。

延伸（早做完的人）

  • red:user、blue:user 一起開，看混出什麼顏色。
  • 寫一個 for 迴圈，讓三顆輪流亮。提示：sleep 1 會等一秒。

9　改語系（選做）

語系（locale）決定程式用哪一種語言、日期格式跟你說話。這塊板現在只有英文（en_US.UTF-8）。中文的定義檔其實已經在板子裡，只是還沒「生成」。

locale                                    # 現在是 en_US.UTF-8
sudo vim /etc/locale.gen                  # 找 "# zh_TW.UTF-8 UTF-8"，刪掉開頭的 # 和空白（順便練 vim）
sudo locale-gen                           # 看到 zh_TW.UTF-8... done
locale -a | grep zh                       # 有 zh_TW.utf8 了
export LANG=zh_TW.UTF-8                   # 只換這個視窗
date                                      # 星期幾變中文

在 vim 裡找那一行：打 /zh_TW.UTF-8 按 Enter，游標會跳過去；按 0 回到行首，按兩下 x 刪掉 # 和後面的空白，再 :wq 存檔離開。

  • 只換這個視窗，不改整台（不用 update-locale），免得動到 App 的執行環境。
  • 板子的時區是 UTC，date 顯示的時間會比台灣慢 8 小時。想讓時間對：sudo timedatectl set-timezone Asia/Taipei（⚠️ 選做，這行改的是整台板子的時區）。
  • 一句話帶走：語系是「生成」出來的，不是「安裝」的。

⚠️ 這一段還在確認。跟你看到的不一樣就停手，把畫面給老師看。它是選做，不影響今天要交的三樣。

10　請 AI 寫點陣（主菜）

板子上那片 8 列×13 行的小燈，叫 LED 點陣（LED matrix）。今天請 agy 寫程式，讓它顯示你想要的圖案。你負責三件事：把規矩講清楚、讀過它要做的事再按、最後親眼看板子。

① 建一個 App，叫 agy 進來

arduino-app-cli app new my-matrix
cd ~/ArduinoApps/my-matrix
agy

app new 會建出 ~/ArduinoApps/my-matrix/，裡面有 app.yaml、python/main.py、sketch/sketch.ino、sketch/sketch.yaml。今天只改 sketch/sketch.ino。python/main.py 一定要留著，官方把它標成必要的檔。

② 貼這段提示詞

先把下面這段貼到任何能打字的地方（記事本、文字編輯器都行），把 ＿＿＿＿ 換成你要的圖案，括號裡的例子一起刪掉，再整段貼進 agy。改好的這段就是要交的第 3 樣，記得留一份。

這是 Arduino UNO Q 的 App 資料夾。請只改 `sketch/sketch.ino`，用 `Arduino_LED_Matrix` 在 8×13 的 LED 點陣上顯示＿＿＿＿（例：一顆會跳的愛心、我學號的最後兩碼）。規則：`uint8_t frame[104]`，第 r 列第 c 行是 `frame[r*13+c]`，亮度 0–7；`setup()` 先 `matrix.begin(); matrix.setGrayscaleBits(3);`，用 `matrix.draw(frame)` 顯示。不要改 `python/main.py`、`app.yaml`，不要動網路、SSH、sudo 相關設定，不要用 ArduinoGraphics。改完告訴我要跑哪一行指令。

這段提示詞（prompt）分三塊：第一句講要它做什麼；「規則」那句告訴它這塊板的點陣怎麼排（104 格，每格亮度 0 到 7）、該用哪幾個函式，這些 AI 不一定知道；最後一句是不准碰的東西。

⚠️ 哪一個角是 frame[0]（第 0 列第 0 行）還在確認。圖案上下或左右反了，就請 agy 翻過來。

③ 讀過再按

agy 要寫檔、跑指令、上網之前，都會先停下來問你。每一次都讀過它要做什麼再按：

  • 要改 sketch/sketch.ino：可以。
  • 要改 python/main.py 或 app.yaml、要用 sudo、要裝 ArduinoGraphics 或其他函式庫：不要按允許，請它照提示詞的規則重來。

④ 上板，看板子

agy 改完後，另開一個 SSH 視窗（或先離開 agy），打：

arduino-app-cli app start ~/ArduinoApps/my-matrix
  • 等 30 秒到 2 分鐘（第一次最久）：板子要編譯程式，再燒進另一顆晶片（W2 講過的 STM32）。別重按。
  • 中間出現紅字 verify failed in bank at 0x08000000，或 level=error msg="Stopped decode loop: EOF"，都是正常的。
  • 最後一行是 ✓ App "my-matrix" started successfully 才算跑起來。
  • 然後看板子。畫面說成功不算數，點陣真的亮出你要的圖案才算。拍照（最多 2 張）交 e學苑。
  • agy 最後告訴你的指令，如果跟這一頁不一樣（例如叫你用 app restart），照這一頁的做。

⑤ 改第二版

arduino-app-cli app stop ~/ArduinoApps/my-matrix

等 3 秒，請 agy 改，改完再打一次上面那行 app start。不要用 app restart，它會卡住。

別踩的雷

  • python/main.py 一定要留著。
  • 別清空 App 資料夾。裡面有個藏起來的 .cache/，刪了 App 就停不掉。
  • 一次只能跑一支 App。
  • 要捲動文字得另裝 ArduinoGraphics（要上網下載），今天別碰。
  • app start 在 SSH 裡跑。在 adb shell 裡跑會失敗（見第 11 節）。

三條底線

  1. agy 要動檔、跑指令前會問你：讀過再按。
  2. 板子密碼不給 AI。不要打進 agy，也不要寫進提示詞。
  3. 不准加 --dangerously-skip-permissions。這個選項會讓 agy 不問你就直接動手。

11　卡住了怎麼辦

先把整段錯誤訊息複製下來（線上的貼到 Meet 聊天室），再對這張表。表上找不到，就叫老師。

看到什麼先做這個
"$ADB" devices -l 沒列出板子，或 no devices/emulators found跟 W2 一樣：確認是資料線、直接接電腦不經過 hub、換一個 USB 埠。
$ADB 是空的、"$ADB" 打了沒反應這個視窗沒跑過第 2 節那段，重跑一次。
ip -4 -o addr show wlan0 什麼都沒印板子還沒連上 Wi-Fi。在家的：在板子裡打 nmcli --ask dev wifi connect "你家的Wi-Fi名稱"，照提示打 Wi-Fi 密碼（不會顯示），再查一次 IP。在教室的叫老師。
ssh 等很久，最後 Connection timed out電腦跟板子在同一個網路嗎？線上的：板子和筆電要連同一個 Wi-Fi。還是不通，就走 USB（第 4 節後半）。
Connection refused板子的 SSH 還沒修好。回第 3 節，systemctl is-active ssh 要回 active。
Permission denied (publickey,password)密碼打錯。打密碼時畫面不會出現任何字，慢慢打完再按 Enter；帳號要是 arduino。
REMOTE HOST IDENTIFICATION HAS CHANGED叫老師。這代表這台電腦記得的板子金鑰跟現在的不一樣（例如同一個位址換了一塊板）。不要自己亂刪 known_hosts。
裝 agy 時出現 syntax error你是不是用了 curl … | bash？照第 5 節：先存成檔、看第一行，再 bash 它。
head -1 看到的不是 #!/bin/bash下載壞了，重跑一次 curl 那行。
下載一直不動，或失敗全班一起抓會慢。先開另一個 SSH 視窗做第 7 節；真的失敗，把整段訊息給老師。
agy: command not found打 source ~/.bashrc，或關掉這個 SSH 視窗重新連進去。
agy 登入卡住告訴老師（休息時間處理），先往下做第 7、8 節。
卡在 vim 出不去按幾下 Esc，打 :q! 再按 Enter。
echo 1 > /sys/class/leds/green:user/brightness 說 No such file or directory你的板子燈的名字不一樣。ls /sys/class/leds/ 看一下，換成名字裡有 user 和 green 的那個（例如 unoq:user-green1）。
一 SSH 進去就出現 setlocale 或 cannot change locale 的警告不影響操作：你的電腦把自己的中文語系帶進了板子，但板子還沒生成中文語系。先打 export LANG=en_US.UTF-8 就安靜了；做完第 9 節也會好。
Stat /Data/Local/Tmp你在 adb shell 裡跑了 app start。改用 SSH 跑；非用 adb 不可，先打 export TMPDIR=/tmp。
app start 最後沒有 ✓ … started successfully往上找第一個 error（Stopped decode loop: EOF 那種是正常的，跳過），把那一段整段貼給 agy，請它照提示詞的規則修。
app start 說成功，點陣卻沒亮再看一次最後一行是不是 ✓ App "my-matrix" started successfully；打 ls ~/ArduinoApps/my-matrix/python/，確認 main.py 還在。
