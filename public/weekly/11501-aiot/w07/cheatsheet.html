第三部分 16:10–17:00藍牙健康手環

3-1 推程式、開始喊

電腦在 ~/Downloads

"$ADB" push w07-starter/health_ble.py /home/arduino/

板子名字＝UNOQ-＋組別兩位數＋座位字母（≤12 字，不用學號、姓名）；把 G03A 換成你的，這個視窗一直跑

python3 ~/health_ble.py --name UNOQ-G03A

要看到 advertising as 'UNOQ-G03A'（558 上不用 sudo；刷完 Wi-Fi 沒連，W=0 正常）。Permission denied／AccessDenied → 前面加 sudo。

3-2 nRF Connect 找到自己

手機掃描頁用名字過濾；別去手機設定頁配對；Android 允許「附近的裝置」

RSSI 四個距離：貼著／1 公尺／3 公尺／手掌包住（負數，越接近 0 越強）。0xFFFF 後面 7 bytes：[溫度×10 低, 溫度×10 高, 負載×10, 記憶體%, 容器數, 開機分 低, 開機分 高]，低位在前。示意 B0 01 03 26 02 7D 00 → 43.2 °C、0.3、38%、2、125 分；跟板上 T= 比。

3-3 Bluefruit Connect 的 UART

手機連自己的板 → UART；板上印 phone subscribed (StartNotify)。看到好幾個服務（BLE-MIDI、1800…）正常，找 6E400001

打：help、health、apps、ip、HELP。清單以外回 unknown: '…' (try help)，不執行。RX＝板子收、TX＝板子送。

3-4 Plotter＋操板子（📸 證據 3）

手機Plotter；順序：溫度、負載、記憶體%、硬碟%、Wi-Fi%；只看溫度打 plot temp

電腦開視窗 C 再進板子；不通改走 2222（視窗 A 要先 forward）

ssh arduino@192.168.7.2
ssh -p 2222 arduino@127.0.0.1

視窗 C四支 yes，看 3 分鐘；停掉（用 -x，別用 -f），再看 2 分鐘

for i in 1 2 3 4; do yes > /dev/null & done
pkill -x yes

證據 3＝Plotter 截圖＋溫度起點、最高、停掉後 2 分鐘。

你先在 App 按 Disconnect → 同組同學用他的手機連你的板、打 apps（輪流）；連不上就板子 Ctrl-C 重跑 3-1。不配對、不用密碼＝誰都連得上；所以程式只認清單上的字，絕不把手機的字丟給 shell。
