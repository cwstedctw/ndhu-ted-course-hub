ONE NEW IDEA
燈不是在閃，
是程式一直回頭
while True 底下縮排的那幾行，做完就回到第一行再做一次。
while True:
    red.value(1)
    time.sleep(wait)
    red.value(0)
    time.sleep(wait)
回頭

IF / ELSE
如果…就…，不然就…
if n < 3 就快，else 就慢。右下角印的 n 和 wait，跟燈對得上嗎？
if n < 3:
    wait = 0.2
else:
    wait = 1.0
n = 0 wait = 0.2
n = 1 wait = 0.2
n = 2 wait = 0.2
n = 3 wait = 1.0
n = 4 wait = 1.0
