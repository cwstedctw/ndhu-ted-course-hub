  3. 按播放（右上那格的綠色圓鈕）。紅燈一亮一滅＝可以往下。綠燈不會動，那是正常的——這支程式只叫了 16 號。

燈不亮？先看兩件：腳位是不是 16、短腳後面有沒有串 220Ω 再回到 GND。還是不亮，開〈這條線為什麼不亮〉五題對一遍；想看電流怎麼走的，開〈腳位透視鏡〉。

硬事實（跟上週一樣）：紅燈 GPIO16、綠燈 GPIO13、限流電阻 220Ω、wait = 0.5。

3　順序：程式是一行一行跑的

電腦不會跳著看。它從第一行開始，一行做完才做下一行。你看不到它在哪一行——所以我們讓它自己講。

  1. 加兩行。在 red.value(1) 那行的下面加 print('亮')，在 red.value(0) 那行的下面加 print('滅')。前面的四格空白要跟上下行一樣。
  2. 按播放。右下角那格黑底面板（序列埠終端機）會一行一行印出：
亮 滅 亮 滅

字跟燈對得上嗎？印「亮」的時候燈亮、印「滅」的時候燈滅——那就是它現在跑到哪一行。

先猜，再跑

  • 把兩行 print 對調（print('滅') 放到 red.value(1) 下面）。先寫你猜會印出什麼，再按。
  • 把 print('亮') 搬到 time.sleep(wait) 的下面。字會晚出現嗎？晚多久？

找不到那格黑底面板：它在畫面右下角，字是白的不是紅的，夾在開機那幾行中間。改完程式要重按播放，它不會自己重跑。

4　變數：一個名字，裝一個數字

wait = 0.5 這一行，是把 0.5 裝進一個叫 wait 的名字裡。這種會裝東西的名字叫變數（variable）。下面兩行 time.sleep(wait) 用的都是這個名字——改一次，兩行一起變。

  1. 改 0.5。改成 2、改成 0.05，每次先猜再按。
  2. 再加一個名字。在 wait = 0.5 下面加一行 off_wait = 0.1，然後把第二個 time.sleep(wait) 改成 time.sleep(off_wait)。先猜：燈會變成怎樣？

答案是亮久、滅短——因為兩個「等」現在各用各的名字。這就是為什麼要取名字：想讓誰不一樣，就給誰一個新名字。

5　迴圈：燈不是在閃，是程式一直回頭

while True: 那一行的意思是「底下縮排的那幾行，做完就回到我這裡再做一次」。這叫迴圈（loop）。前面那四格空白叫縮排（indent），它在說「這幾行是屬於迴圈的」。

弄壞一次看縮排

把最後一行 time.sleep(...) 前面的四格空白刪掉（你剛剛可能已經把它改成 off_wait，就是那一行），讓它頂到最左邊。先猜燈會怎樣，再按播放。

它看起來會一直亮——因為滅完馬上回頭又亮，中間沒有等。那一行不再屬於迴圈，程式永遠走不到它。看完改回來。

要它數幾次就停：for

把 blink-v1.py 整段貼進去，蓋掉原本的，按播放。

times = 5                    # 一共閃幾次

for n in range(times):       # n 會從 0 數到 4，剛好 5 次
    ...
print('閃完了，燈停在滅')

右下角會印五行 n = 0 … n = 4，然後印「閃完了」，燈停在滅。while True 是一直回頭，for 是數幾次就停。

今天最多人猜錯的：第一個印出來的是 0，不是 1。電腦從 0 開始數。把 times 改成 8，先猜最後一行的 n = 是多少，再按。

6　條件：如果…就…，不然就…

blink-v1.py 裡還有四行：

    if n < 3:                # n 還小於 3 的時候（0、1、2）
        wait = 0.2           # 快
    else:                    # 其他時候（3、4）
        wait = 1.0           # 慢

if 就是問一句「現在的 n 小於 3 嗎」。是，就走上面那行；不是，就走 else 那行。這叫條件（if／else）。所以前三次快、後兩次慢。右下角每一行都印了 n 和 wait：

n = 0 wait = 0.2 n = 1 wait = 0.2 n = 2 wait = 0.2 n = 3 wait = 1.0 n = 4 wait = 1.0 閃完了，燈停在滅
  1. 把 3 改成 1。先猜前幾次會快，再按，看右下角印的對不對得上燈。
  2. 把 3 改成 5。再猜一次。

7　弄壞一次：沒有紅字也要會寫

上週說過「沒報錯不等於做對」。今天教你怎麼把它寫下來。

  1. 先把 blink-v0.py 貼回來（用 v1 也可以，只是右下角會多印 n = 那幾行）。把 16 改成 25，按播放。右下角的字照樣印（程式在跑），但燈就是不亮，而且沒有任何紅字錯誤訊息。這種沒有紅字的，用三句寫：我做了什麼／我預期看到什麼／實際看到什麼。寫進卡的背面，然後改回 16、跑一次確認。
  2. 把 import time 那一行刪掉，按播放。這次右下角會有訊息，最後一行開頭是 NameError。認的是最後那一行開頭那個 ○○Error，不用整段看懂。

三句的寫法照抄自共用教材 P9〈電腦出錯了，先做這四步〉（background-knowledge/P9-電腦出錯先做的四步.md）：「沒有紅字的（燈不亮、畫面沒反應、按了沒事）：第一步的『原文』改寫成三句——我做了什麼、我預期看到什麼、實際看到什麼。」各科同一份，本週不另寫版本。

8　看不懂的那一行，貼去另一個分頁問

今天的 AI 開在瀏覽器另一個分頁（任何一個網頁版都可以）。它碰不到你的 Wokwi，也碰不到板子，給你的是文字；搬運的人是你。

  • 把看不懂的那一行貼過去，問：「這一行在做什麼？」
  • 把第 7 節那段錯誤訊息貼過去，問：「這段訊息是什麼意思？先解釋，不要先幫我改。」
