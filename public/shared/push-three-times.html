叫 Antigravity 替你裝好 git 與 GitHub CLI，把一支 Python 小程式推上 GitHub——改三次、推三次

Have Antigravity install git and GitHub CLI, push a small Python script to GitHub, then change it three times and push each time

大部分的活是 AI 替你做的。你負責三件事：講清楚要它做什麼、每一步執行前看一眼再按同意、做完自己去 GitHub 驗一次。做完你會有一個公開的 repo，裡面有三筆看得懂的歷史。

The AI does most of the work. You do three things: say clearly what you want, look at each step before you approve it, and check the result on GitHub yourself. When you finish you will own a public repo with three readable commits.
