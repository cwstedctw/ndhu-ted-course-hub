訓練參數實驗台

Teachable Machine 的 Advanced 有三個參數：Epochs、Batch Size、Learning Rate。這裡一次改一個，按「開始訓練」，看曲線怎麼變。

全部訓練資料看過一次＝一輪。Teachable Machine 預設 50。

一次看幾張、修正一次。預設 16。

每次修正走多大步。預設 0.001。

第 0 輪已修正 0 次測試準確率 —

旁邊這張圖怎麼看

每個點是一張圖片：●紅圓、■藍方。空心的是測試資料（模型沒學過）。底色是模型的判斷：偏紅＝猜紅圓，偏藍＝猜藍方。兩區的交界就是它學到的「規律」。

訓練前，模型一律猜紅圓，所以準確率從 50% 起跳。

兩個座標是模型從圖片抽出的兩個數字（簡化說法）；真實模型會抽出很多個。

Epochs 一輪數

全部訓練圖都看過一次，叫一輪。輪數越多，學得越久。

例：按 ② 只跑 3 輪，準確率還沒爬上去就停了（學不夠）。按 ③ 跑 300 輪，Loss 還在往下，準確率卻跟 50 輪差不多：多跑不一定多得分，只是等更久。

Batch Size 批次大小

一次拿幾張來看、看完修正一次。80 張、每批 16 張＝5 批＝一輪修正 5 次。

例：按 ⑥ 每批 512 張，比全部資料還多，一輪只修正 1 次；同樣 50 輪，總修正次數少很多，曲線爬得慢。

Learning Rate 學習率

每次修正走多大步。步子太小學得慢，太大會衝過頭。

例：按 ⑤ 0.00001，50 輪幾乎沒動。按 ④ 0.5，Loss 曲線上下亂跳。

這是簡化的玩具模型（兩個數字、一個小神經網路），用來看「改一個參數會怎樣」的趨勢；數字不會跟 Teachable Machine 一樣。每次重新訓練都從同一個起點開始，所以只要參數一樣，結果就一樣——一次只改一件，才看得出是哪一件造成的。
