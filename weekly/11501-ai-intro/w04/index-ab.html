2Teachable Machine 與圖片包

它怎麼學，一行講完：資料（data）→ 訓練（train）→ 模型（model）→ 預測（predict）。（簡化說法：訓練＝從例子裡找規律。）

官方 README 怎麼說（英文原句，每句下面是白話翻譯）：

  • “a web-based tool that makes creating machine learning models fast, easy, and accessible for everyone”一個網頁工具，讓每個人都能快速、輕鬆地做出機器學習模型。
  • “train and run the models you make in your web browser”你做的模型，在你自己的瀏覽器裡訓練、執行。
  • “without writing any machine learning code”不用寫任何機器學習程式碼。
出處：GitHub googlecreativelab/teachablemachine-community 的 README（2026-09-25 查）。
兩人一組、一台電腦、一個模型。E403 沒有攝影機，全班用圖片包。

下載 image-pack.zip，先解壓縮（Upload 不吃 zip）。三個資料夾（red-circle、blue-square、green-triangle）各 24 張，程式畫的圖形：沒有照片、沒有人臉。test 夾每類 2 張較難的：只拿來測，不拿去訓練。

3動手 1：訓練，再測

在 teachablemachine.withgoogle.com：

  1. Get Started → Image Project → Standard image model。
  2. 把 Class 1、Class 2 改名成 red-circle、blue-square。（第三類按 Add a class，有餘力再加。）
  3. 每類按 Upload → 只選 01–12（12 張）。
  4. 用預設值按 Train Model，跑完前別關分頁。
  5. 在 Preview 把 Input 從 webcam 改成 file，把 test 夾的圖一張張丟進去，記下百分比。

介面可能改版，找不到就問老師。

按下 Train 時發生什麼事

  • 訓練樣本（training samples）拿來學；測試樣本（test samples）留著考它。
  • 一輪（epoch）：每張訓練圖都看過一次。

4Advanced 的三個參數

在 Training 底下點 Advanced。預設值（2026-09-29 官網實查）：

  • Epochs（一輪數）＝50：學幾輪。
  • Batch Size（批次大小）＝16：看幾張修正一次。工具自己的例子：80 張 ÷ 16 ＝ 5 批 ＝ 1 輪。
  • Learning Rate（學習率）＝0.001：每次修正多大步。太小學得慢、太大會衝過頭（簡化說法）。
先到參數實驗台玩一次：params-lab.html（六個範例；是簡化的玩具模型，數字不會跟 Teachable Machine 一樣）。

Advanced 旁邊點 Under the hood：Accuracy per epoch（越高越好）、Loss per epoch（越低越好），訓練和測試各一條線。

5三個實驗：一次只改一件

  1. 只改 Epochs：5、50、200，其他維持預設。test 圖對幾張？曲線長怎樣？
  2. 只改學習率：0.0001、0.001、0.1（Epochs 改回 50）。哪一個的 Loss 亂跳？
  3. 補資料：按 Reset Defaults，每類補上 13–24，再訓一次。Under the hood 按 Accuracy per class、Confusion Matrix。資料和參數，哪個幫比較多？

每個實驗做完截一張圖。為什麼一次一件：一次改兩件，就不知道是哪一件造成的。

找一張它判錯的

判錯是線索。常見原因（簡化說法）：例子太少；test 圖跟訓練圖不像（變小、偏色、轉角度、雜訊）；參數（輪數太少、步子太大）。
