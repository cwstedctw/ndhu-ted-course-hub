Agent 計畫、差異、批准與驗證

這是 120 分鐘 W3 主路線中的約 25 分鐘離線 Agent 夥伴活動，不是另一門縮短版課程。你不需要網路或 AI 帳號；先看預寫計畫與差異，再由人批准、修改或拒絕，最後用測試驗證。

  • 120 分鐘主路線內約 25 分鐘
  • 不連網
  • 不執行貼入程式碼
  • 不儲存輸入

隱私界線：本頁沒有姓名、學號或自由輸入欄位，也不使用 localStorage。所有選擇只留在目前分頁；重新整理即清除。請勿把真實個人資料寫在列印紙上。

English support: complete quick guide

Route note: this is an approximately 25-minute offline Agent companion activity inside the 120-minute W3 main route, not a separate shortened lesson.

Goal: practise a supervised workflow without an AI account. This page uses only pre-written suggestions. It never runs pasted code, sends network requests, or saves personal data.

  1. Choose one synthetic campus topic and generate the pre-written Agent plan.
  2. Inspect the conceptual before/after difference. It is not executable code.
  3. Approve, modify, or reject the suggestion and record a reason.
  4. Run two tests: a normal case must return a result; an empty case must show a correction message and must not invent a result.
  5. Select one risk, build the evidence card, and print it before leaving.

Assessment: the task, two tests, human decision, and risk boundary are the same as in the live-AI route. English grammar or style is not graded in W3.
