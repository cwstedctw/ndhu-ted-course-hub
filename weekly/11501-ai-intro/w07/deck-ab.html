三種「成功卻是錯」

三種錯誤訊號；「通過」也是它說的。

1
名牌叫錯，exit code 0! agent "member" not found
… done

印了 not found，用領隊名牌做完，照樣說成功。

2
exit code 0 不等於做完exit 0
outbox/ (no new file)

指令乾淨結束，但 outbox 沒新檔＝沒做。

3
「隊員還在跑」(stopped)
leader: “still running…”

它說隊員還在做，其實已經停了。

檢查點不看也說得出三種訊號
