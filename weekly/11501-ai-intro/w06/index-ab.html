上週你叫 Codex 做了一個網頁：「課間我想做什麼？」挑選器。今天讓兩個 AI 替那個網頁寫一頁使用說明：怎麼用，加上三件它做不到的事。它們只准用 workspace/shared/ 裡的檔案。隊員寫，領隊對著檔案驗收，至少挑一處退回，隊員另存新檔改成 v2。v1、v2 都留著。

怎麼跟它們講話你自己決定。資料夾裡的 AGENTS.md 已經告訴它們自己是誰、紙條怎麼傳；哪一個不照做，就叫它再讀一次。

交：三張截圖（領隊的第一張任務紙條、v2、領隊驗收 v2 的回話；只做完一輪的，交 v1 和驗收 v1 的回話）＋一句話：領隊抓到什麼？

驗收標準：檔案裡沒有的就不算。

三個觀念

  • 兩個 AI 不直接講話，只共用一個資料夾。
  • 傳紙條：領隊把任務紙條放收件匣（inbox），隊員把成品放寄件匣（outbox），共用區（shared）放兩人都讀的資料。沒有魔法連線。
  • 兩個 app、同一個資料夾、一份公約。AGENTS.md 告訴它自己是誰、紙條放哪、做完要停下來把棒子交回你。

今天的名詞

  • 領隊（leader）：OpenCode 桌面版裡的 AI。寫任務紙條、驗收成果。
  • 隊員（member）：Antigravity 裡的 AI。動手寫使用說明。
  • 專案（project）：app 工作的那個資料夾。兩個 app 都開同一個專案：my-team。
  • 團隊公約（AGENTS.md）：每個 AI 開機先讀的那份檔。它告訴 OpenCode 自己是領隊、告訴 Antigravity 自己是隊員。
  • 核准（approval）：app 有些動作會先停下來問你。先讀，在 my-team 裡面的就允許。
  • 手動接力（manual relay）：每一棒都由你親手從一個 app 傳到另一個。

這一段約 25 分鐘，先一個人做。你用自己的話跟 OpenCode 裡的 AI 講目標，它動手；你負責看它要做什麼，最後自己到 GitHub 驗收。

目標：GitHub 歷史頁看得到四筆（由舊到新）

  1. Initial commit：在 GitHub 網頁建 repo 時自動產生。
  2. v1 中文版：BMI 網頁 index.html。輸入身高（公分）、體重（公斤），算出 BMI 和分級，全部中文。
  3. v2 中英雙語：同一頁加一個切換鈕，可以換中文和 English。
  4. Revert "v2 中英雙語"：用 git revert 撤銷 v2，網頁變回 v1 的樣子；v2 那筆還留在歷史裡。
四個詞：commit＝存一個版本；push＝把版本傳上 GitHub；clone＝把 GitHub 上的 repo 抓到這台電腦；revert＝撤銷某一筆，做法是再加一筆把它改回來。
不要在對話裡打學號、姓名。AI 問要不要允許執行指令：先看它要跑什麼，再按允許。

    你應該看到：「文件」裡多一個 bmi 資料夾，裡面有 README.md。

    卡住了

3玩挑選器、開領隊與隊員、做目標

A · 拿到小隊資料夾、玩一分鐘挑選器

  1. A1把 ai-team-starter.zip 解壓縮到「文件」（按右鍵 →「解壓縮全部」）。一層層點進去，直到 AGENTS.md 就在眼前：那一層就是 my-team。（「解壓縮全部」可能多一層：文件\ai-team-starter\my-team。）

    你應該看到：my-team 裡有 AGENTS.md、leader.md、member.md、leader.cmd、member.cmd、opencode.json，還有 workspace 資料夾。（電腦若隱藏副檔名，檔名後面「點」之後的部分不會顯示。）

  2. A2在 my-team 裡雙擊 workspace\shared\campus-picker.html，它會在瀏覽器打開；畫面是英文的話，先按標題旁的「中文」按鈕切成中文。選室內 · 30 分鐘 · 低 → 按「幫我選」；再改選 15 分鐘、體力「中」（地點選哪個都一樣）→ 按「幫我選」，會出現「沒有符合條件的活動」。

    你應該看到：第一組條件抽到一個活動；15 分鐘＋中，出現「沒有符合條件的活動」。
跟你上週交給 AI 的是同一份需求。現在看看它真的會什麼：使用說明要寫的就是這些。

選做：想改用你上週自己的網頁？把它的 index.html 改名成 campus-picker.html，放進 workspace\shared\ 蓋過去。

C · 做目標：五步

每一棒都由你親手傳。表裡只寫它要知道什麼、做完應該看到什麼；怎麼講由你決定。

寫檔：它應該不用問。如果它問要不要允許在 my-team 裡寫檔，就允許。
等待：驗收可能要 5 分鐘左右（領隊要逐句對檔案）。畫面還在變、或顯示它正在做，就等。整整 3 分鐘完全沒變化，才在同一個專案開新對話（OpenCode、Antigravity 都一樣）。紙條都是資料夾裡的檔案，不會不見。
步驟要讓它知道的事做完應該看到
C1 派任務你 → OpenCode 領隊要讓它知道的事今天手動接力。用你自己的話把目標告訴它：替 shared 裡的挑選器寫一頁使用說明（怎麼用＋三件做不到的事），只能用 shared 裡的檔案。領隊看不到這個網頁，所以別只說「第 0 節」。寫完紙條停，不要自己寫說明。做完應該看到workspace\inbox\ 多一個檔；領隊說「紙條在 inbox，請去叫隊員」然後停。
C2 接任務你 → Antigravity 隊員要讓它知道的事去 inbox 看最新的紙條，照做；成品另存新檔到 outbox，加一行交接；做完停。做完應該看到workspace\outbox\ 多一個檔＝v1；隊員說「做好了，請回去找領隊」。
C3 驗收 v1你 → OpenCode 領隊要讓它知道的事去 outbox 看成品，逐句對 shared 裡的檔案，列出檔案裡沒有的功能、數字、步驟；寫退回紙條進 inbox，至少挑一處要改的（v1 看起來沒問題也一樣）；再給你三句總結。做完應該看到領隊列出幾句「檔案裡沒有」；inbox 多一張退回紙條。這一輪抓到的，可以拿來寫作業那句「領隊抓到什麼」。它說全部通過？再請它至少挑一處。
C4 改成 v2你 → Antigravity 隊員要讓它知道的事看 inbox 最新那張（退回紙條），照著改，另存成 v2、不要蓋掉 v1；做完停。做完應該看到outbox 同時有 v1、v2 兩個檔。
C5 驗收 v2你 → OpenCode 領隊要讓它知道的事用同樣方法驗 v2，逐句對 shared 裡的檔案。做完應該看到「檔案裡沒有」比第一次少，或是零。

時間不夠？老師可能把 C4–C5 改成課後做。

你也要驗。領隊退回紙條上寫的錯，自己對一次網頁。隊員交接寫「已修正」，不等於真的改了，打開成品看。
「做完了」是它說的，「通過」也是它說的；驗收是你的。
檢查：inbox 有任務紙條；outbox 有 v1、再有 v2；你說得出領隊抓到什麼。

邊做邊截作業要的圖：第一張任務紙條、v2、領隊驗收 v2 那段（第 7 節）。

看第 6 節：跟同學配對，或改走②。

6另外的走法

走哪一條都同分。觀念一樣：兩個 AI、一套紙條、由你驗收。

只有你這台出狀況，就挑一條合適的走法。

① OpenCode 終端機版，桌面版裝不起來時用：下載 opencode-windows-x64.zip、解壓縮，把 opencode.exe 拖進 my-team、跟 AGENTS.md 放一起，再雙擊 leader.cmd。一樣是領隊，只是開在終端機視窗。

② ChatGPT 網頁＋Gemini 網頁：兩個瀏覽器分頁，ChatGPT 當領隊、Gemini 當隊員。紙條和 shared 裡檔案的內容，用複製貼上傳。

③ 跟同學配對（一人操作、一人驗收），或用紙本接力（老師有印好的）：卡 1 是領隊紙條，附「shared 裡有什麼」小框；卡 2 是隊員成品；卡 3 帶你驗收：圈出小框裡沒有的、寫退回紙條，再自己改成 v2。
