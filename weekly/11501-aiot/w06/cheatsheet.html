W6 指令小抄：借眼睛——攝影機走 USB 進板子，再把一條線變成網路

AIoT 智慧裝置實作 115-1・10/15（四）E307。照順序一行一行打；電腦＝視窗 A（跑過找 adb 那段）、板子＝SSH 視窗 B。看不懂為什麼 → 學生頁同一節；卡住 → 學生頁第 9 節，或把完整錯誤訊息貼給 AI agent（板子密碼不要貼）。可以印成一張 A4。

1　就位（接線、等心跳；視窗 A）

電腦USB 看得到（要有 2341:0078）

lsusb | grep -E '2341:0078|05c6:9008'

電腦找 adb（兩行一起貼）、列出板子（要有 device）

ADB=$(find "$HOME/.arduino15/packages/arduino/tools/adb" \
    -type f -name adb -perm -u+x -print 2>/dev/null | sort -V | tail -n 1)
"$ADB" devices -l

電腦開 2222 通道（不印字）；再開一個視窗 B，SSH 進板子（打 yes、板子密碼）

"$ADB" forward tcp:2222 tcp:22
ssh -p 2222 arduino@127.0.0.1

✅ 視窗 B 提示字元 arduino@ 開頭。"$ADB" 開頭的都在 A 打、arduino-app-cli／sudo 都在 B 打。

2　把 App 放上板子

電腦抓下來、解開（第二行不印字）、推上板子

cd ~/Downloads
curl -fsSL https://cwstedctw.github.io/ndhu-ted-course-hub/weekly/11501-aiot/w06/starter/w06-starter.tar.gz | tar xz
ls w06-starter
"$ADB" push w06-starter/face-usb-classroom /home/arduino/ArduinoApps/
"$ADB" push w06-starter/w06-usbnet /home/arduino/

板子跑起來（老師板 16 秒；出廠板第一次可能先拉 969 MB，不要重按）、看兩個容器、看 log

arduino-app-cli app start ~/ArduinoApps/face-usb-classroom
docker ps --format "{{.Names}}"
arduino-app-cli app logs ~/ArduinoApps/face-usb-classroom --tail 12

✅ started successfully＋face-usb-classroom-main-1、…-ei-video-obj-detection-runner-1 兩列。

3　三條通道，開網頁

電腦17000 網頁、18080 影像、14912 AI 框選（不印字）；再列出來看

"$ADB" forward tcp:17000 tcp:7000
"$ADB" forward tcp:18080 tcp:8080
"$ADB" forward tcp:14912 tcp:4912
"$ADB" forward --list

Chrome 開 http://127.0.0.1:17000（一定要 127.0.0.1）→ 選攝影機 → 允許 → 開始辨識 → 右下有臉框。📸 證據 1：臉框＋六格同一張（送出 8.0 FPS、板子實際收到 8.0）。✋ 8.0 是誰定的？

4a　一條線變網卡：先看、核對、裝（裝進 adbd 的生命週期）

板子先看三樣＋要裝的檔（lsmod 那行現在什麼都不印）

ls /sys/kernel/config/usb_gadget/g1/configs/c.1/
ls /lib/modules/$(uname -r)/kernel/drivers/usb/gadget/function/
lsmod | grep -E "ncm|u_ether"
cat ~/w06-usbnet/10-extra-functions.conf

板子核對（沒印 OK 就不要裝，留在 adb 路線）

grep -q 'ExecStopPost=/usr/lib/android-sdk/platform-tools/adbd-usb-gadget reset' /usr/lib/systemd/system/adbd.service && echo OK

板子七行 sudo：放檔案、重讀、enable（打板子密碼；最後一行印 non-existent unit 是正常）

cd ~/w06-usbnet
sudo install -d -m 755 /home/arduino/usbnet
sudo install -m 755 ncm-hook.sh /home/arduino/usbnet/ncm-hook.sh
sudo install -d /etc/systemd/system/adbd.service.d
sudo install -m 644 10-extra-functions.conf /etc/systemd/system/adbd.service.d/
sudo install -m 644 usbnet-dhcp.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable usbnet-dhcp

板子重啟 adbd——SSH 會斷，正常；數 15 秒

sudo systemctl restart adbd

4b　網卡起來了沒：電腦這頭、板上回頭看

電腦就在視窗 B（SSH 斷了就回到電腦）：多一張 192.168.7.x 網卡、ping、不用通道的 SSH（檢查腳本 sh w06-starter/pc/check-usbnet.sh 在視窗 A 跑，一次看五樣）

ip -4 -br addr
ping -c 5 192.168.7.2
ssh arduino@192.168.7.2

板子四行回頭看：兩個 active、c.1/ 多了 ncm.usb0、模組載了、hook 日誌

systemctl is-active adbd usbnet-dhcp
ls /sys/kernel/config/usb_gadget/g1/configs/c.1/
lsmod | grep -E "ncm|u_ether"
cat /tmp/ncm-hook.log

📸 證據 2：ip -4 -br addr＋c.1/ 兩張。網卡是持久的，一台電腦一次只接一塊板。

5　量快慢（只有第一行必做）

電腦USB 網路的 ping（看最後一行 min/avg/max）

ping -c 10 192.168.7.2

有餘力：板子查 Wi-Fi IP（⚠️ 沒在板上跑過）→ 電腦ping 它（教室網路可能擋住）

nmcli -g IP4.ADDRESS dev show wlan0
ping -c 10 <板子的 Wi-Fi IP>

老師 10/14：USB 0–1 ms vs 家用 Wi-Fi 平均 156 ms；100 MB：0.8 秒 vs 52 秒。

有餘力：板子100 MB（⚠️ 沒逐字跑過）→ 電腦抓 → 板子 Ctrl＋C、刪檔

dd if=/dev/urandom of=/tmp/blob100.bin bs=1M count=100
python3 -m http.server 8000 --bind 192.168.7.2 --directory /tmp
curl -o /dev/null -w "%{speed_download} B/s\n" http://192.168.7.2:8000/blob100.bin
rm /tmp/blob100.bin

6　同一個網頁改走 USB 網路（零 adb）

先直連 http://192.168.7.2:7000：攝影機下拉只剩「這個瀏覽器不支援攝影機」（瀏覽器只在 localhost／HTTPS 給攝影機）。

電腦拆光 forward（第二行要印空的，留在畫面上）、開轉接程式（會一直跑）

"$ADB" forward --remove-all
"$ADB" forward --list
python3 w06-starter/pc/usbnet-bridge.py

印四行（USB 網路轉接啟動…＋三行對照）→ Chrome 開 http://127.0.0.1:17000 → 臉框回來。📸 證據 3：空的 forward --list＋臉框同一張。

7　有餘力：改兩處 fps、看瓶頸

板子8 → 20（兩處都改）、確認、重啟

cd ~/ArduinoApps/face-usb-classroom
sed -i "s/^    fps=8,/    fps=20,/" python/main.py
sed -i "s/^const TARGET_FPS = 8;/const TARGET_FPS = 20;/; s/max: 12 }/max: 30 }/" assets/app.js
grep -n -E "fps=|TARGET_FPS = |max: " python/main.py assets/app.js
arduino-app-cli app stop ~/ArduinoApps/face-usb-classroom
arduino-app-cli app start ~/ArduinoApps/face-usb-classroom

Chrome 重新整理 → 送 20.0／板子收 20.0；F12 主控台每行一次 classification（行尾＝毫秒）；板子看容器 CPU：

docker stats --no-stream

送 8 → AI 5.5 次/秒（CPU 76%）；送 20 → 6.3 次/秒（113%）。瓶頸在 AI 那一層，不在線、不在 kernel。改回：把兩行 sed 的 20 和 8 對調（學生頁第 7 節）。

8　收尾

板子停 App；電腦轉接程式 Ctrl＋C、拆通道；網卡留著、線拔掉

arduino-app-cli app stop ~/ArduinoApps/face-usb-classroom
"$ADB" forward --remove-all

三張證據存好；作業老師上課時會在 e學苑 開。要拿掉網卡（五行、最後一行是 sudo reboot、不是 restart adbd）：學生頁第 8 節的摺疊。

本頁不印板子密碼、板子序號、Wi-Fi；192.168.7.x 是 USB 線上的私人網段，每塊板都一樣。
