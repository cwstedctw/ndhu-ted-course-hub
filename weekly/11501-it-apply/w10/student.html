01 · 選擇工具

Word 和 LaTeX 都能完成文件

Word 適合直接在版面上改字與共同批註；LaTeX 將文字與排版標記寫在純文字原稿，交給排版程式產出 PDF。手機可在表格內左右滑動。

要做的事WordLaTeX
修改與批註直接看版面修改；老師可以追蹤修訂。修改 .tex 原稿，再重新產生 PDF。
版本紀錄.docx 保存版本，差異可用 Word 的比較功能查看。原稿是純文字，Git 可顯示改了哪些字。
引用與書目搭配 Zotero 外掛可自動更新。可用書目檔與引用代號產生；需要設定。

.tex 是 LaTeX 文字原稿；.pdf 是成品。XeLaTeX 是支援中文的排版引擎之一。Overleaf 是瀏覽器中的 LaTeX 編輯與編譯服務。


03 · 第一次動手
用 Overleaf 編譯範本
本課先用 Overleaf，不必安裝 TeX。無法註冊或服務中斷時，先與老師確認備援；中文排版不順可先下載英文備援範本，用 pdfLaTeX 練結構與除錯；再依老師指示完成中文版本。
  1. 下載：下載一頁中文範本（.tex），記住下載位置。內容是虛構示範。可先查看已編譯的中文範例 PDF；英文備援另有英文範例 PDF。
  2. 登入：前往 Overleaf 官網登入。不要把密碼或驗證碼貼給 AI。
  3. 建立：選 New Project → Blank Project，輸入名稱後按 Create；左側會看到 main.tex。
  4. 放入範本：用文字編輯器開啟下載的 履歷.tex，全選複製；回 Overleaf 的 main.tex 全選取代。
  5. 編譯：在專案中開啟齒輪 Settings（設定），或從 File 選單進 Settings；選 Compiler 頁籤，再從 Compiler 下拉選 XeLaTeX，按 Recompile。若使用英文備援範本，改選 pdfLaTeX。成功時右側應顯示一頁 PDF，再用 PDF 下載按鈕存檔。
看不到 PDF？先確認選 XeLaTeX，再看錯誤的檔案和行號。請 AI 幫忙時，只提供不含敏感資訊的錯誤與相關幾行原稿。
依據：建立專案、選編譯引擎、中文排版。


04 · 做自己的版本
把骨架換成你的經驗
  1. 打開 main.tex，把示範文字改成自己的學習、活動或專案經驗；可用化名，不需要填電話、住址或證件號碼。
  2. 至少改兩個結構元素，例如小節標題、清單、段落順序或強調文字。每改一次就按 Recompile。
  3. 核對 PDF 是否為一頁、有沒有缺字、超出邊界或保留虛構範例。事實由你確認。
可複製的 AI 提示詞
我正在用 LaTeX 編輯一頁履歷或申請書。
請先說明下列原稿的結構，再建議如何調整標題與清單。
不要編造我的經驗，也不要加入電話、地址或證件號碼。
如果你不能讀取我的檔案，請直接告訴我。這是我願意提供的原稿片段：
（貼上已去除個人敏感資訊的片段）
AI 的建議要由你核對，不要把真實敏感資料交給未核准的服務。


05 · 出錯也是練習
故意弄壞一行，再把它修好
  1. 下載故意出錯的中文練習檔；英文路線使用英文出錯練習檔。另開專案或另存副本，不要覆蓋自己的作品。
  2. 把內容貼進 main.tex，中文版選 XeLaTeX，英文版選 pdfLaTeX，再按 Recompile。打開錯誤記錄，看檔名、行號與附近標題。
  3. 找找 \section*{ 後面少了什麼。加回一個右大括號 }，再編譯；確認 PDF 真的出現。
  4. 記下錯誤與修正方式。錯誤行號可能靠近原因，不一定精確指向漏掉的字元。

07 · 延伸：文獻管理
Zotero 是什麼？先收對一篇
Zotero 保存作者、題名、年份與 DOI 等書目資料。PDF 是閱讀全文的附件，附件不等於書目條目；插入引用前仍要核對原文。
安裝與第一篇文獻：一步一步做
  1. 從 Zotero 官方下載頁安裝 Windows 或 Mac 桌面版；再為常用瀏覽器安裝 Zotero Connector。Connector 是儲存按鈕，不能取代桌面程式。
  2. 開啟 Zotero，在「我的文獻庫」按右鍵建立文獻集，命名「課堂練習」並選取它。先用練習集，不要讓 AI 操作整個個人文獻庫。
  3. 在瀏覽器打開公開示範文獻，按 Connector 儲存。若失敗，可用 Zotero 魔術棒「依識別碼新增」輸入 DOI 10.1186/s12877-021-02075-3 並按 Enter，等候條目出現。
  4. 回 Zotero 核對題名、作者、年份、期刊與 DOI。Zotero 有時會自動附上 PDF；先展開條目確認，再核對附件是否為正確文章。若沒有全文，可從期刊頁下載 PDF，拖到正確文章條目底下；無 PDF 時先讀期刊網頁全文。
先做本機練習不必同步；例文用來練查證，不代表它支持你寫的每句話。
在 Word 插入引用與文末書目
  1. 開 Windows 或 Mac 的 Word 桌面版並保持 Zotero 開啟。新建文件，確認上方有 Zotero 頁籤；Word 網頁版不能使用這組桌面外掛。
  2. 在句尾選 Add/Edit Citation，選格式，搜尋並選剛加入的文獻；選取後按 Enter，確認引用已出現在句尾。
  3. 在文末加「參考文獻」標題，選 Add/Edit Bibliography。修正 Zotero 條目後回 Word 按 Refresh；換格式用 Document Preferences。
  4. 沒有 Zotero 頁籤時，關閉 Word，在 Zotero 設定的 Cite → Word Processor Plugins 重新安裝，再打開 Word；仍有問題看官方排解。
不要手改自動產生的書目；先更正 Zotero 條目再更新。Unlink Citations 會移除可更新連結，只在需要交付最終副本時確認後使用。

AI 協助規劃的提示詞
我想寫一份關於「填入你的題目」的報告。
請先問我研究問題、目標讀者、篇幅與已找到的來源。
只根據我提供的原文提出大綱；區分作者原文與你的推論。
讀不到全文或找不到出處請標「待查證」；不要編造文獻、DOI、數字或結論。
先提出計畫，讓我檢查後再協助修改段落。
實作：讓一篇文章的引用出現在 LaTeX 文件中
  1. 下載論文示範原稿和練習書目檔。這是教學範例，不是完整研究論文。
  2. 在 Overleaf 建立新的空白專案，把原稿內容貼進 main.tex。從檔案區的上傳功能加入 practice.bib；確認它與 main.tex 位於同一個專案。若無法上傳，可在檔案區選 New file，命名 practice.bib，用文字編輯器開啟下載的書目檔，複製全部內容貼上並儲存。
  3. 選 XeLaTeX 並按 Recompile。檢查正文的引用與文末書目；若出現問號，再次編譯並核對檔案名稱。示範句只說明文章的出版資訊，不代表已證明你自己的研究主張。
  4. 打開 practice.bib 找到 Su2021；它與 main.tex 中的 \cite{Su2021} 必須一致。修改正文時先核對期刊原文與 DOI。
  5. 想換成自己的文獻時，先在 Zotero 核對條目，再匯出 BibTeX 書目檔。上傳自己的 .bib，查看實際引用代號；在 LaTeX 原稿中改成相符的代號。原稿中的 \bibliography{practice} 讀的是 practice.bib：如果新檔名是 myrefs.bib，就同步把原稿改為 \bibliography{myrefs}（不要寫副檔名）。也可在新專案將書目另存為 practice.bib，但先確認不會覆蓋要保留的檔案。不要假設所有文獻都是 Su2021，也不要覆蓋其他專案的書目。
  6. 請 AI 依你提供的原文協助列大綱或修改一段，再逐句比對原文。下載 PDF 前檢查引用、書目、作者與資料；找不到的內容明標待查證。
這個示範含一篇公開文獻；你的課堂報告要用什麼題目、來源數量與格式，以老師公告為準。


之後想用 LaTeX 管理參考文獻？
Zotero 的 Better BibTeX 外掛可把文獻集匯出成 .bib 書目檔；原稿使用引用代號指向書目。參考官方安裝與自動匯出。先用練習文獻集，核對匯出位置與實際代號；不要覆蓋其他專案書目。
若讓 AI 連接 Zotero，權限可能包含修改或刪除。先看授權範圍；練習只要求搜尋與新增，並明講不要自動附 PDF，附件由人回期刊核對後加入。
這是延伸練習，不把期刊論文、Zotero 外掛或本機完整論文管線列成 W10 共同交付要求。
