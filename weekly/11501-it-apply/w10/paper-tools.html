論文工具箱：
四個工具，跑一次

00 · 先看全貌

一篇論文的三件事，四個工具各管一段

論文（paper）的正式成品通常是一份 PDF。從「有想法」到「有 PDF」，工具分工像這樣：

① 畫圖gnuplot 讀資料檔，用純文字腳本畫出 PDF 或 PNG 圖。
② 管文獻Zotero 收集書目、核對原文，匯出成 .bib 書目檔。
③ 排版LaTeX 把文字、圖、引用排成 PDF。線上用 Overleaf，本機用 MiKTeX。
④ 成品一份 PDF；原始碼是純文字，放進 repo 看得出每次改了什麼。
今天只有 Overleaf 是必要的（W10 主教材已經在用）。MiKTeX、Zotero、gnuplot 都是「知道它在哪、裝得起來、跑過一次」就好。

02 · 安裝

每個工具裝完都有一句「怎麼確認真的裝好」

裝完不要只看「安裝完成」畫面。下面每一段最後一步是驗證：開終端機（Windows 叫「命令提示字元」或「PowerShell」，Mac 叫「終端機」）打一行指令，有回版本號才算數。

Overleaf（免安裝）
  1. 到 overleaf.com 用學校信箱或個人信箱註冊、登入。不要把密碼或驗證碼貼給 AI。
  2. 新專案：New Project → Blank Project。左側 main.tex 就是你的原稿。
  3. 中文稿要在 Menu → Settings → Compiler 選 XeLaTeX。
  4. 驗證：按 Recompile，右側出現 PDF。

W10 主教材的第 03 段有逐步截圖說明，可回去看。

MiKTeX（Windows）
  1. 到 miktex.org/download，下載 Basic Installer（檔名像 basic-miktex-25.12-x64.exe）。Basic 版先裝核心，缺的套件之後自動補；Net Installer 是一次下載全部，很大，今天不需要。
  2. 執行安裝檔。遇到「Install missing packages on-the-fly」選 Yes，第一次編譯時它才會自己把缺的套件抓下來。
  3. 裝完開 MiKTeX Console，按 Check for updates 更新一次。
  4. 驗證：重新開一個命令提示字元，輸入 xelatex --version，第一行要出現 MiKTeX 與版本號。
第一次編譯中文稿會很慢（可能一兩分鐘），因為它在下載 xeCJK 等套件；不是當機。
LaTeX 本機版（Mac）
  1. MiKTeX 官網也提供 Mac 磁碟映像檔（Drag'n'Drop installer），但 2026-11 當時那份是 2022 年的 Intel 版。Apple 晶片（M1 以後）的 Mac 建議改裝 TeX 社群的 MacTeX；它有一份只含核心的小版本 BasicTeX，夠本課用。
  2. 裝完關掉再重開終端機。
  3. 驗證：輸入 xelatex --version，出現 TeX Live 與年份即可。

教室電腦與老師示範以 Windows 為主，Mac 同學卡住先用 Overleaf，不影響交付。

Zotero（Windows／Mac）
  1. 到 zotero.org/download，左邊下載 Zotero 桌面版（Windows 64-bit 或 macOS），右邊為你的瀏覽器裝 Zotero Connector。Connector 只是瀏覽器上的「存入」按鈕，沒有桌面版它存不進去。
  2. 開 Zotero，在「我的文獻庫」按右鍵 新增文獻集，命名「課堂練習」。
  3. 驗證：按工具列的魔術棒「依識別碼新增」，貼 DOI 10.1186/s12877-021-02075-3 按 Enter；條目出現、作者六位、期刊 BMC Geriatrics，代表桌面版正常。
  4. 要在 Word 用：Zotero 設定 → Cite → Word Processor Plugins 確認已安裝；開 Word 桌面版看到 Zotero 頁籤。
gnuplot（Windows）
  1. 到 SourceForge gnuplot 下載區，點最新的 6.0.x 資料夾，下載檔名像 gp60x-win64-mingw.exe 的安裝檔。
  2. 執行安裝。看到 Add application directory to your PATH environment 這個選項要打勾，之後才能在任何資料夾直接打 gnuplot。
  3. 裝完重新開一個命令提示字元（舊視窗讀不到新的 PATH）。
  4. 驗證：輸入 gnuplot --version，出現 gnuplot 6.0 patchlevel …。
gnuplot（Mac）
  1. 先有 Homebrew（Mac 的套件管理工具）。沒有的話照它首頁那一行指令安裝，會問一次密碼。
  2. 終端機輸入 brew install gnuplot，等它跑完。
  3. 驗證：gnuplot --version 出現 6.0 系列版本號。
03 · 十分鐘示範

三個檔，做出一張圖加一筆引用的一頁 PDF

老師課堂會跑一次。你照做時只需要 Overleaf 加上一台裝了 gnuplot 的電腦；沒裝 gnuplot 的人，第一步跳過，直接用老師給的 現成圖檔。

下載四個檔

  • figure-data.dat：示範資料（虛構），八週兩組的錯誤數。
  • figure-demo.gp：gnuplot 腳本，讀上面的資料畫圖。
  • paper-with-figure.tex：一頁論文原稿，放圖加引用。
  • practice.bib：書目檔，W10 主教材用過的同一份。

完成的樣子

一頁 PDF：標題、兩段文字、圖 1（折線圖）、文末一筆參考文獻。看老師編譯好的範例 PDF。

圖裡的字用英文，因為 gnuplot 的中文字型每台電腦不同，先求圖出得來。

步驟一：gnuplot 畫圖（約 2 分鐘）

  1. 把 figure-data.dat 和 figure-demo.gp 放在同一個資料夾。
  2. 終端機進到那個資料夾，輸入：
    gnuplot figure-demo.gp
  3. 資料夾多出 figure-demo.pdf，打開看是一張折線圖。
腳本在做什麼（逐行白話）
set terminal pdfcairo size 10cm,7cm   ← 輸出成 PDF、指定尺寸
set output "figure-demo.pdf"          ← 檔名
set title / xlabel / ylabel            ← 圖名、座標軸名
set grid                               ← 加格線
plot "figure-data.dat" using 1:2 ..., \
     "figure-data.dat" using 1:3 ...   ← 第 1 欄當 x，第 2、3 欄各畫一條線
set output                             ← 關檔，PDF 才寫完整

試試看：把 figure-data.dat 某一列的數字改掉，再跑一次，圖就變了。這就是「資料改、圖自動更新」。

步驟二：LaTeX 排版（約 5 分鐘）

  1. Overleaf 開 New Project → Blank Project。把 paper-with-figure.tex 的內容全選複製，貼進 main.tex 取代原本內容。
  2. 左側檔案區按 Upload，把 practice.bib 和 figure-demo.pdf 兩個檔傳上去。三個檔要在同一層。
  3. Menu → Settings → Compiler 選 XeLaTeX，按 Recompile。Overleaf 會自動幫你跑書目與第二次編譯。
  4. 右側 PDF 要看到：「圖 1」有圖、正文有 [1]、文末有參考文獻。三樣都在才算完成。
本機（MiKTeX）要打四行
xelatex paper-with-figure
bibtex  paper-with-figure
xelatex paper-with-figure
xelatex paper-with-figure

為什麼跑兩次 xelatex？第一次它還不知道圖號、引用號是多少，先記在輔助檔；第二次才填回正文。只跑一次會看到「圖 ??」和「[?]」。

步驟三：換成自己的文獻（約 3 分鐘，有 Zotero 才做）

  1. 在 Zotero 的「課堂練習」文獻集按右鍵 匯出文獻集，格式選 BibTeX，存成 myrefs.bib。
  2. 用文字編輯器打開 myrefs.bib，看每筆開頭 @article{代號, 的代號是什麼。Zotero 自動產生的代號跟 Su2021 不一樣。
  3. 上傳 myrefs.bib 到 Overleaf；把原稿的 \bibliography{practice} 改成 \bibliography{myrefs}（不寫副檔名），\cite{Su2021} 改成你的代號。
  4. Recompile。文末書目換成你的文獻，就接通了「Zotero → LaTeX」這條線。

小測：Recompile 之後正文出現 [?]，最可能是什麼？

選一個答案。
04 · 為什麼

這一套的好處，要等稿子改第三版才看得出來

  • 資料改了，圖跟著改。用 Excel 畫圖貼進 Word，資料一改要重貼一次、還要對齊；gnuplot 腳本重跑一次就好，而且腳本是純文字，放進 repo 看得出你改了哪個座標軸。
  • 文獻改了，書目跟著改。手打參考文獻最容易漏一筆或格式不一致；Zotero 改一筆、Word 按 Refresh 或 LaTeX 重編，全文更新。
  • 原稿是純文字。這是 W2 講的那件事：改一個字，只有純文字說得出差在哪。.tex、.gp、.bib 都是純文字，期末放進 repo 的 commit 會真的有內容。
  • 但不是什麼都該用 LaTeX。老師要在檔案裡直接批註、對方只收 Word、或只是一頁通知，Word 比較快。工具選擇卡就是在練這個判斷。
05 · 卡住怎麼辦

先看錯誤訊息，再決定問誰

看到什麼通常是怎麼處理
'gnuplot' 不是內部或外部命令（Windows）安裝時沒勾 PATH，或還在用舊的終端機視窗重開一個終端機再試；還是不行就重跑安裝檔、勾選 PATH 那項
can't read data file "figure-data.dat"終端機所在的資料夾不是放資料檔的那個用 cd 進到放檔案的資料夾，或把兩個檔搬到一起
gnuplot 說 warning: iconv failed to convert degree sign只是字元轉換提醒不影響輸出，PDF 照樣產生，可以忽略
! LaTeX Error: File 'figure-demo.pdf' not found圖檔沒上傳，或檔名大小寫不同看 Overleaf 左側檔案區有沒有那個檔；名字要跟原稿裡寫的一模一樣
正文出現 [?]、文末沒書目，或 Citation 'Su2021' undefined代號跟 .bib 對不上，或書目還沒跑完核對 \cite{…} 跟 .bib 的代號；再按一次 Recompile；本機要跑 bibtex 加兩次 xelatex
圖出現「圖 ??」只編譯了一次再 Recompile 一次
MiKTeX 第一次編譯卡很久在下載缺的套件等它跑完；看 MiKTeX Console 有沒有在下載
Zotero Connector 按了沒反應桌面版沒開先開 Zotero 桌面版再按；或用「依識別碼新增」貼 DOI

請 AI 幫忙時，只貼不含個資的錯誤訊息與相關幾行原稿；AI 說「修好了」之後，自己 Recompile 一次、打開 PDF 看，才算修好。
