證據卡怎麼寫？

以下是虛構的本機模擬範例，不是真實學生紀錄，也不是 GitHub commit。

1. 存得住

今天的路徑：本機模擬。

第一版 v1：放入任務分類紀錄，保存練習起點。雨天安排寫「雨天到圖書館」。

第二版 v2：練習故意改壞一行，把雨天地點改成「操場」，保留前一版，才能練救回。

2. 看得懂差異

原本：雨天到圖書館。

後來：雨天到操場。

只有地點改了，其他內容相同。

3. 救得回來

我選 v1，因為 v2 是故意改壞的練習版。我從 v1 複製內容回 working，打開目前檔案，讀到「雨天到圖書館」。v1 與 v2 都留著。

在實作中，做到這一步後才勾「我打開目前檔案確認過」。沒有做的動作不要先勾。

4. 網址，或卡關

目前狀態：網站範本能在本機開啟，還沒有公開網址。

卡關登記：GitHub 驗證信尚未到，今天先走本機路徑。願意公開的網站檔會依教師指示交到 e學苑，由教師依課程固定發布安排提供網址。

課內先記錄半成品，差異或救回還沒完成的欄位可以寫「W3 前補」。這份範例不新增繳交要求。
