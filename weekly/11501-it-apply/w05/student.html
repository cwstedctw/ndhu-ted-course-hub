2. 先拿到範本

  1. 下載 報告範本_W5.docx，用 Word 打開。上方出現黃色的「受保護的檢視」就按「啟用編輯」。

範本裡黃底、用【】括起來的段落是要你換掉的地方，其他文字是示範用的範例資料（虛構），可以留著。

換掉黃底那段的方法：先把整段選起來按 Delete 刪掉，再打字或插入。直接打字蓋過去，你打的字會跟著變黃底。

3. 一步一步做（Word）

步驟 1｜看骨架。 「檢視」索引標籤，勾「功能窗格」（View → Navigation Pane；也可以按 Ctrl＋F）。

你應該看到左邊列出「一、研究動機」「（一）想知道的事」這些標題，點一下就跳過去。這就是套了標題樣式的效果。

步驟 2｜產生目錄。 第 1 頁「目錄」下面那一行寫著「目錄還沒產生」，在那一行按右鍵 →「更新功能變數」（Update Field）。

你應該看到一份有頁碼的目錄。按住 Ctrl 點目錄裡的標題，會跳到那一頁。

步驟 3｜自己試那一擊：圖連同圖說對調。 第三節「三、結果」有圖 1 和圖 2。

  1. 把滑鼠移到圖 1 圖片左邊的空白處（游標變成往右上的箭頭），按住往下拖到「圖 1 …」那行圖說，圖片和圖說兩段一起反白。
  2. Ctrl＋X 剪下。
  3. 在「圖 2 …」那行圖說的下一段開頭點一下（就是「從圖 2 可以看到」那一段的最前面），Ctrl＋V 貼上。
  4. Ctrl＋A 全選，按 F9。跳出「更新目錄」就選「更新整個目錄」→ 確定。別選「只更新頁碼」：它只改數字，改過的標題字不會跟著變。

你應該看到兩張圖的號碼互換了；正文的「如圖 X 所示，每週練習時間……」也跟著變，指的還是那張長條圖。

只搬圖片、沒帶圖說，號碼不會動（見第 5 節）。這一步做完要不要對調回來都可以。

步驟 4｜加你自己的一張圖。 到「（一）我新增的圖與表」的第一段黃底【】：

  1. 選起那段按 Delete，再「插入 → 圖片 → 此裝置」（Insert → Pictures → This Device）；也可以用 Win＋Shift＋S 截一張圖，再 Ctrl＋V 貼上。想讓圖置中，點圖片按 Ctrl＋E。
  2. 點一下圖片，「參考資料 → 插入標號」（References → Insert Caption）。
  3. 「標籤」選「圖」。清單裡沒有「圖」，就按「新增標籤」，輸入 圖 → 確定。
  4. 「位置」選讓圖說在圖片下面的那一項。在「標號」那一格的「圖 3」後面空一格，打你的說明 → 確定。

你應該看到圖片下方出現「圖 3　你的說明」。點那個 3 會出現灰底，代表它是功能變數（field），不是手打的字。

截的是別人的網頁或圖表，步驟 7 要把出處寫進參考文獻。

步驟 5｜加一張表。 第二段黃底【】：

  1. 選起那段按 Delete，「插入 → 表格」，拉一個 3×3 的表，填幾格內容。
  2. 點表格裡任一格，「參考資料 → 插入標號」，「標籤」選「表」（沒有就新增標籤「表」），「位置」選讓說明在表格上面的那一項，打說明 → 確定。

你應該看到表格上方出現「表 2　你的說明」。

步驟 6｜用交互參照寫「如圖 3 所示」。 第三段黃底【】選起來按 Delete，換成一句你自己的話：

  1. 打「如」。
  2. 「插入 → 交互參照」（Insert → Cross-reference）。「參考資料」索引標籤的「標號」群組也有同一顆按鈕。
  3. 「參照類型」選「圖」，「插入參照類型的」選「僅標籤及數字」。「以超連結插入」預設是勾著的，保持勾著（之後按住 Ctrl 點才會跳過去）。下面清單點你的圖 →「插入」，再關掉對話框。
  4. 接著打「所示，……」。表也照做一次，例如「數字整理在表 2」。

你應該看到「如圖 3 所示」。按住 Ctrl 點「圖 3」，會跳到那張圖。

步驟 7｜加一筆查得到的來源。

  1. 「參考資料」索引標籤，「樣式」選 APA。
  2. 游標放在要引用的那句話後面，「插入引文 → 新增來源」，「來源類型」選網站，填作者（或機構）、名稱、年份、網址 → 確定。
  3. 到最後的「參考文獻」，選起黃底那段按 Delete，「參考資料 → 書目 → 插入書目」。

你應該看到正文那句後面出現 (作者, 年份)，參考文獻下面出現你那一筆。

引文功能用不了，就照這個格式手打一行：作者（年份）。標題。網站名稱。網址。不管哪一種，網址都要點得開。AI 給你的來源，先點開確認網頁真的存在、裡面真的有那句話。

步驟 8｜替代文字（alt text）。 在你的圖上按右鍵 →「檢視替代文字」（舊版叫「編輯替代文字」），寫一句這張圖在說什麼，例如「長條圖：第 1 到第 5 週的練習時間從 30 分鐘增加到 90 分鐘」。

可以按「為我產生替代文字」或請 AI 給一句，但要自己對照圖片核對：圖的種類、數字、趨勢對不對。範本的圖 1、圖 2 已經寫好，可以點開參考。

步驟 9｜全部更新一次。 Ctrl＋A → F9 →「更新整個目錄」→ 確定（「只更新頁碼」不會改標題字）。確認黃底【】都換掉了，再 Ctrl＋S 存檔。

你打的字如果變黃底：選起來，「常用 → 文字醒目提示色彩」的下拉箭頭 →「無色彩」。

步驟 10｜匯出 PDF。 「檔案 → 匯出 → 建立 PDF/XPS」，檔名 報告_v2.pdf。按「選項」，勾「使用下列項目建立書籤」、選「標題」→ 確定 →「發佈」。

你應該看到PDF 左側的書籤列出你的標題，目錄有頁碼。

4. 互查：跟隔壁交換看 PDF

  • 目錄有頁碼，而且跟正文的頁碼對得上。
  • 圖、表的號碼從 1 開始，沒有跳號。
  • 每個「如圖 N 所示」「表 N」指到的是對的那一張。
  • 參考文獻的網址點得開。
  • 你的圖有替代文字（PDF 上看不到，回 Word 按右鍵確認）。

6. Google 文件備援

Google 文件沒有自動的圖說編號和交互參照，這條路的號碼是手打的：算備援，不算自動交叉引用。標題樣式、目錄、替代文字、PDF 都做得到。

  1. 把範本上傳到 Google 雲端硬碟，用 Google 文件開啟；上方檔名旁出現 .DOCX 字樣，就按「檔案 → 另存為 Google 文件」再做。
  2. 標題：「格式 → 段落樣式 → 標題 1／標題 2」。
  3. 目錄：「插入 → 目錄」。改了標題後，點目錄旁的重新整理按鈕。
  4. 圖說：在圖片下面自己打，格式固定：「圖 3　說明」（圖、空格、號碼、全形空格、說明）。表的說明放表格上面：「表 2　說明」。
  5. 「如圖 3 所示」也是自己打。改了圖表順序，每一個號碼都要自己重新檢查。
  6. 來源：照步驟 7 的格式手打，一樣要附網址。
  7. 替代文字：圖片按右鍵 →「替代文字」。
  8. 交件：「檔案 → 下載」，各下載一次 Microsoft Word（.docx）和 PDF 文件（.pdf）。
