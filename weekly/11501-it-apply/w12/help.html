Zotero

看到什麼通常是怎麼處理
按 Connector 沒反應，或說「Is Zotero running?」Zotero 桌面版沒開先把桌面版打開、再按一次。還是不行，照官方的 Is Zotero Running? 說明：把瀏覽器整個關掉重開；擴充功能的「網站存取權」設成所有網站（On all sites）；暫時關掉廣告阻擋類的擴充功能
按了 Connector，卻要我授權 zotero.org 帳號它找不到桌面版，改問你要不要存到網路上的文獻庫有裝桌面版的：先打開桌面版再按。沒裝的：照 教室電腦怎麼辦 第二列授權
工具列找不到 Connector裝好後藏在拼圖圖示裡；或你用的是 Edge，卻只裝了 Chrome 版拼圖 → 圖釘釘出來；用 Edge 就裝 Edge 版，或改用 Chrome
存進來了，但不在 W12-sleep存的時候左邊選的不是 W12-sleep在「我的文獻庫」找到那一筆，拖到左邊 W12-sleep 上放開。下次先點選 W12-sleep 再存
Google Scholar 要我證明不是機器人全班同一個網路位址，查太多次（官方說明）改用 PubMed 或直接用 DOI；Scholar 通常幾小時後會恢復
魔術棒說查詢失敗（Lookup Failed）DOI 貼錯，或前後多了空白回步驟頁（今天這篇在第 3 步）按 DOI 旁的「複製」鈕重貼，只貼 10. 開頭那一串
匯出選單是灰的那個文獻集是空的先確認 W12-sleep 裡真的有那一筆
教室電腦要管理員密碼、裝不了 Zotero教室電腦鎖住安裝看 教室電腦怎麼辦，別硬試
Overleaf 句子後面是 [?]代號或 .bib 檔名對不上回 1-6 打開 .bib 抄代號，一個字都不能差；再 Recompile
Overleaf 中文變方框、或一堆紅字Compiler 不是 XeLaTeX齒輪 Settings → Compiler 改 XeLaTeX，再 Recompile

gnuplot

看到什麼通常是怎麼處理
Windows 說找不到 gnuplot（不是內部或外部命令、無法辨識）上週裝的版本不會自己加進 PATH；或終端機是安裝前就開的關掉終端機重開；還是不行就用完整路徑：& "C:\Program Files\gnuplot\bin\gnuplot.exe" scatter.gp（見 2-1）
can't read data file "sleep-quiz.dat"終端機不在練習包資料夾裡回 2-1，在看得到 sleep-quiz.dat 的那一層按右鍵開終端機
雙擊 .gp 檔，黑色視窗一閃就關雙擊會跑完腳本馬上結束，看不到訊息不要雙擊，照 2-1 在終端機打指令；跑完看資料夾裡的 PNG 修改時間
跑完沒報錯，圖看起來沒變開著的是舊圖，或改完 .gp 沒存檔記事本按 Ctrl＋S 存檔；圖片視窗關掉重開
把圖上的字改成中文，變方框或亂碼gnuplot 找不到那台電腦的中文字型今天圖上的字維持英文；中文說明寫在報告的圖說裡
warning: iconv failed to convert degree sign只是字元轉換提醒可以忽略，圖照樣產生
電腦根本沒有 gnuplot教室電腦沒裝，筆電也沒裝用練習包裡老師畫好的兩張圖做 2-4；有筆電的同學可以兩人一組

問 AI 可以，但照這三條

  1. 不貼密碼、驗證碼。
  2. 只貼錯誤訊息，跟相關的那幾行。
  3. AI 說「好了」，你自己再跑一次、打開看，才算好。

Zotero 裝不了，怎麼辦

照順序試，哪一條通了就用哪一條。不管走哪一條，1-5 的核對都要做。

情況改走這條
有自己的筆電改用筆電做第一部分，最省事。
電腦不讓裝軟體，但 Chrome 可以裝擴充功能存到網路上的文獻庫：到 zotero.org 註冊帳號（要收確認信）、登入。照 1-3 裝 Connector。Zotero 桌面版沒開的時候，按 Connector 會請你授權連到 zotero.org 帳號，授權後就存進網路上的文獻庫。存好後到 zotero.org 的 Web Library，選取那一筆，用上方工具列的匯出（Export）圖示、格式選 BibTeX，就能拿到 .bib。
要帳號、要收信，不是零設定；下課記得登出。
連 Chrome 擴充功能也裝不了跟旁邊有筆電的同學一組，看他做一遍；你自己用練習包的 okano2019-teacher.bib 當證據 ②，打開它跟 nature.com 網頁核對作者、年份、期刊（你會發現它少了文章編號）。證據 ① 改交「核對時的畫面截圖」。
