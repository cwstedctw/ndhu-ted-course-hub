先看你們的簡報，再請 AI 把它變好看

資訊科技與應用 W4（AB 班）。2026/09/29（二）16:10–18:00，17:00 休息 10 分鐘。

今天兩件事：先看兩位同學上週用 Antigravity 做的簡報，再幫 Antigravity 裝一個 UI／UX 設計技能（skill），請它把你的簡報改得更好看。

今天的完成線：同一頁簡報，改版前、改版後各一張截圖。內容文字不變，外觀變了。

2. 三個名詞

  • UI（使用者介面，User Interface）：畫面長怎樣——配色、字型、版面、留白。
  • UX（使用者經驗，User Experience）：用起來順不順——看得清楚、重點一眼找到、不迷路。
  • skill（技能）：一個資料夾，裡面一份 SKILL.md 說明書。裝進專案的 .agents/skills/ 之後，Antigravity 做相關工作時會自己去翻。今天用的是公開的 UI UX Pro Max（GitHub 頁面），內建上百種風格、配色、字型搭配。

3. 路線 A：一步一步裝 skill、改簡報

步驟 1｜打開上週的簡報資料夾。 Antigravity 左上 File → Open Folder，選上週簡報所在的那個資料夾。之後的每一步都在這個資料夾裡做。

步驟 2｜先截一張「改版前」。 把簡報打開，挑一頁截圖存好。等一下要跟改版後比。

步驟 3｜查前置。 在 Antigravity 的對話框貼這段：

幫我檢查這台電腦有沒有 Node.js 和 Python 3，只回報版本號。缺哪一個就告訴我，不要自己安裝。

兩個都有 → 繼續步驟 4。缺任何一個 → 改走第 4 節路線 B，不要現場硬裝。

步驟 4｜請它裝 skill。 貼這段：

在目前這個資料夾執行這行指令，把 UI UX Pro Max skill 裝進這個專案：
npx -y ui-ux-pro-max-cli init --ai antigravity
裝好之後，列出 .agents/skills 底下有哪些資料夾。

它要執行指令前會先問你——看清楚是這一行再按同意（叫 AI 做事的第二件事）。裝好會看到 ui-ux-pro-max 等幾個資料夾，大約十秒。

步驟 5｜確認它認得。 開一個新對話，貼：

你現在有哪些 skill 可以用？用中文列出名字就好。

清單裡有 ui-ux-pro-max 就對了。沒有 → 關掉 Antigravity 再開、重新打開同一個資料夾，再問一次。

步驟 6｜一行提示詞，讓它改版。 貼這段（開頭的 /ui-ux-pro-max 是叫它用這個 skill）：

/ui-ux-pro-max 讓我的簡報更好看，文字內容一個字都不要改

它要改檔前會先問你，看它列的檔案對不對再按同意。後面那半句不能省——老師試過，只說「更好看」，它會自己多加一行你沒寫的字。

想要自己的風格？ 在中間加三樣：這份簡報在講什麼、給誰看、你要的風格（skill 的說明寫它會看這三樣來選設計）。例如：

/ui-ux-pro-max 讓我的簡報更好看。這是一份教大家判斷假新聞的簡報，給大學生看，風格用 Claymorphism，要活潑、親切。文字內容一個字都不要改

風格名用英文最準（skill 裡內建 88 種，下面挑幾個好認的）：

Minimalism & Swiss Style極簡、大留白、很專業

Claymorphism黏土、圓潤、可愛

Cyberpunk UI賽博龐克、暗色螢光

Memphis Design80 年代、幾何色塊、活潑
Vaporwave蒸氣波、粉紫漸層
Bauhaus包豪斯、紅黃藍幾何
Editorial Grid / Magazine雜誌排版
Pixel Art像素遊戲風

不喜歡就再說一次：「換成 Bauhaus 風格，文字一樣不要改。」同一份內容換兩三種風格比一比，挑你最喜歡的那張截圖。

步驟 7｜自己驗三件事，截「改版後」。

  1. 字夠大嗎？站遠一點看得清楚嗎？
  2. 顏色看得清楚嗎？字跟背景的對比夠不夠？
  3. 內容跟改版前一樣嗎？被它偷改的，叫它改回來：「第 3 頁那句被你改了，還原成原本的字。」

同一頁截一張改版後，跟步驟 2 那張放在一起。

4. 路線 B：不裝 skill，直接講

在 Antigravity（或老師核可的網頁版聊天 AI，把簡報內容貼進去）貼這段：

幫我把這份簡報改得更好看，先給我兩套方案、不要改檔：
- 選一種明確的風格（例如深色科技感、清爽雜誌風）
- 配色 3 到 4 個顏色，字和背景對比要夠
- 標題大、內文至少 28px，一頁一個重點
- 只改外觀和版面，文字內容一個字都不要改

挑一套之後，說「用這套改，文字內容一個字都不要改」，再照路線 A 的步驟 7 自己驗三件事、截改版前後。
