1螢幕是一張格子紙

128 欄 × 64 列，每一格只記「亮」或「暗」——電腦裡最小的單位就是一個 1 或 0，叫位元（bit）。

畫面＝範例 07 的 show() 真的送出去的 1024 個位元組（跟 Wokwi 螢幕逐點比對過，0 點不同）。把滑鼠移到螢幕上，或用手指點一下。

128 × 64
橫 128 點、直 64 點
8192 點
每一點 1 個位元：亮＝1、暗＝0
1024 位元組
8 個位元＝1 個位元組（byte）；8192 ÷ 8 ＝ 1024
指到螢幕上的任何一點，這裡會說它在第幾欄、第幾列、是 1 還是 0。

這就是投影片第 6 頁說的：text()、rect() 只畫在 ESP32 的記憶體裡，show() 才把這 1024 個位元組一次從兩條線送進螢幕。位元組寫給人看時，常用十六進位（hex）：兩個字（0–9、A–F）剛好是一個位元組，例如 0x7C。

2位元 ↔ 點：點一格，看它住在哪個位元組

8 個點湊成一個位元組，但「哪 8 點」有兩種約定：橫著湊，或直著湊。同一張圖，兩種寫法的位元組完全不一樣。下面的 MONO_HLSB（橫著存）、MONO_VLSB（直著存）只是 MicroPython 給這兩種排法取的代號，不用背。

格子 範例
按一格：切換亮暗，並標出它在下面兩種排法裡是哪個位元組的哪一位。按一個位元組：標出它管的那 8 點。

橫著存 MONO_HLSB 一列從左到右，每 8 點一個位元組；最左邊那點是最高位

直著存 MONO_VLSB 一直欄 8 點一個位元組；最上面那點是 bit 0（SSD1306 自己的排法）

直著存寫成二進位時，最下面那點寫在最左邊——所以投影片第 2 頁說「由下往上讀」。「A」的第 2 欄由下往上是 0 1 1 1 1 1 0 0 ＝ 0x7C。

# -*- coding: utf-8 -*-
r"""把一張圖變成 OLED 用的點陣（MONO_HLSB），印出可以直接貼進 main.py 的 bytearray。

怎麼跑（Windows；要先裝 Pillow：py -m pip install pillow。沒有 py 指令的電腦，把 py 換成 python）：
    py image_to_hex.py "我的圖.png"
    py image_to_hex.py "我的圖.png" --size 64x64 --threshold 100
    py image_to_hex.py "D:\圖片\白底黑線.jpg" --size 32x32 --invert
檔名或路徑有空白、有中文，整串用引號包起來。

五個步驟：讀圖 → 變灰階、縮到螢幕大小 → 每一點判斷黑或白 → 八點組成一個位元組 → 印成十六進位。
"""
import argparse
import json
import keyword
import os
import re
import sys

from PIL import Image, ImageOps


def size(s):               # 寬x高：x、X、× 都可以；這塊螢幕最大 128x64
    m = re.fullmatch(r'\s*(\d+)\s*[xX×]\s*(\d+)\s*', s)
    if not m or not (0 < int(m[1]) <= 128 and 0 < int(m[2]) <= 64):
        raise argparse.ArgumentTypeError(f'大小要寫成「寬x高」，寬 1～128、高 1～64，例如 128x64、64x64（你打的是 {s}）')
    return int(m[1]), int(m[2])


def threshold(s):          # 門檻只能是 0～255 的整數
    if not s.isdigit() or int(s) > 255:
        raise argparse.ArgumentTypeError(f'門檻要是 0～255 的整數，例如 128（你打的是 {s}）')
    return int(s)


def name(s):               # 變數名稱：英文字母、數字、底線，不能數字開頭、不能是 Python 保留字
    if not s.isidentifier() or keyword.iskeyword(s):
        raise argparse.ArgumentTypeError(f'變數名稱只能用英文字母、數字、底線，不能數字開頭，例如 SEA、CAT_1（你打的是 {s}）')
    return s


p = argparse.ArgumentParser(description='圖片 → OLED 點陣（MONO_HLSB）')
p.add_argument('image', help='圖檔（png、jpg 都可以）')
p.add_argument('--size', type=size, default=(128, 64), help='縮成「寬x高」，例如 128x64、64x64、32x32、16x16')
p.add_argument('--threshold', type=threshold, default=128, help='門檻 0–255：灰階 ≥ 門檻就算「亮」')
p.add_argument('--invert', action='store_true', help='黑白顛倒（原圖是白底黑線時用）')
p.add_argument('--name', type=name, default='IMG', help='印出來的變數名稱，例如 SEA')
p.add_argument('--no-import', action='store_true', help='不印 import framebuf（同一個 main.py 已經有一次時用）')
p.add_argument('--json', help='（選用）把每一步的中間結果存成 JSON，網頁的逐步模擬用')
a = p.parse_args()
W, H = a.size

# 步驟 1：讀圖。透明的地方先墊黑色（OLED 不亮的地方就是黑的）
try:
    src = Image.open(a.image).convert('RGBA')
except OSError:
    sys.exit(f'打不開這個圖檔：{a.image}\n檔名有空白或中文的話，整串用引號包起來，例如 "我的圖.png"')
bg = Image.new('RGBA', src.size, (0, 0, 0, 255))
src = Image.alpha_composite(bg, src)

# 步驟 2：變灰階（每點 0 黑～255 白），再等比例縮到 W×H 以內，置中，旁邊補黑
gray_img = ImageOps.contain(src.convert('L'), (W, H))
canvas = Image.new('L', (W, H), 0)
canvas.paste(gray_img, ((W - gray_img.width) // 2, (H - gray_img.height) // 2))
gray = [[canvas.getpixel((x, y)) for x in range(W)] for y in range(H)]

# 步驟 3：每一點跟門檻比，夠亮就是 1（螢幕上這點亮）；--invert 就反過來
bits = [[(1 if g >= a.threshold else 0) ^ (1 if a.invert else 0) for g in row] for row in gray]

# 步驟 4：橫著存（MONO_HLSB）：一列從左到右，每 8 點組成 1 個位元組，最左邊那點是最高位
data = []
for row in bits:
    for x0 in range(0, W, 8):
        byte = 0
        for x in range(x0, x0 + 8):
            byte = byte * 2 + (row[x] if x < W else 0)   # 寬度不是 8 的倍數，最後補 0
        data.append(byte)

# 步驟 5：印成十六進位，一列一行，整段可以直接貼進 main.py（裡面已經有 import framebuf）
per_row = (W + 7) // 8
print(f'# 由 image_to_hex.py 產生：{os.path.basename(a.image)} → {W}×{H}，門檻 {a.threshold}'
      + ('，黑白顛倒' if a.invert else '') + f'，共 {len(data)} 位元組')
if not a.no_import:
    print('import framebuf')
print(f'{a.name}_W, {a.name}_H = {W}, {H}')
print(f'{a.name} = bytearray(')
for y in range(H):
    row = data[y * per_row:(y + 1) * per_row]
    print("    b'" + ''.join(f'\\x{v:02x}' for v in row) + "'")
print(')')
print(f'# 用法：fb = framebuf.FrameBuffer({a.name}, {a.name}_W, {a.name}_H, framebuf.MONO_HLSB)')
print('#       oled.blit(fb, x, y); oled.show()')

if a.json:
    with open(a.json, 'w', encoding='utf-8') as f:
        json.dump(dict(image=os.path.basename(a.image), w=W, h=H, threshold=a.threshold, invert=a.invert,
                       src_size=list(Image.open(a.image).size), fit=[gray_img.width, gray_img.height],
                       gray=gray, bits=bits, bytes=data), f, ensure_ascii=False)

5中文字怎麼上螢幕

  
內建的 text() 只有一套 96 格的 8×8 字型，對應可列印的 ASCII 32–126 號（英文字母、數字、標點）；最後一格在這個韌體是缺字方框。中文要自己準備每一個字的點陣圖（bitmap），再用 blit() 貼上去。

  

    

      
先試試看：直接 oled.text('東', 0, 0) 會怎樣？

      

      
Wokwi 韌體實測：畫出三個方格，共 96 個亮點。因為「東」存成 UTF-8 要 3 個位元組，text() 一個位元組畫一格，查不到字型的就畫成這個方格。所以中文不是「顯示不出來」，是變成一排方格。

# -*- coding: utf-8 -*-
r"""把中文字變成 OLED 用的點陣（16×16 或 12×12），印出可以直接貼進 main.py 的程式。

怎麼跑（Windows；要先裝 Pillow：py -m pip install pillow。沒有 py 指令的電腦，把 py 換成 python）：
    py zh_font_to_bitmap.py 東華創客
    py zh_font_to_bitmap.py 東華創客 --size 12 --threshold 80
    py zh_font_to_bitmap.py 東華創客 --font "D:\fonts\你下載的字型.ttf"

五個步驟：開字型 → 把字畫在小畫布上 → 每一點判斷黑或白 → 八點組成一個位元組 → 印成十六進位。
"""
import argparse
import json
import os
import sys

from PIL import Image, ImageDraw, ImageFont


def threshold(s):          # 門檻只能是 0～255 的整數
    if not s.isdigit() or int(s) > 255:
        raise argparse.ArgumentTypeError(f'門檻要是 0～255 的整數，例如 80（你打的是 {s}）')
    return int(s)


p = argparse.ArgumentParser(description='中文字 → OLED 點陣（MONO_HLSB）')
p.add_argument('text', help='要轉的字，例如 東華創客')
p.add_argument('--font', default=r'C:\Windows\Fonts\msjh.ttc', help='字型檔（.ttf／.ttc），預設＝Windows 的微軟正黑體')
p.add_argument('--size', type=int, default=16, choices=[12, 16], help='一個字幾點寬、幾點高：16 或 12')
p.add_argument('--threshold', type=threshold, default=80, help='門檻 0–255：灰階 ≥ 門檻就算「亮」')
p.add_argument('--json', help='（選用）把每一步的中間結果存成 JSON，網頁的逐步模擬用')
a = p.parse_args()
N = a.size
if not a.text.strip():
    p.error('要轉的字是空的，例如：py zh_font_to_bitmap.py 東華創客')

# 步驟 1：開字型。字的大小設成 N 點，一個中文字剛好佔滿 N×N 的格子
try:
    font = ImageFont.truetype(a.font, N)
except OSError:
    sys.exit(f'找不到字型（或打不開）：{a.font}\nWindows 可以先試 --font C:\\Windows\\Fonts\\msjh.ttc（微軟正黑體）')
try:
    font.set_variation_by_axes([400])   # 可變字型（例如 Noto Sans TC）預設是最細的，調成 400＝一般粗細
except Exception:
    pass                                 # 一般字型沒有粗細可調，略過

glyphs, steps = {}, {}
for ch in dict.fromkeys(a.text):         # 重複的字只做一次
    # 步驟 2：在 N×N 的黑色小畫布上，用白色畫這個字。
    # 字的「底線」放在 88% 高的地方：中文字型的方框大約是底線上方 88%、下方 12%
    img = Image.new('L', (N, N), 0)      # 'L'＝灰階，每點 0（黑）到 255（白）
    ImageDraw.Draw(img).text((0, N * 0.88), ch, font=font, fill=255, anchor='ls')
    gray = [[img.getpixel((x, y)) for x in range(N)] for y in range(N)]

    # 步驟 3：每一點跟門檻比，夠亮就是 1（螢幕上這點亮），不夠就是 0
    bits = [[1 if g >= a.threshold else 0 for g in row] for row in gray]

    # 步驟 4：橫著存（MONO_HLSB）：一列從左到右，每 8 點組成 1 個位元組，最左邊那點是最高位
    data = []
    for row in bits:
        for x0 in range(0, N, 8):
            byte = 0
            for x in range(x0, x0 + 8):
                byte = byte * 2 + (row[x] if x < N else 0)   # 12 點寬的字，每列最後 4 位補 0
            data.append(byte)
    glyphs[ch] = bytes(data)
    steps[ch] = dict(gray=gray, bits=bits, bytes=data)

# 步驟 5：印成十六進位，整段可以直接貼進 main.py（裡面已經有 import framebuf）
half = len(next(iter(glyphs.values()))) // 2
print(f'# 由 zh_font_to_bitmap.py 產生：{a.text}，{N}×{N}，門檻 {a.threshold}，字型 {os.path.basename(a.font)}')
print('import framebuf')
print()
print(f'SIZE = {N}')
print('GLYPHS = {')
for ch, b in glyphs.items():
    h = [''.join(f'\\x{v:02x}' for v in part) for part in (b[:half], b[half:])]
    print(f"    {ch!r}: bytearray(b'{h[0]}'")       # !r：用 Python 的寫法印這個字（自動加引號）
    print(f"                    b'{h[1]}'),   # {len(b)} 位元組")
print('}')
print()
print('def draw_zh(oled, text, x, y):')
print('    for ch in text:')

# Subclassing FrameBuffer provides support for graphics primitives
# http://docs.micropython.org/en/latest/pyboard/library/framebuf.html
class SSD1306(framebuf.FrameBuffer):
    def __init__(self, width, height, external_vcc):
        self.width = width
        self.height = height
        self.external_vcc = external_vcc
        self.pages = self.height // 8
        self.buffer = bytearray(self.pages * self.width)
        super().__init__(self.buffer, self.width, self.height, framebuf.MONO_VLSB)
        self.init_display()

    def init_display(self):
        for cmd in (
            SET_DISP,  # display off
            # address setting
            SET_MEM_ADDR,
            0x00,  # horizontal
            # resolution and layout
            SET_DISP_START_LINE,  # start at line 0
            SET_SEG_REMAP | 0x01,  # column addr 127 mapped to SEG0
            SET_MUX_RATIO,
            self.height - 1,
            SET_COM_OUT_DIR | 0x08,  # scan from COM[N] to COM0
            SET_DISP_OFFSET,
            0x00,
            SET_COM_PIN_CFG,
            0x02 if self.width > 2 * self.height else 0x12,
            # timing and driving scheme
            SET_DISP_CLK_DIV,
            0x80,
            SET_PRECHARGE,
            0x22 if self.external_vcc else 0xF1,
            SET_VCOM_DESEL,
            0x30,  # 0.83*Vcc
            # display
            SET_CONTRAST,
            0xFF,  # maximum
            SET_ENTIRE_ON,  # output follows RAM contents
            SET_NORM_INV,  # not inverted
            SET_IREF_SELECT,
            0x30,  # enable internal IREF during display on
            # charge pump
            SET_CHARGE_PUMP,
            0x10 if self.external_vcc else 0x14,
            SET_DISP | 0x01,  # display on
        ):  # on
            self.write_cmd(cmd)
        self.fill(0)
        self.show()

    def poweroff(self):
        self.write_cmd(SET_DISP)

    def poweron(self):
        self.write_cmd(SET_DISP | 0x01)

    def contrast(self, contrast):
        self.write_cmd(SET_CONTRAST)
        self.write_cmd(contrast)

    def invert(self, invert):
        self.write_cmd(SET_NORM_INV | (invert & 1))

    def rotate(self, rotate):
        self.write_cmd(SET_COM_OUT_DIR | ((rotate & 1) << 3))
        self.write_cmd(SET_SEG_REMAP | (rotate & 1))

    def show(self):
        x0 = 0
        x1 = self.width - 1
        if self.width != 128:
            # narrow displays use centred columns
            col_offset = (128 - self.width) // 2
            x0 += col_offset
            x1 += col_offset
        self.write_cmd(SET_COL_ADDR)
        self.write_cmd(x0)
        self.write_cmd(x1)
        self.write_cmd(SET_PAGE_ADDR)
        self.write_cmd(0)
        self.write_cmd(self.pages - 1)
        self.write_data(self.buffer)


class SSD1306_I2C(SSD1306):
    def __init__(self, width, height, i2c, addr=0x3C, external_vcc=False):
        self.i2c = i2c
        self.addr = addr
        self.temp = bytearray(2)
        self.write_list = [b"\x40", None]  # Co=0, D/C#=1
        super().__init__(width, height, external_vcc)

    def write_cmd(self, cmd):
        self.temp[0] = 0x80  # Co=1, D/C#=0
        self.temp[1] = cmd
        self.i2c.writeto(self.addr, self.temp)

    def write_data(self, buf):
        self.write_list[1] = buf
        self.i2c.writevto(self.addr, self.write_list)

        self.init_display()

    def init_display(self):
        for cmd in (
            SET_DISP,  # display off
            # address setting
            SET_MEM_ADDR,
            0x00,  # horizontal
            # resolution and layout
            SET_DISP_START_LINE,  # start at line 0
            SET_SEG_REMAP | 0x01,  # column addr 127 mapped to SEG0
            SET_MUX_RATIO,
            self.height - 1,
            SET_COM_OUT_DIR | 0x08,  # scan from COM[N] to COM0
            SET_DISP_OFFSET,
            0x00,
            SET_COM_PIN_CFG,
            0x02 if self.width > 2 * self.height else 0x12,
            # timing and driving scheme
            SET_DISP_CLK_DIV,
            0x80,
            SET_PRECHARGE,
            0x22 if self.external_vcc else 0xF1,
            SET_VCOM_DESEL,
            0x30,  # 0.83*Vcc
            # display
            SET_CONTRAST,
            0xFF,  # maximum
            SET_ENTIRE_ON,  # output follows RAM contents
            SET_NORM_INV,  # not inverted
            SET_IREF_SELECT,
            0x30,  # enable internal IREF during display on
            # charge pump
            SET_CHARGE_PUMP,
            0x10 if self.external_vcc else 0x14,
            SET_DISP | 0x01,  # display on
        ):  # on
            self.write_cmd(cmd)
        self.fill(0)
        self.show()

        self.write_cmd(SET_DISP)

    def poweron(self):
        self.write_cmd(SET_DISP | 0x01)

    def contrast(self, contrast):
        self.write_cmd(SET_CONTRAST)
        self.write_cmd(contrast)

    def invert(self, invert):
        self.write_cmd(SET_NORM_INV | (invert & 1))

    def rotate(self, rotate):
        self.write_cmd(SET_COM_OUT_DIR | ((rotate & 1) << 3))
        self.write_cmd(SET_SEG_REMAP | (rotate & 1))

        x0 = 0

        self.write_cmd(x1)
        self.write_cmd(SET_PAGE_ADDR)
        self.write_cmd(0)

# MicroPython SSD1306 OLED driver, I2C and SPI interfaces

from micropython import const
import framebuf


# register definitions
SET_CONTRAST = const(0x81)
SET_ENTIRE_ON = const(0xA4)
SET_NORM_INV = const(0xA6)
SET_DISP = const(0xAE)
SET_MEM_ADDR = const(0x20)
SET_COL_ADDR = const(0x21)
SET_PAGE_ADDR = const(0x22)
SET_DISP_START_LINE = const(0x40)
SET_SEG_REMAP = const(0xA0)
SET_MUX_RATIO = const(0xA8)
SET_IREF_SELECT = const(0xAD)
SET_COM_OUT_DIR = const(0xC0)
SET_DISP_OFFSET = const(0xD3)
SET_COM_PIN_CFG = const(0xDA)
SET_DISP_CLK_DIV = const(0xD5)
SET_PRECHARGE = const(0xD9)
SET_VCOM_DESEL = const(0xDB)
SET_CHARGE_PUMP = const(0x8D)


# Subclassing FrameBuffer provides support for graphics primitives
# http://docs.micropython.org/en/latest/pyboard/library/framebuf.html
class SSD1306(framebuf.FrameBuffer):
    def __init__(self, width, height, external_vcc):
        self.width = width
        self.height = height
        self.external_vcc = external_vcc
        self.pages = self.height // 8
        self.buffer = bytearray(self.pages * self.width)
        super().__init__(self.buffer, self.width, self.height, framebuf.MONO_VLSB)
        self.init_display()

    def init_display(self):
        for cmd in (
            SET_DISP,  # display off
            # address setting
            SET_MEM_ADDR,
            0x00,  # horizontal
            # resolution and layout
            SET_DISP_START_LINE,  # start at line 0
            SET_SEG_REMAP | 0x01,  # column addr 127 mapped to SEG0
            SET_MUX_RATIO,
            self.height - 1,
            SET_COM_OUT_DIR | 0x08,  # scan from COM[N] to COM0
            SET_DISP_OFFSET,
            0x00,
            SET_COM_PIN_CFG,
            0x02 if self.width > 2 * self.height else 0x12,
            # timing and driving scheme
            SET_DISP_CLK_DIV,
            0x80,
            SET_PRECHARGE,
            0x22 if self.external_vcc else 0xF1,
            SET_VCOM_DESEL,
            0x30,  # 0.83*Vcc
            # display
            SET_CONTRAST,
            0xFF,  # maximum
            SET_ENTIRE_ON,  # output follows RAM contents
            SET_NORM_INV,  # not inverted
            SET_IREF_SELECT,
            0x30,  # enable internal IREF during display on
            # charge pump
            SET_CHARGE_PUMP,
            0x10 if self.external_vcc else 0x14,
            SET_DISP | 0x01,  # display on
        ):  # on
            self.write_cmd(cmd)
        self.fill(0)
        self.show()

    def poweroff(self):
        self.write_cmd(SET_DISP)

    def poweron(self):
        self.write_cmd(SET_DISP | 0x01)

    def contrast(self, contrast):
        self.write_cmd(SET_CONTRAST)
        self.write_cmd(contrast)

    def invert(self, invert):
        self.write_cmd(SET_NORM_INV | (invert & 1))

    def rotate(self, rotate):
        self.write_cmd(SET_COM_OUT_DIR | ((rotate & 1) << 3))
        self.write_cmd(SET_SEG_REMAP | (rotate & 1))

    def show(self):
        x0 = 0
        x1 = self.width - 1
        if self.width != 128:
            # narrow displays use centred columns
            col_offset = (128 - self.width) // 2
            x0 += col_offset
            x1 += col_offset
        self.write_cmd(SET_COL_ADDR)
        self.write_cmd(x0)
        self.write_cmd(x1)
        self.write_cmd(SET_PAGE_ADDR)
        self.write_cmd(0)
        self.write_cmd(self.pages - 1)
        self.write_data(self.buffer)


class SSD1306_I2C(SSD1306):
    def __init__(self, width, height, i2c, addr=0x3C, external_vcc=False):
        self.i2c = i2c
        self.addr = addr
        self.temp = bytearray(2)
        self.write_list = [b"\x40", None]  # Co=0, D/C#=1
        super().__init__(width, height, external_vcc)

    def write_cmd(self, cmd):
        self.temp[0] = 0x80  # Co=1, D/C#=0
        self.temp[1] = cmd
        self.i2c.writeto(self.addr, self.temp)

    def write_data(self, buf):
        self.write_list[1] = buf
        self.i2c.writevto(self.addr, self.write_list)


class SSD1306_SPI(SSD1306):
    def __init__(self, width, height, spi, dc, res, cs, external_vcc=False):
        self.rate = 10 * 1024 * 1024
        dc.init(dc.OUT, value=0)
        res.init(res.OUT, value=0)
        cs.init(cs.OUT, value=1)
        self.spi = spi
        self.dc = dc
        self.res = res
        self.cs = cs
        import time

        self.res(1)
        time.sleep_ms(1)
        self.res(0)
        time.sleep_ms(10)
        self.res(1)
        super().__init__(width, height, external_vcc)

    def write_cmd(self, cmd):
        self.spi.init(baudrate=self.rate, polarity=0, phase=0)
        self.cs(1)
        self.dc(0)
        self.cs(0)
        self.spi.write(bytearray([cmd]))
        self.cs(1)

    def write_data(self, buf):
        self.spi.init(baudrate=self.rate, polarity=0, phase=0)
        self.cs(1)
        self.dc(1)
        self.cs(0)
        self.spi.write(buf)
        self.cs(1)
