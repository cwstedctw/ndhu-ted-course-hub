名字我預期實際上一樣嗎
貼上模式：把程式直接貼進來跑

兩種時候用這一塊：

  • 沒辦法改資料夾裡的檔案的時候，例如在教室電腦上、檔案是在 GitHub 網頁上改的。
  • 檔案讀不到，或最上面只說「Script error.」、想看詳細錯誤訊息的時候。

把檔案的內容整份複製，貼進對應的格子，按「用貼上的內容跑測試」。格子裡有內容，就用它取代同名的檔案（切換版本、重新整理也一樣）；空著的格子照舊讀資料夾裡的檔案。貼上的內容會自動記住，重新整理還在。貼上的程式寫錯時，詳細的錯誤訊息會出現在頁面最上面的說明框。

測試寫在 tests.js，規則寫在 rules.md，格式說明在 README.md。
